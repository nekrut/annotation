## Two AUGUSTUS `--genemodel=partial` runs, and three defects

Every submission the benchmark had scored was `--genemodel=complete` or a
curated annotation, so section 4.5's *predicted*-partial handling had only ever
run on fixtures -- and the fixtures were built around the reference convention.
AUGUSTUS 3.5.0 was run twice: *T. thermophila* (`--species=tetrahymena`, one
invocation per scaffold over its 1,158 scaffolds, genetic code 6) and
*A. mellifera* (`--species=honeybee1`, 177 sequences, 36.4 min on 22 cores).
Both species are in AUGUSTUS's own training set, so neither is a measurement.

| run | nucl | exon | donor | transcript | locus | start | stop |
|---|---:|---:|---:|---:|---:|---:|---:|
| *T. thermophila* | 0.420 | 0.328 | 0.392 | 0.208 | 0.536 | 0.310 | 0.434 |
| *A. mellifera* | 0.891 | 0.693 | 0.811 | 0.225 | 0.793 | 0.402 | 0.618 |

1. **Counting a reused transcript id was not enough.** An earlier run added a
   count and a warning for ids appearing on more than one sequence, but still
   welded their chains together. Over 1,158 scaffolds 214 ids collide, and the
   welding takes the whole file to 218 scored chains from 10,355: nucleotide F1
   **0.020** against 0.420. Ids are now keyed by (sequence, strand). The control
   is exact -- the same run repeated with `--uniqueGeneId=true` scores
   identically block for block.
2. **`predicted_partial_5prime`/`_3prime` could not fire.** They read
   `start_range=`/`end_range=`, which no predictor writes. A GTF-lineage
   predictor states a truncated end by *omitting* the `start_codon`/`stop_codon`
   feature. Reading that removes 208 false-positive starts and 22 false-positive
   stops from the *T. thermophila* run.
3. **A 3'-partial gene could be handed a stop codon it never predicted.** The
   bare-GTF case and the truncated-gene case both reach the 3 bp extension as a
   chain with no `stop_codon` feature and need opposite treatment. *A. mellifera*
   exercises it because `honeybee1` excludes the stop from the CDS while
   `tetrahymena` includes it: 13 chains skipped, 8 false-positive stops. The
   fixture shows the worse form, where the invented codon lands on the
   reference's real stop and scores a **true positive**.

## The check that makes (2) more than a guess, and one number for T-human-008

GENCODE 50 states partiality **both** ways: it writes codon features *and* tags
incomplete CDS ends `cds_start_NF`/`cds_end_NF`. Read from omissions: 13,203
5'-partial and 19,535 3'-partial. Read from the tags: 13,226 and 19,858.
Agreement 99.7% and 99.2% over 370,910 transcripts. So the omission means what
section 4.5 now says it means, at about 1% error on curated human data.

For marx (T-human-008) and for T-human-011, since it bears on what a training
target may assume: **5.3% of GENCODE's CDS-bearing transcripts have an
incomplete CDS end that the file does not mark with any attribute a window
cutter is likely to read** -- only by the absence of a codon feature. A cutter
that paints start and stop codons from the annotation will paint 13,203 starts
and 19,535 stops that the annotation does not actually claim, unless it reads
either the omission or the NF tags. That is information, not an instruction;
the sidecar's `distinct_sites` accounting is the natural place for it if it is
wanted.

## Also documented

"AUGUSTUS excludes the stop codon" is not a property of AUGUSTUS.
`stopCodonExcludedFromCDS` is a line in each *species* parameter file: of the
166 shipped with 3.5.0, **44 set it `true` and 122 set it `false`**. Two runs of
the same binary one species apart need opposite flags. Section 4.5 carries the
one-line census.
