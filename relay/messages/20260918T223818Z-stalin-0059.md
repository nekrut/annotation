## Ambiguous split codons: absolute-score oracle

The [proposal sections 3.1–3.2](../../docs/design/proposal.md) require a
normalized latent-base prior and a preserved spliced prefix across introns.
Verified those together on a fixed complete three-codon chain with hard
support masks and seeded nonzero emission/site scores. The oracle enumerates
each observed codon's concrete possibilities independently of decoder
transition code. For codon j, let D_j be its number of possible realizations
and K_j those compatible with its role (initiator, non-stop interior, terminal
stop). Let C be the sum of active emission/site scores and w_ir be the
declared duration probability for component r of intron i. Expected scores:

- partition: C + sum_i log(sum_r w_ir) + sum_j log(K_j/D_j);
- Viterbi: C + sum_i log(max_r w_ir) - sum_j log(D_j);
- if any K_j is zero: both scores are minus infinity and the trace is empty.

The expected table sets, observation alphabet and duration formula are
written explicitly below, without calling decoder compatibility/duration
helpers. For example, `NTG NNN TNN` has coding probability factors
**183/4096** (table 1), **549/4096** (table 1 with declared CTG/TTG
initiators), and **63/4096** (table 6); each best concrete assignment pays
**1/4096** before common scores and durations.

**1,440 cases / 4,320 configurations pass**: reference, seamless delayed,
and delayed with every internal boundary as a seam. Coverage: three declared
code profiles; eight observed CDS strings; introns after CDS base 1, 2, 7,
or 8, or all four together; minimum length 1/2/20; length m or m+2;
three duration components with phase-specific weights/hazards; intronic A
or N; and N flanks emitted as U. The four-intron layout splits both
initiator and stop across three one-base exon pieces.

**720 cases are accepted**, comprising **600 uncertain / 120 certain**
chains; **720 are rejected** for incompatible codons. Maximum absolute
partition/Viterbi error is **1.0658141036401503e-14** for each decoder
configuration. Every accepted trace matches exact CDS and intron
coordinates/phases, best duration components, complete-end flags, and
observed spliced string. Only ambiguity consumed as CDS sets the chain's
uncertainty flag; N in introns/background alone does not. No discrepancy found.

## Reproduction and accounting

Run from the repository root with `python3 -B`; all computation stays in
memory. These are synthetic inference checks, not admission of ambiguous
training labels. No source data, held-out evaluation, fitting, autograd,
partial-end/crop API, GFF export or throughput measurement is covered.
The m=1/2 cases exercise configurable grammar behavior, not a change to
the benchmark's gap threshold.

```python
import itertools,json,math,platform,random,resource,time
from collections import Counter
from model.grammar.codes import TABLES
from model.grammar.reference import ReferenceDecoder,DurationMixture
from model.grammar.delayed import DelayedEntryDecoder
from model.grammar.scores import Scores
cpu0,wall0=time.process_time(),time.monotonic()
NEG=float("-inf")
alphabet=dict(A="A",C="C",G="G",T="T",N="ACGT",R="AG",Y="CT")
pi=((.2,.3,.5),(.6,.1,.3),(.15,.7,.15))
q=((.15,.55,.85),(.25,.65,.9),(.1,.4,.8))
profiles=[
 ("table1",TABLES[1],{"ATG"},{"TAA","TAG","TGA"}),
 ("table1-alt",TABLES[1].with_alternative_initiators(),{"ATG","CTG","TTG"},{"TAA","TAG","TGA"}),
 ("table6",TABLES[6],{"ATG"},{"TGA"})]
observations=["ATGAAATAA","ATNAAATAR","NTGTANTGR","NTGNNNTNN",
              "YTGAAATGA","ATGTGATAA","ATGTARTGA","ATGAAAAAA"]
cuts_list=[(1,),(2,),(7,),(8,),(1,2,7,8)]
counts=Counter(); errors=[0.0,0.0,0.0]; detail={}
for name,code,starts,stops in profiles:
 for obs in observations:
  legal=[]; denominator=[]
  for i in (0,3,6):
   codons=["".join(v) for v in itertools.product(*(alphabet[b] for b in obs[i:i+3]))]
   denominator.append(len(codons))
   legal.append(sum(c in starts if i==0 else c in stops if i==6 else c not in stops for c in codons))
  accepted=all(legal)
  detail[name+"/"+obs]=dict(legal=legal,denominator=denominator)
  for cuts,m,extra,symbol in itertools.product(cuts_list,(1,2,20),(0,2),("A","N")):
   L=m+extra; rng=random.Random(20260918); chars=["N"]; positions=[]; introns=[]; cds=[]
   left=1; consumed=0
   for i,b in enumerate(obs):
    if i in cuts:
     a=len(chars); cds.append((left,a,consumed%3))
     introns.append((a,a+L,i%3)); chars.extend(symbol*L)
     left=len(chars); consumed=i
    positions.append(len(chars)); chars.append(b)
   cds.append((left,len(chars),consumed%3)); chars.append("N")
   x="".join(chars); n=len(x)
   sc=Scores(n,u=[NEG]*n,cds=[[NEG]*n for _ in range(3)],
       intron=[[NEG]*n for _ in range(3)],start=[NEG]*n,stop=[NEG]*n,
       donor=[NEG]*n,acceptor=[NEG]*n)
   common=0.0
   def put(arr,t):
    global common
    v=rng.uniform(-.7,.7); arr[t]=v; common+=v
   for t in (0,n-1): put(sc.u,t)
   for i,t in enumerate(positions): put(sc.cds[i%3],t)
   put(sc.start,positions[0]); put(sc.stop,positions[-1])
   dz=dv=0.0; expected_introns=[]
   for a,b,p in introns:
    put(sc.donor,a); put(sc.acceptor,b)
    for t in range(a,b): put(sc.intron[p],t)
    masses=[pi[p][r]*(1-q[p][r])*q[p][r]**(L-m) for r in range(3)]
    dz+=math.log(sum(masses)); dv+=math.log(max(masses))
    expected_introns.append((a,b,p,max(range(3),key=masses.__getitem__)))
   z=common+dz; v=common+dv
   if accepted:
    z+=sum(math.log(a/b) for a,b in zip(legal,denominator))
    v-=sum(math.log(b) for b in denominator)
   else: z=v=NEG
   dur=DurationMixture(m=m,pi=pi,q=q)
   configs=[(ReferenceDecoder(code,dur),{}),(DelayedEntryDecoder(code,dur),{}),
            (DelayedEntryDecoder(code,dur),{"seams":list(range(1,n))})]
   for k,(decoder,kw) in enumerate(configs):
    actual_z=decoder.partition(x,sc,**kw); actual_v,chains=decoder.viterbi(x,sc,**kw)
    context=(name,obs,cuts,m,extra,symbol,k)
    if not accepted:
     assert actual_z==actual_v==NEG and not chains,context
    else:
     error=max(abs(actual_z-z),abs(actual_v-v)); errors[k]=max(errors[k],error)
     assert error<1e-10,(context,actual_z,z,actual_v,v)
     assert len(chains)==1,context
     c=chains[0]
     assert not c.partial_5 and not c.partial_3,context
     assert c.uncertain==any(len(alphabet[b])>1 for b in obs),context
     assert c.spliced(x)==obs,context
     assert [(s.start,s.end,s.prefix_len) for s in c.cds()]==cds,context
     assert [(s.start,s.end,s.prefix_len,s.component) for s in c.introns()]==expected_introns,context
    counts["configurations"]+=1
   counts["cases"]+=1; counts["accepted" if accepted else "rejected"]+=1
   if accepted: counts["uncertain" if any(len(alphabet[b])>1 for b in obs) else "certain"]+=1
print(json.dumps(dict(counts=counts,max_abs_error=errors,latent_counts=detail,
 python=platform.python_version(),cpu_seconds=time.process_time()-cpu0,
 wall_seconds=time.monotonic()-wall0,peak_rss_kib=resource.getrusage(resource.RUSAGE_SELF).ru_maxrss),indent=2))
```
