## The annex bibliography, measured rather than self-reported

`engels`'s cover reports "eight distinct DOI sources" absent from its base
bibliography; `stalin`'s index lists twelve. Those two counts overlap, and five
of `stalin`'s twelve were already in the merged file from other reviews. New
[`scripts/review/merge_annex_refs.py`](https://github.com/nekrut/annotation/blob/b648f75/scripts/review/merge_annex_refs.py)
scans the 49 messages either agent filed against `T-human-003` or
`T-human-004`, extracts every DOI, subtracts the DOIs the five artifact
bibliographies already carry, and finds **15 annex-only works** — 10 reached
only by `engels`, 7 only by `stalin`, 2 by both. All 15 resolve in Crossref.

`merge_refs.py` now reads `docs/review/annex-refs.bib` as a sixth source, so
they land in `refs.bib` with `reviews = {engels (annex)}` and an `annex` field
naming the messages. **refs.bib is 111 → 126 works**; the re-run Crossref pass
gives 110 ok and the same 9 bad DOIs as before, all from `trotsky`. Every one
of the 15 is cited in the synthesis: README §2.6 lists them with what the annex
reached for, and §5.14 now cites *Stentor*'s 15-base introns, the ciliate
genetic codes with no dedicated stop codon, and the U12-intron database
directly instead of pointing at "`stalin`'s scope annexes".

`check_conflicts.py` scans the annex works too and reports two new
preprint/journal pairs, PhyloCSF++ and ClaMSA (4 conflicts + 6 pairs, was
4 + 4). That is `engels`'s own annex point — ClaMSA's recovered tables belong
to the preprint version — now falling out of the check rather than sitting in
prose.

The most consequential one I did find while extracting citations goes to
whoever takes **T-human-010**: `stalin` 0016 traces `codeml` overriding
`cleandata` to 1 for `runmode=-2/-3`, after which `ReadSeq`/`RemoveIndel`
deletes any codon column with an ambiguity or gap in *any* input row. So
handing a full multispecies alignment to a pairwise KA/KS fit silently removes
codons that were clean in the target/informant pair. Materialize each pair
before cleaning, and report original and retained codon counts. This is in
README §7, not §5, because it is an instruction to a downstream task rather
than a claim about the literature.
