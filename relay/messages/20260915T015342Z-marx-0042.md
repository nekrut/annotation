### Run 1: EGAPx v1.0 on *Ciona intestinalis*

- Command or job script:
  `cluster-run.sh submit --cpus 20 --mem 240 --gpus 0 --time 12:00:00 --name egapx-ciona docs/cost-baseline/cluster/egapx_ciona.sbatch <checkout> <scratch>/egapx`.
  The script clones `ncbi/egapx` at tag `v1.0`, runs
  `ui/egapx.py input.yaml -e singularity` with an input of genome and taxid
  7719 only (no RNA-seq; proteins from EGAPx's own taxon-matched NCBI sets),
  caps Nextflow CPU and memory labels to the allotment (the node has 20 CPUs
  against EGAPx's stated 32; every edit is logged), and times the driver
  under GNU time with a Nextflow trace.
- Container or environment: `docker://ncbi/egapx:1.0`, pulled by EGAPx
  itself through singularity or apptainer; on the node: Nextflow 23.10 or
  later, Python 3.11 or later with venv, git, GNU time at `/usr/bin/time`,
  network access to NCBI, GitHub and Docker Hub.
- Inputs (verified against NCBI's `md5checksums.txt` by `benchmark/fetch.py`;
  SHA-256 recorded in `inputs.sha256` after download):
  - https://ftp.ncbi.nlm.nih.gov/genomes/all/GCF/018/327/825/GCF_018327825.1_ASM1832782v2/GCF_018327825.1_ASM1832782v2_genomic.fna.gz, 42,164,729 bytes, md5 c9eacbcc32a5182a496cfa7e057b9aa2
  - https://ftp.ncbi.nlm.nih.gov/genomes/all/GCF/018/327/825/GCF_018327825.1_ASM1832782v2/GCF_018327825.1_ASM1832782v2_genomic.gff.gz, 7,079,141 bytes, md5 5acd9a693eea48d5a944fa7f7273cf21
  - EGAPx support files and protein sets, fetched by EGAPx on first run
    (several GB; not checksummed here).
- Outputs to return: `<scratch>/egapx/return/` (all text, under 1 MB in
  total): `summary.tsv`, `trace.txt`, `egapx.time`, `resource_caps.txt`,
  `egapx-Ciona_intestinalis.json`, `egapx-Ciona_intestinalis.yaml`,
  `input.yaml`, `inputs.sha256`, `repo_commit.txt`, `egapx_commit.txt`,
  `versions.txt`, `hardware.txt`, `disk_usage.txt`, `out_listing.txt`,
  `egapx.stdout.tail`, `egapx.stderr.tail`. The prediction GFF (about 10 MB

  the cost row, and
  `benchmark/score.py --reference <gff.gz> --prediction out/complete.genomic.gff --species Ciona_intestinalis --declaration <yaml> --genome <fna.gz>`
  for accuracy. Return `summary.tsv` and the `.json` even if EGAPx exits
