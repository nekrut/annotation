## The assembly-report inventory agrees with the actual benchmark GFF selection

Fetched all ten **train** source GFFs in memory and verified their compressed
bytes against [panel.tsv](../../benchmark/panel.tsv)'s pinned MD5s.
Parsed sequence lengths, region attributes and feature-type counts, then
called the existing [select_seqids](../../benchmark/score.py) on that
metadata. Re-fetched assembly reports, verified their NCBI sibling checksums,
and applied engels-0049's explicit assembly-unit/role/length inventory.
Also checked the admission manifest checksums, source checksum identities,
representative/admitted counts, and membership of every represented seqid.

For **every species**, the actual GFF-selected seqid set equals that report
inventory, and all GFF sequence lengths agree with the reports. Selected
sequence counts and base totals also exactly reproduce the committed
[degraded benchmark results](../../benchmark/validation/degraded/).
The aggregate is **995 selected seqids**, including **700** without
representative manifest rows, totaling **44,445,020 bases**.

The source GFFs now let us characterize those 700 more precisely:

**None of the 700 has any CDS feature row** in the pinned GFF.
Of these, 604 contain only a `region` feature; the other 96 have additional
features, including noncoding RNAs, pseudogenes, transcripts or matches.
This establishes absence of annotated CDS in those source files, not
biological absence of protein-coding genes or the reliability of negative
training labels. A loader should enumerate the selected source sequences,
then join representatives/masks, preserving these sequences in the declared
sampling and scoring universe.

## Ddp5 is explicitly annotated as nuclear

Dictyostelium `NC_001889.1` is **14,955 bp** and its pinned GFF region has
`genome=plasmid`, `Is_circular=true`, `plasmid-name=Ddp5`, and
`note=high copy number nuclear plasmid`.
It has six genes, six mRNAs, eight CDS rows, and six admitted representatives.
[Source GFF](https://ftp.ncbi.nlm.nih.gov/genomes/all/GCF/000/004/695/GCF_000004695.1_dicty_2.7/GCF_000004695.1_dicty_2.7_genomic.gff.gz),
MD5 `074ff2892412e4068538cf5df8dba350`.

Thus being a plasmid alone does not establish a violation of the
benchmark's nuclear scope. The current selector intentionally excludes its
listed organelle categories but has no plasmid exclusion, and Ddp5's
inclusion reproduces the accepted benchmark denominator. This resolves the
source-metadata part of engels-0049's reconciliation item; it does not
establish a policy for circular sequence-edge treatment. No selection,
admission or split policy was changed.

## Reproduction and limits

Run the following from the repository root at the commit above with
`python3 -B`; it uses read-only sequential HTTP requests and creates no
files. Assembly report URLs/MD5s also appear in engels-0049; the exact GFF
URLs are constructed from the pinned panel entries below.

```python
import csv,gzip,hashlib,io,json,platform,time,urllib.request
from collections import Counter
from pathlib import Path
from types import SimpleNamespace
from benchmark.fetch import asm_parent
from benchmark.score import select_seqids
cpu0,wall0=time.process_time(),time.monotonic()
def get(url):
    req=urllib.request.Request(url,headers={"User-Agent":"relay-benchmark/0.1 (https://github.com/nekrut/annotation)"})
    with urllib.request.urlopen(req,timeout=25) as response: return response.read()
panel=[r for r in csv.DictReader(open("benchmark/panel.tsv"),delimiter="\t") if r["split"]=="train"]
out=[]
for p in sorted(panel,key=lambda r:r["species"]):
    sp=p["species"]; stem=p["ftp_dir"]; base=asm_parent(p["accession"])+"/"+stem
    raw=get(base+"/"+stem+"_genomic.gff.gz")
    assert hashlib.md5(raw).hexdigest()==p["md5_gff"],sp
    ref=SimpleNamespace(seq_len={},region_attrs={}); features={}
    with io.TextIOWrapper(gzip.GzipFile(fileobj=io.BytesIO(raw))) as stream:
        for line in stream:
            if line.startswith("##sequence-region"):
                _,s,a,b=line.split(); ref.seq_len[s]=int(b)-int(a)+1
            if line.startswith("#"): continue
            f=line.rstrip("\n").split("\t")
            if len(f)<9: continue
            s=f[0]; features.setdefault(s,Counter())[f[2]]+=1
            if f[2]=="region" and f[3]=="1":
                ref.region_attrs[s]=f[8]; ref.seq_len.setdefault(s,int(f[4]))
    reasons={}; keep=select_seqids(ref,reasons=reasons)
    root=Path("model/labels/manifests"); path=root/(sp+".manifest.tsv.gz")
    summary=json.loads((root/(sp+".summary.json")).read_text())
    assert hashlib.md5(path.read_bytes()).hexdigest()==summary["manifest_md5"]
    assert summary["gff_md5"]==p["md5_gff"]
    with gzip.open(path,"rt") as f: rows=list(csv.DictReader(f,delimiter="\t"))
    assert len(rows)==summary["representatives"]
    assert sum(r["status"]=="admitted" for r in rows)==summary["admitted"]
    represented={r["seqid"] for r in rows}
    assert represented<=keep,(sp,represented-keep)
    report_name=stem+"_assembly_report.txt"; report=get(base+"/"+report_name)
    sums={line.split()[-1].removeprefix("./"):line.split()[0] for line in get(base+"/md5checksums.txt").decode().splitlines() if line.strip()}
    assert hashlib.md5(report).hexdigest()==sums[report_name]
    records=[line.split("\t") for line in report.decode().splitlines() if line and not line.startswith("#")]
    by_ref={r[6]:r for r in records if r[6]!="na"}
    unit="C57BL/6J" if sp=="Mus_musculus" else "Primary Assembly"
    inventory={s for s,r in by_ref.items() if r[7]==unit and r[1] in {"assembled-molecule","unlocalized-scaffold","unplaced-scaffold"} and int(r[8])>=10000}
    assert all(s in by_ref and ref.seq_len[s]==int(by_ref[s][8]) for s in ref.seq_len)
    absent=keep-represented
    with_cds={s for s in absent if features.get(s,{}).get("CDS",0)}
    region_only={s for s in absent if set(features.get(s,{}))=={"region"}}
    historic=json.loads(Path("benchmark/validation/degraded",sp+".json").read_text())
    assert len(keep)==historic["scored_sequences"]
    assert sum(ref.seq_len[s] for s in keep)==historic["scored_bp"]
    item=dict(species=sp,gff_md5=p["md5_gff"],report_md5=sums[report_name],
        report_candidates=len(inventory),gff_selected=len(keep),scored_bp=sum(ref.seq_len[s] for s in keep),
        report_only=sorted(inventory-keep),gff_only=sorted(keep-inventory),
        absent_representatives=len(absent),absent_bp=sum(ref.seq_len[s] for s in absent),
        absent_with_cds=len(with_cds),absent_with_cds_bp=sum(ref.seq_len[s] for s in with_cds),
        absent_region_only=len(region_only),absent_region_only_bp=sum(ref.seq_len[s] for s in region_only),
        other_absent=len(absent-with_cds-region_only),
        other_absent_features=dict(sum((features[s] for s in absent-with_cds-region_only),Counter())),
        absent_cds_examples={s:dict(features[s]) for s in sorted(with_cds)[:4]})
    if sp=="Dictyostelium_discoideum":
        s="NC_001889.1"
        item["Ddp5"]=dict(length=ref.seq_len[s],region=ref.region_attrs[s],features=dict(features[s]),selected=s in keep,
            representatives=sum(r["seqid"]==s for r in rows),admitted=sum(r["seqid"]==s and r["status"]=="admitted" for r in rows))
    out.append(item); print(json.dumps(item),flush=True)
print(json.dumps(dict(total_absent=sum(r["absent_representatives"] for r in out),total_absent_bp=sum(r["absent_bp"] for r in out),
    total_absent_with_cds=sum(r["absent_with_cds"] for r in out),total_region_only=sum(r["absent_region_only"] for r in out),
    python=platform.python_version(),cpu_seconds=time.process_time()-cpu0,wall_seconds=time.monotonic()-wall0)),flush=True)
```
