## Independent enumerator agrees, edge partials included

I wrote a brute-force path enumerator from the state semantics in
`reference.py`'s module docstring (proposal 3.1/3.2), **without importing
marx's `transitions()` or duration helpers**: my own transition relation,
DFS over every legal state path 0..n, forward = logsumexp over path totals,
Viterbi = max. This differs from the existing path-enumeration test and from
the earlier concrete-resolution checks ([engels-0036](20260915T162245Z-engels-0036.md),
[stalin-0043](20260915T163851Z-stalin-0043.md), which enumerated *chains*
and did not exercise the reference DP's bookkeeping or the edge grammar).

Sweep: tables 1/6, alternative initiators off/on, m 1-4, R 1-3, edges
off and on (`EdgePrior(log .4, log .6)`), random score lattices, over 9
short sequences with IUPAC ambiguity. **672 configs, 2,381,807 enumerated
paths.** My enumerator, `ReferenceDecoder`, and `DelayedEntryDecoder` all
agree pairwise on both forward and Viterbi scores:

```
indep-vs-reference : max|dF|=1.78e-15 max|dV|=8.88e-16
indep-vs-delayed   : max|dF|=1.78e-15 max|dV|=1.78e-15
reference-vs-delayed: max|dF|=1.78e-15 max|dV|=1.78e-15
```

This is the first independent check of the **edge partials** (3.1): E0 (CDS
from boundary 0, first base forced CDS), J (residual intron from the edge,
correctly non-terminal at n), and the censored S/E/I/T exit at n, all with
the `entry - log3 - p*log4` phase/prefix prior. The scores match, so the
E0/J/exit priors and the "no path without observed CDS" property hold.

## Reproduction

Extract the branch's `model/grammar/` to a temp dir importable as
`model.grammar`, then run with Python 3.11, stdlib only, `-B`. Core of the
independent transition relation (full driver enumerates all paths via DFS and
compares to both decoders; the transition function below is the independent
part, transcribed from the docstring, not from `transitions()`):

```python
def trans(self, st, x, t, sc):   # my own relation; dur = DurationMixture
    k = st[0]
    if k == "U":
        yield ("U",), sc.u[t]
        bs = permitted_bases(x[t]); pr = -math.log(len(bs))
        for b in bs:
            if b in self.prefixes:
                yield ("S", b), sc.start[t] + sc.cds[0][t] + pr
        return
    if k == "E0":
        yield from self._coding(("E", st[1]), x, t, sc); return
    if k in ("S", "E"):
        yield from self._coding(st, x, t, sc)
        p = len(st[1])
        if self.m == 1:
            for r in range(self.R):
                yield ("T", st, r), sc.donor[t] + sc.intron[p][t] + math.log(self.dur.pi[p][r])
        else:
            yield ("I", st, 1), sc.donor[t] + sc.intron[p][t]
        return
    if k == "I":
        _, c, j = st; p = len(c[1])
        if j + 1 < self.m:
            yield ("I", c, j + 1), sc.intron[p][t]
        else:
            for r in range(self.R):
                yield ("T", c, r), sc.intron[p][t] + math.log(self.dur.pi[p][r])
        return
    if k in ("T", "J"):
        _, c, r = st; p = len(c[1])
        yield st, sc.intron[p][t] + math.log(self.dur.q[p][r])
        ex = math.log(1 - self.dur.q[p][r]) + sc.acceptor[t]
        for nxt, s in self._coding(c, x, t, sc):
            yield nxt, s + ex
        return
```

Initial weights add `("E0", q): entry - log3 - len(q)*log4` and
`("J", ("E", q), r): that + log pi[len(q)][r]` when edges are on; terminal
gives `edges.exit` to S/E/I/T only (never J, never U's 0.0 override). Ran in
memory from git blobs with `-B`; no work-product or other owner's files
changed. Next useful review: the reverse-complement replay once it lands.
