Reviewed [PR #38](https://github.com/nekrut/annotation/pull/38) at
`1c3413ed8398ef3a52763b2a5c84ad1f8c279d20`. Changes requested for the encoder
increment below. This is not acceptance of the end-to-end pilot or its budget;
the loader, loss, fitting and measurement remain explicitly pending.

1. **P2 — Local attention still performs dense quadratic work.**
   [`LocalAttention.forward`](https://github.com/nekrut/annotation/blob/1c3413ed8398ef3a52763b2a5c84ad1f8c279d20/model/a/encoder.py#L119)
   computes full QK-transpose and attention-times-V products; masking afterward
   restricts dependencies but does not restrict those products' work. Bias,
   index, score and probability arrays also have full token-by-token extent.
   For the specified 4,104-base input, T=342, four heads, width=96: each block
   has 467,856 score entries versus 21,888 slots for 16 offsets (21.375x).
   The two attention products cost 22,457,088 MACs versus 1,050,624 for a
   fixed-window implementation, from `2*T*T*96` versus `2*T*16*96`.
   These are operation counts, **not measured runtime or an end-to-end
   budget failure**. Implement the products over the declared offsets
   (e.g. gathered/unfolded local keys and values), retaining the same weights
   and relative biases. Compare outputs and gradients against this dense
   implementation as a small oracle, and meter the actual implementation.
   The current arithmetic/shape tests do not establish the proposed local
   compute envelope. Separately, the fusion and emission heads currently
   process all halo positions; section 3.5 budgets these heads on the retained
   core. The future core interface should crop before those heads.

2. **P2 — Unavailable bases contaminate nearby real-base GC.**
   [`encode_sequence`](https://github.com/nekrut/annotation/blob/1c3413ed8398ef3a52763b2a5c84ad1f8c279d20/model/a/features.py#L85)
   calls `gc_track(seq)` before applying availability. With the same real
   sequence `A` and availability `[True, False]`, placeholders `AC`, `AT`,
   and `AN` yield channel-6 values 0.5, 0.0, and 0.0 respectively at the
   real A, although the second position is unavailable in every case.
   The existing test even uses `AC` as a padded input but checks only the
   unavailable column. Exclude unavailable positions from both GC counts
   before constructing neighboring features, and add an invariance test
   that changes only unavailable letters. Merely zeroing their own output
   columns does not satisfy the masked-padding contract.

3. **P2 — Explicit package list excludes the new implementation.**
   [`pyproject.toml`](https://github.com/nekrut/annotation/blob/1c3413ed8398ef3a52763b2a5c84ad1f8c279d20/pyproject.toml#L20)
   still declares `packages = ["model", "model.grammar"]`; `model.a` is not
   included. Add it or use appropriate package discovery, then verify a
   wheel installed outside the checkout can import the new package. Source-tree
   tests alone will hide this omission. This is a static packaging finding;
   I did not build or install a wheel.
