The revision section 3.3 proposed is in and measured. It is the
**decoder**, not a refit: the same fit-cpu-v3 checkpoint, the same
tiling, scorer and pinned core, with one hard constraint added.

**Why the decoder.** The pooled decoder's 16-entry donor and acceptor
dinucleotide tables are a *soft* bias — they reorder splice sites, they
cannot forbid one. Fit v3 emitted 3,986 non-canonical introns on chr V
against 470 canonical false positives, and exactly **one** of its true
introns was non-canonical. The grammar was admitting paths the biology
does not.

**The increment** (PR 38 at `7875483`). `model.a.pooled.motif_bias`
gains a `canonical` mask: a donor emission is `-inf` unless the first two
intron bases are `GT`/`GC`, an acceptor `-inf` unless the last two are
`AG`. Both decoders already read `-inf` as a hard mask, so no kernel
changed. A dinucleotide that is ambiguous or reaches past the window is
**not** masked — the mask fires only on positive evidence, so an `N` or a
tile edge can never delete a legal site, and in both decode modes it
reads the same extended slice as the bias. It is threaded through
`predict_sequence` and `measure --canonical-splice`, recorded in the
measured row (`canonical_splice`), and the window profile refuses the
flag rather than report an unmasked row as masked. **Inference only**: a
hard `-inf` in the chain-loss numerator would make a reference intron
with an unusual dinucleotide unreachable and the loss infinite. Tests:
`CanonicalSpliceMask` (the mask is exactly the concrete non-canonical
sites; every intron decoded under it is canonical, while the unmasked
decode does leave the canonical set) and `CanonicalFlag`; 226 pass.

**Ablation** (`relay/artifacts/T-human-014/smoke-local-20260920/fit-cpu-v3/score-canonical/`).
The launcher is `score-final/run_final.sh` with the flag added and the
directory renamed; substituting both back diffs empty against it, so the
gate, the failure propagation and every workload argument are unchanged.
All four workloads exit 0.

- **Splice placement roughly doubles, and not only by deletion**: the
  number of *correct* introns rises 433 → 1,070, so the mask moves the
  Viterbi path onto real sites rather than merely removing wrong ones.
- **Structure improves**: exact transcripts +44%, exact exon F1 doubles,
  fusions 312 → 226.
- **Nucleotide F1 falls 0.598 → 0.585** (sens 0.533 → 0.503, prec 0.680 →
  0.698; predicted CDS 4.40 → 4.04 Mb): coding bases it used to claim
  through illegal introns are given up. Locus F1 follows, 0.603 → 0.590.
- **The mask is cheaper**, 8.88 → 8.65 CPU-s/Mb (decode 105.48 → 100.90
  CPU-s): it removes transitions rather than adding work. **The CPU
  verdict stands and no positive CPU allowance for B follows.**
- **A still misses the accuracy target**: exact-transcript sensitivity
  0.020 per scored locus (0.015 per reference transcript), with 21,550
  reference GT-AG introns still missed. What remains is not which sites
  are *legal* but which legal site scores highest — the next decoder
  increment (donor/acceptor scoring, locus boundaries). Nothing here
  accepts T-human-014.
