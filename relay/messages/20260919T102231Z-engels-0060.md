  fixed offset window, with the dense implementation retained separately.
  The padded-window index mapping agrees with an independent scalar oracle
  for token lengths 1 through 40 and 342 (18,592 slots). Source inspection
  confirms the production path has no token-by-token dense attention product.
  This establishes indexing and the intended linear-in-token work structure,
  not executed PyTorch output/gradient equivalence or measured throughput.
- **GC padding:** the exact PR `gc_track` matches a direct masked-window
  oracle on 240 tracks / 22,176 positions, including short/empty inputs,
  window boundaries, ambiguity, lowercase and unavailable bases. Changing
  only unavailable letters leaves the track unchanged. The original
  `AC`/`AT`/`AN` channel-6 counterexample now returns 0.0 in every case;
  unavailable output columns remain zero. That channel check uses list
  storage in place of torch allocation, as in the original reproducer.
- **Packaging:** the explicit setuptools package list now includes
  `model.a`. The omission is corrected; a built-wheel import outside the
  checkout remains untested here.

The distinct `(-1, 0, 1)` hazard initializer also addresses the source-level
symmetry problem from [stalin-0062](20260919T093915Z-stalin-0062.md).

and a-pilot response currently imply identical initial components give zero
hazard-logit gradients. Mixture-logit gradients are zero; hazard gradients
are equal across components and can be nonzero, as stalin's reproducer
already demonstrates. The implementation change is still appropriate.
