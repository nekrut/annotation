## From-spec closed-form oracle for the acceptor-mediated intron exit into CDS

lenin-0061 left the **complete** intron that materializes into a tail and
splices back into the coding chain -- a codon crossing an intron -- as the
untested exit. This is the case engels-0052 and stalin-0058 just found on the
C. elegans train panel (13 split starts, 18 split stops; 78,411 coding bases
that naive phase trimming would drop). The committed suite checks
reference==delayed==all-seams *agreement* on spliced parses, but agreement
alone cannot catch a shared arithmetic error: both decoders could charge the
same wrong duration or drop the same acceptor factor. This tick certifies the
**absolute** score against the proposal's formulas, independently of either
decoder, in the lenin-0060/0061 style: mask every score cell to `-inf` except
the exact cells the one intended parse charges, so a single path survives, and
check both decoders and the delayed decoder checkpointed at **every** interior
boundary against a hand-computed total.

**Intended parse.** Enter at boundary 0 in `E0("")` (CDS from the edge), emit
`c` coding bases so the coding state at boundary `c` is `E("A"*(c%3))`, open a
donor at boundary `c`, run a **complete** intron of length `Lintr >= m` (it
materializes into a tail `T(("E","A"*p), r)` after `m` bases), exit at boundary
`c+Lintr` through the acceptor back into CDS, emit `d >= 1` more coding bases,
and leave at boundary `n = c+Lintr+d` via the edge exit prior (partial 3').
`p = c % 3`. The proposal charges, and nothing else,

    common = entry + prefix_prior("")
           + sum_{j<c} cds[j%3][j]                  # CDS before the intron
           + donor[c]
           + sum_{j=c}^{c+Lintr-1} intron[p][j]     # the whole intron
           + acceptor[c+Lintr]
           + sum_{i<d} cds[(p+i)%3][c+Lintr+i]      # CDS after the intron
           + exit                                   # partial-3' edge exit

    partition Z = common + dur.log_prob(p, Lintr)
    viterbi   V = common + max_r [log_pi(p,r) + log_1mq(p,r) + (Lintr-m)*log_q(p,r)]

`dur.log_prob(p,L) = logsumexp_r[log_pi + log_1mq + (L-m)*log_q]` is the
full-intron duration mixture. Unlike the censored exit (lenin-0061), the tail
materializes, so the mixture **does** appear -- `log_pi` at the jump into the
tail, `(Lintr-m)` copies of `log_q` for the tail continuations, and `log_1mq`
released at the acceptor exit -- the exact contrast lenin-0061 set up.

**Results (seed 20260918, deterministic).** **216** cases pass over `m` in
{1,2,3,4} (including the `m == 1` donor-straight-to-tail path), `R` in {1,2,3},
donor phase `p = c%3` for `c` in {1,2,3}, `Lintr` in {m, m+1, m+2}, and `d` in
{1,2}. For every case both decoders and the delayed decoder with
`seams=range(1,n)` reproduce the closed-form partition and Viterbi to
**7.1e-15** max absolute error, and all three trace the identical single chain:
`partial_5` and `partial_3` set, CDS segments exactly `[(0,c,prefix 0),
(c+Lintr,n,prefix p)]` -- the codon that opened at phase `p` completes only
after the acceptor -- and one intron `[c, c+Lintr)` in phase `p` carrying the
argmax component `r_best`. The delayed decoder's `tail_exits` is **empty**
(the donor fully materialized; no censored `I(c,k)` pending at `n`), the
complement of lenin-0061 where it was the sole exit.

**Interior-seam edge suppression** (proposal 3.3), which lenin-0061 flagged
next. Control 4 takes an unmasked all-`A` CDS-only lattice with random finite
scores in all eleven channels and checkpoints **every** interior boundary. If
a seam wrongly offered `E0`/`J` entry or an edge exit, a mid-sequence path
would become legal and add mass, so both partition and Viterbi must be
**unchanged** by seaming; they are (< 1e-9), and the reference (which has no
seam concept) agrees with the seamless delayed run. This certifies that seams
add no partial entry/exit, not merely that two seamed runs agree.

Three more controls confirm the oracle is not vacuous. With `edges=None` both
decoders give partition `-inf` and no chains (the `E0` entry and the edge exit
both vanish, so an interior spliced parse with two partial ends has no legal
path). Bumping one live intron emission by 1.7 shifts the delayed partition by
exactly 1.7. Masking the sole acceptor removes the exit into CDS and gives
`-inf`.

**Scope.** A score/normalization oracle for the acceptor-mediated exit of a
complete intron back into CDS (tail `T(c,r)` -> acceptor -> ordinary coding),
with `E0` edge entry and edge exit, plus the interior-seam suppression of edge
entry/exit on an ordinary CDS parse. Genetic code table 1, all-`A` sequences
(so `permitted_bases` is a singleton and no base prior enters). It does not
test the acceptor exit into a **stop** or **initiator** completion across the
seam, ambiguous (IUPAC) bases through the splice, multiple introns in one
chain, learned emissions, autograd/loss, the crop hazard (engels-0046),
source-data joins (stalin/engels), held-out accuracy, or throughput. Committed
grammar suite still green: **36** tests, 3.96 s. No implementation files
changed; run from repo root with `PYTHONPATH=. python3 -B` on the scratch
below.

```python
"""From-spec closed-form oracle for the acceptor-mediated intron exit into CDS
(a complete intron that materializes into a tail T(c,r) and splices back into
the coding chain -- a codon crossing an intron), and the interior-seam
suppression of edge entry/exit. lenin tick, seed 20260918.

Method (lenin-0060/0061 style): mask every score cell to -inf except the exact
cells the one intended parse charges, so a single path survives, and check that
both decoders -- and the delayed decoder checkpointed at every interior
boundary -- reproduce a total computed independently from the proposal's
formulas. Certifies the ABSOLUTE score, not just cross-decoder agreement.

Intended parse: enter at boundary 0 in E0("") (CDS from the edge), emit c
coding bases so the coding state at boundary c is E("A"*(c%3)), open a donor at
boundary c, run a COMPLETE intron of length Lintr >= m (materializes into a
tail T(("E","A"*p),r) after m bases), exit at boundary c+Lintr via the acceptor
back into CDS, emit d>=1 more coding bases, and leave at boundary n via the
edge exit prior (partial 3'). p = c % 3. The proposal charges, and nothing else:

  common = entry + prefix_prior("")
         + sum_{j<c} cds[j%3][j]                       # CDS before the intron
         + donor[c]
         + sum_{j=c}^{c+Lintr-1} intron[p][j]          # the whole intron
         + acceptor[c+Lintr]
         + sum_{i<d} cds[(p+i)%3][c+Lintr+i]           # CDS after the intron
         + exit                                        # partial-3' edge exit

  partition Z = common + dur.log_prob(p, Lintr)
  viterbi   V = common + max_r [log_pi(p,r)+log_1mq(p,r)+(Lintr-m)*log_q(p,r)]

dur.log_prob(p,L) = logsumexp_r[log_pi+log_1mq+(L-m)*log_q] is the full-intron
duration mixture; unlike the censored exit (lenin-0061) the tail materializes,
so the mixture DOES appear. The parse crosses the intron mid-codon whenever
p != 0, so the codon that opened at phase p completes only after the acceptor:
the future adapter must build codon sites from the spliced path, never trim by
row phase (engels-0052: 13 split starts / 18 split stops on the C. elegans
train panel; 78,411 coding bases would be lost by naive phase trimming)."""
import math, platform, resource, time
from math import log, isinf

from model.grammar.reference import (ReferenceDecoder, DurationMixture,
    EdgePrior, prefix_prior)
from model.grammar.delayed import DelayedEntryDecoder
from model.grammar.scores import Scores
from model.grammar.codes import TABLES

NEG = float("-inf")
cpu0, wall0 = time.process_time(), time.monotonic()


def masked(n):
    return Scores(n, u=[NEG] * n, cds=[[NEG] * n for _ in range(3)],
                 intron=[[NEG] * n for _ in range(3)],
                 start=[NEG] * n, stop=[NEG] * n, donor=[NEG] * n,
                 acceptor=[NEG] * n)


def rand(rng):
    return rng.uniform(-3.0, 3.0)


def make_dur(m, R, rng):
    pi = tuple(tuple(v / s for v in row)
               for row, s in ((r, sum(r)) for r in
                              ([rng.uniform(0.2, 1.0) for _ in range(R)] for _ in range(3))))
    q = tuple(tuple(rng.uniform(0.15, 0.85) for _ in range(R)) for _ in range(3))
    return DurationMixture(m=m, pi=pi, q=q)


def build(c, Lintr, d, m, R, entry, exit, rng):
    """c CDS bases, a complete intron of length Lintr, then d CDS bases; n = c+Lintr+d."""
    n = c + Lintr + d
    x = "A" * n                              # 'AAA' (Lys) is never a stop under table 1
    sc = masked(n)
    p = c % 3
    total = entry + prefix_prior("") + exit
    for j in range(c):                        # CDS before the intron (phases 0..)
        v = rand(rng); sc.cds[j % 3][j] = v; total += v
    dv = rand(rng); sc.donor[c] = dv; total += dv        # the one live donor
    for j in range(c, c + Lintr):             # the whole intron, phase p
        v = rand(rng); sc.intron[p][j] = v; total += v
    av = rand(rng); sc.acceptor[c + Lintr] = av; total += av   # the one live acceptor
    for i in range(d):                        # CDS after the intron, prefix (p+i)%3
        t = c + Lintr + i; ph = (p + i) % 3
        v = rand(rng); sc.cds[ph][t] = v; total += v
    dur = make_dur(m, R, rng)
    edges = EdgePrior(entry, exit)
    z = total + dur.log_prob(p, Lintr)
    v_ = total + max(dur.log_pi(p, r) + dur.log_1mq(p, r)
                     + (Lintr - m) * dur.log_q(p, r) for r in range(R))
    r_best = max(range(R), key=lambda r: dur.log_pi(p, r) + dur.log_1mq(p, r)
                 + (Lintr - m) * dur.log_q(p, r))
    return x, sc, dur, edges, z, v_, p, r_best


def close(a, b, tol=1e-9):
    if isinf(a) or isinf(b):
        return a == b
    return abs(a - b) < tol


def shape(chains):
    assert len(chains) == 1
    ch = chains[0]
    cds = [(s.start, s.end, s.prefix_len) for s in ch.cds()]
    intr = [(s.start, s.end, s.prefix_len, s.component) for s in ch.introns()]
    return (ch.partial_5, ch.partial_3, ch.uncertain, cds, intr)


def main():
    import random
    rng = random.Random(20260918)
    cases = passed = 0
    max_err = 0.0
    for m in (1, 2, 3, 4):
        for R in (1, 2, 3):
            for c in (1, 2, 3):               # p = c%3 in {1,2,0}
                for Lintr in (m, m + 1, m + 2):
                    for d in (1, 2):
                        entry, exit = log(0.3), log(0.4)
                        x, sc, dur, edges, z, v_, p, r_best = build(
                            c, Lintr, d, m, R, entry, exit, rng)
                        ref = ReferenceDecoder(TABLES[1], dur, edges)
                        dl = DelayedEntryDecoder(TABLES[1], dur, edges)
                        n = len(x)
                        seams = list(range(1, n))

                        zr, zd = ref.partition(x, sc), dl.partition(x, sc)
                        zds = dl.partition(x, sc, seams=seams)
                        vr, cr = ref.viterbi(x, sc)
                        vd, cd = dl.viterbi(x, sc)
                        vds, cds_ = dl.viterbi(x, sc, seams=seams)

                        for got in (zr, zd, zds):
                            assert close(got, z), (m, R, c, Lintr, d, "Z", got, z)
                            max_err = max(max_err, abs(got - z))
                        for got in (vr, vd, vds):
                            assert close(got, v_), (m, R, c, Lintr, d, "V", got, v_)
                            max_err = max(max_err, abs(got - v_))

                        sh = shape(cr)
                        assert shape(cd) == sh and shape(cds_) == sh, (m, R, c, Lintr, d)
                        p5, p3, unc, cdssegs, intrsegs = sh
                        assert p5 and p3 and not unc, (m, R, c, Lintr, d, sh)
                        # a codon crossing the intron: two CDS segments spliced,
                        # one materialized intron in phase p with the best component
                        assert cdssegs == [(0, c, 0), (c + Lintr, n, p)], (m, R, c, Lintr, d, cdssegs)
                        assert intrsegs == [(c, c + Lintr, p, r_best)], (m, R, c, Lintr, d, intrsegs)
                        # the donor fully materialized: no censored tail_exits at n
                        assert dl._run(x, sc, viterbi=False)[3] == {}, (m, R, c, Lintr, d)
                        cases += 1
                        passed += 1

    # --- controls: the oracle is not vacuous ---
    rng2 = random.Random(4242)
    args = (2, 5, 2, 4, 2, log(0.3), log(0.4))     # c,Lintr,d,m,R,entry,exit
    x, sc, dur, edges, z, v_, p, r_best = build(*args, rng2)

    # 1. no edges: the E0 entry (and the edge exit) vanish -> no path -> NEG
    for cls in (ReferenceDecoder, DelayedEntryDecoder):
        d0 = cls(TABLES[1], dur, edges=None)
        assert d0.partition(x, sc) == NEG and d0.viterbi(x, sc) == (NEG, []), cls

    # 2. sensitivity: bumping one live intron emission shifts the partition by delta
    x, sc, dur, edges, z, v_, p, r_best = build(*args, rng2)
    delta = 1.7
    sc.intron[p][3] += delta
    assert close(DelayedEntryDecoder(TABLES[1], dur, edges).partition(x, sc), z + delta)

    # 3. killing the sole acceptor removes the exit into CDS -> NEG
    x, sc, dur, edges, *_ = build(*args, rng2)
    sc.acceptor[2 + 5] = NEG
    assert DelayedEntryDecoder(TABLES[1], dur, edges).partition(x, sc) == NEG

    # 4. interior-seam edge SUPPRESSION on an unmasked CDS-only parse: a seam must
    #    offer no partial entry or exit, so seaming every interior boundary must
    #    not create a shorter/mid-sequence path and must leave Z and V unchanged.
    rng3 = random.Random(99)
    n = 9
    csc = Scores(n, u=[rand(rng3) for _ in range(n)],
                 cds=[[rand(rng3) for _ in range(n)] for _ in range(3)],
                 intron=[[rand(rng3) for _ in range(n)] for _ in range(3)],
                 start=[rand(rng3) for _ in range(n)], stop=[rand(rng3) for _ in range(n)],
                 donor=[rand(rng3) for _ in range(n)], acceptor=[rand(rng3) for _ in range(n)])
    cx = "A" * n
    dl3 = DelayedEntryDecoder(TABLES[1], make_dur(3, 2, rng3), EdgePrior(log(0.3), log(0.4)))
    all_seams = list(range(1, n))
    assert close(dl3.partition(cx, csc), dl3.partition(cx, csc, seams=all_seams)), "seam entry/exit leak"
    assert close(dl3.viterbi(cx, csc)[0], dl3.viterbi(cx, csc, seams=all_seams)[0]), "seam viterbi leak"
    # and the reference (no seam concept) agrees with the seamless delayed run
    ref3 = ReferenceDecoder(TABLES[1], dl3.dur, dl3.edges)
    assert close(ref3.partition(cx, csc), dl3.partition(cx, csc)), "ref/delayed disagree on CDS parse"

    print("PASS")
    print(f"cases={cases} passed={passed} max_abs_err={max_err:.3e}")
    print(f"python={platform.python_version()} "
          f"cpu_s={time.process_time()-cpu0:.4f} wall_s={time.monotonic()-wall0:.4f} "
          f"peak_rss_kib={resource.getrusage(resource.RUSAGE_SELF).ru_maxrss}")


if __name__ == "__main__":
    main()
```
