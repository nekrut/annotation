## A semiring-ordering check the prior verifications did not run

stalin ([stalin-0061](20260919T003714Z-stalin-0061.md)) and I
([lenin-0064](20260919T000726Z-lenin-0064.md)) checked that every committed
numerator score is *finite*; engels checked *identity/source* provenance.
None checked the one relation the two scores must satisfy by construction.
Each result reports `viterbi` (best single parse, a max-plus quantity) and
`log_partition` (logsumexp over all parses). Because logsumexp(x) = max(x) +
log(Σ exp(x−max)) and that second term is ≥ 0, the decoder must always emit
`log_partition ≥ viterbi`. A negative margin would prove a decoder bug
(mismatched semirings, a path dropped from the partition, or an emission
counted in one pass but not the other), independent of whether the inputs
were the admitted ones.

Result over all 10 committed `numerator-check/*.json` (manifest MD5s
reverified against summaries first):

| Quantity | Value |
|---|---:|
| Results checked | 100 |
| Ordering violations (`log_partition < viterbi`) | **0** |
| Global margin range `log_partition − viterbi` | **[0.0, 2.98]** |
| Median margin | 0.47 |

The invariant holds everywhere, so the committed scores are internally
consistent as a (logsumexp, max) pair, not just individually finite. This
corroborates the prior finiteness/identity checks from a new direction: a
report could pass every existing check with silently swapped or mis-summed
scores, and this ordering test would still catch it.

## One exact-equality window worth an explicit test in A

The global minimum margin is **0.0 bit-for-bit**, at
`rna-NM_011422.4` in *Mus musculus* (`NC_000071.7`, +, window 3710 bp,
1 intron): `log_partition == viterbi == 36908.25519273038`. Equality is
legitimate — it means the window admits effectively one feasible parse, so
the best path carries all posterior mass — but it is the degenerate floor of
the invariant, and floating-point work near it is where a `<`-vs-`<=`
regression would first surface. Two other species sit just above the floor
(*Danio* 5.8e-11, *Xenopus* 7.1e-9), consistent with near-unique parses, not
error.

Recommendation for A's checker integration (adding to, not overriding,
engels's source-provenance and stalin's result-metadata contracts): assert
`log_partition >= viterbi` for every result and treat exact equality as a
flagged *unique-parse* case (posterior 1.0 on the best path) rather than a
numerical fault, so a future semiring regression fails loudly instead of
producing plausible-looking but inconsistent scores.

## Reproduction and accounting

Run from the repository root with `python3 -B`; reads only committed
manifests and reports.

```python
import csv,gzip,hashlib,io,json,math,platform,resource,time
from pathlib import Path
cpu0,wall0=time.process_time(),time.monotonic()
root=Path("model/labels/manifests"); nc=root/"numerator-check"
per=[]; margins=[]; total=0; viol=[]; zeros=[]
for p in sorted(nc.glob("*.json")):
    sm=json.loads((root/(p.stem+".summary.json")).read_text())
    raw=(root/sm["manifest"]).read_bytes()
    assert hashlib.md5(raw).hexdigest()==sm["manifest_md5"]
    d=json.loads(p.read_text())
    sp=[]
    for r in d["results"]:
        lp,vit=r["log_partition"],r["viterbi"]
        assert math.isfinite(lp) and math.isfinite(vit)
        m=lp-vit; total+=1; margins.append(m); sp.append(m)
        if m< -1e-9: viol.append((p.stem,r["transcript"],lp,vit,m))
        if m==0.0: zeros.append((p.stem,r["transcript"],lp))
    per.append(dict(species=p.stem,n=len(d["results"]),
        min_margin=min(sp),max_margin=max(sp)))
margins.sort()
assert total==100 and viol==[]
assert margins[0]==0.0 and all(m>=0 for m in margins)
print(json.dumps(dict(results_checked=total,violations=viol,
    exact_equality=zeros,global_min=margins[0],global_max=margins[-1],
    median=margins[len(margins)//2],per_species=per,
    python=platform.python_version(),cpu_seconds=time.process_time()-cpu0,
    wall_seconds=time.monotonic()-wall0,
    peak_rss_kib=resource.getrusage(resource.RUSAGE_SELF).ru_maxrss),indent=1))
```
