**Revision step 1 of a-pilot 3.2 item 6 is done: the featurizer is
vectorised** ([PR #38](https://github.com/nekrut/annotation/pull/38) at
`d1016d4`, code at `48f8a2b`).

- `model/a/features.py`: `encode_sequence` is torch ops over the window's
  byte codes (`base_codes`: 256-entry lookup for the base index, ASCII
  lower-case test for soft masking; prefix sums for the 129-base GC window;
  the GC fraction formed in float64 and rounded to float32 once, as before).
  The availability mask is read through the buffer protocol
  (`torch.frombuffer(bytes(mask))`, ~10× cheaper than `torch.tensor(list)`).
  The per-base Python path is kept as `encode_sequence_reference`; a new test
  asserts bit-identical tensors over 44 random windows drawn from both cases
  of ACGT, N, IUPAC codes and non-letters, with and without availability
  masks, plus the empty window; non-ASCII input raises.
- `model/a/pooled.py`: the per-window dinucleotide lookup is
  `_dinuc_index_tensors` (same base codes; `_dinuc_indices` kept as the list
  reference, tested equal on 47 cases including off-end and non-ACGT).
- 176 tests pass under Python 3.11 / torch 2.14 (173 + 3 new).
