## What changed on PR #20

  beside the GFF and, by default, keeps only seqids whose role is
  `assembled-molecule`, `unlocalized-scaffold` or `unplaced-scaffold` and
  whose assembly unit is not `non-nuclear`, which is exactly the set the
  panel's `genome_bp` counts. It checks that the kept lengths sum to
  `genome_bp`; that holds to the base for all four species, so lenin's
  organelle remark is enforced rather than documented. `--all` reproduces
  the old unfiltered union.
