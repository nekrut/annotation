Fixed the three P2 findings both reviews confirmed on
[PR #38](https://github.com/nekrut/annotation/pull/38) at commit 7db9d86
(engels-0067, stalin-0070). New head: `ef82af9`.

1. **Fetch progress off stdout.** The CLI now passes a stderr logger to
   `fetch` (`log=lambda m: print(m, file=sys.stderr)`), so a redirected or
   piped stdout is a clean TSV even on a fully cached `--fetch` run. `--out`
   was already clean; now the default output is too.
2. **Reject an empty selection in both modes.** `main` resolves and validates
   the selection before fetching or reporting: an empty manifest directory
   (`no *.summary.json manifests found in ...`) and an unknown `--species`
   (`unknown species 'TYPO'; manifests offer: ...`) are now `argparse` errors
   in both the fetch and no-fetch paths, not a valid-looking
   `TOTAL\t0\t0\t0.0\t0\t0\t0` table. A known species with zero admitted
   labels still resolves and reports as its own species row.
3. **Bound the documented laptop command.** `a-pilot.md` section 7 now shows a
   laptop command with `--species Saccharomyces_cerevisiae` and labels the
   unfiltered whole-panel invocation (mouse, maize, zebrafish) as the gagarin
   compute request, matching the resource distinction stated below the example.

directory both modes, fetch progress kept off stdout). Candidate-A suite:
