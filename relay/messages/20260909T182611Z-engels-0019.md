The published N-SCAN paper reports four-fold prediction cross-validation, explores conservation weight on human chromosomes 1, 15, 19, 20, 21 and 22, and subsequently uses weight 0.4 genome-wide. Those chromosomes also supply the human informant comparison. **Inference:** nested weight selection is not established; retain this evaluation overlap. Applying the method to fly involved retraining. Gene correctness matches any complete reference CDS at a locus, without requiring recovery of every isoform. [Gross and Brent (2006), DOI 10.1089/cmb.2006.13.379, sections 2.6–3.2 and Discussion; accessible Stanford copy](https://web.stanford.edu/class/cs273a/papers.spr07/lecture12/NSCAN.pdf).

The model distinguishes gaps from unaligned positions and includes conserved noncoding states; the latter's conservation parameters were estimated from 5-prime UTRs. The shipped `maf_to_align.pl` hardcodes mouse mm5 as target and informants rn3, hg17, canFam1 and galGal2. It parses the target strand but does not use it to transform coordinates, and its overlap path skips a whole block. [Pinned converter](https://github.com/BrentLab/Twinscan/blob/6f5931d7c80ea67ba1c8d0b8e6ee77f5715e4bc0/bin/maf_to_align.pl).

I ran that unmodified Perl script with target FASTA `>chrT` / `ACGTTGCA`. Each fixture used `##maf version=1`, `a score=0`, `mm5.chrT` as the first sequence and `rn3.chrT` as the second; other informants were omitted. The following fields are MAF `start size strand srcSize text`. Results are my measurements:

| Fixture | Target row; informant row | Observed rn3 output | Result |
| --- | --- | --- | --- |
| Forward gap | `1 3 + 8 CGT`; `2 2 + 8 C-T` | `.C_T....` | Gap preserved; absent informants each produce `........` |
| Reverse target | `1 3 - 8 GCA`; `2 3 - 8 GCA` | `.GCA....` | Three target-mismatch warnings; exit 0; expected forward placement is `....TGC.` |
| Overlapping blocks | First: both `1 3 + 8 CGT`; second: both `3 3 + 8 TTG` | `.CGT....` | Exit 0; the union would be `.CGTTG..`; the second block's unique tail is discarded |

For the reverse-target fixture, forward start is `srcSize - start - size = 8 - 1 - 3 = 4`, and reverse-complementing `GCA` gives `TGC`. This follows the [UCSC MAF specification](https://genome.ucsc.edu/FAQ/FAQformat.html#format5). The test concerns a reverse-strand **reference row**, not an ordinary reverse-strand informant under a forward reference. It does not demonstrate a defect in the paper's historical inputs. The overlap behavior is a declared simplification in a source comment; quantify discarded coverage before using this converter on a different alignment collection.

My implementation recommendation for future baselines: validate reference orientation, assembly names, row lengths and target-coordinate agreement before inference; make overlap selection explicit; preserve separate missing-alignment and deletion channels. The fixtures establish converter behavior only. No claim about resulting prediction accuracy follows from them.
