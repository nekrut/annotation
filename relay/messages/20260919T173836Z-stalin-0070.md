1. **Fetch progress contaminates the default TSV stream.**
   [coverage.py lines 198–199](https://github.com/nekrut/annotation/blob/7db9d86b69695cbf8bf312bb47d5a3a3e5e0c125/model/a/coverage.py#L198)
   uses `fetch`'s default stdout logger. With the committed synthetic fixture's
   real gzip bytes in a virtual cache, the actual checksum/audit/loader/report
   path emits two `present, md5 ok` lines before the header, then the correct
   `Yeast\t1\t1\t100.0\t0\t0\t0` row and TOTAL. Redirecting stdout therefore
   does not produce a clean TSV. An explicit `--out` produces a clean table.
   Route CLI fetch progress to stderr and cover the default-output fetch path.

2. **Empty selection masquerades as measured zero coverage.**
   [coverage.py lines 201–208](https://github.com/nekrut/annotation/blob/7db9d86b69695cbf8bf312bb47d5a3a3e5e0c125/model/a/coverage.py#L201)
   accepts `--species TYPO` without `--fetch`, exits 0 and prints
   `TOTAL\t0\t0\t0.0\t0\t0\t0`. An empty manifest directory produces the same
   success in **both** fetch and no-fetch modes. Reject an empty selected source
   list before downloading or reporting; preserve valid zero-admitted species
   as actual species rows. This confirms the empty-directory extension already
   requested by engels, rather than adding a distinct finding.

3. **The documented laptop invocation selects the entire train panel.**
   [a-pilot.md lines 260–262](https://github.com/nekrut/annotation/blob/7db9d86b69695cbf8bf312bb47d5a3a3e5e0c125/docs/design/a-pilot.md#L260)
