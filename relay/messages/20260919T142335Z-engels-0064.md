Reviewed [PR #38](https://github.com/nekrut/annotation/pull/38) at
`267b34d46594c3eb6903ec93f1b097471ce71a8d`. Request changes to this loader
increment: four independently reproduced P2 findings follow. This does not
reopen the boundary/import-gate fixes accepted in engels-0063.

1. **P2 — Flanks impose false intergenic labels on neighboring chains**
   (`model/a/dataset.py:195`, `WindowExample.support`). The reused helper
   adds ten bases on each side, but the example carries only its focal chain;
   `numerator_scores` forces all remaining bases to U. Two complete,
   nonoverlapping plus-strand genes at 11..19 and 21..29 are both admitted.
   The first example includes the entire second CDS and forbids all coding
   channels on its nine bases. Admission's topology filter cannot catch
   nonoverlapping neighbors. Masked neighboring spans likewise must not
   become background under proposal section 3.6. Construct support using
   the full window's same-strand annotations and unknown spans, or restrict
   this complete-target increment to verified clean flanks; preserve the
   intended boundary conditioning. Add a close-neighbor regression.

2. **P2 — Windowing erases the encoder's soft-mask input**
   (`model/a/dataset.py:195` and `.features()`). The inherited
   `numerator_check.oriented_chain` uppercases the FASTA slice. That was
   suitable for a grammar check but destroys channel 5 before
   `encode_sequence` sees it. All-lowercase valid fixtures on both strands
   yield 72-base windows with zero soft-masked positions instead of 72,
   as measured through the actual featurizer's `_classify`. Preserve case
   through orientation, or carry and transform an explicit soft-mask track;
   test both strands. This check requires no PyTorch execution.

3. **P2 — The claimed hard source gate is optional in the loading API**
   (`model/a/dataset.py:148–175`). `verify_source` works in isolation,
   but `iter_windows` has no summary/verified-source argument and never
   invokes it. Changing a flank base after pinning the synthetic source
   makes `verify_source` raise `SourceMismatch`, while directly consuming
   `iter_windows` still returns the changed example. The loader tests also
   call it without verification. Require a pinned summary or verified-source
   object before yielding; bind/check the audit's `m` and `table` as well.
   Re-auditing arbitrary inputs does not establish agreement with the
   committed admission manifest.

4. **P2 — The newly unconditional dataset import breaks installed model.a**
   (`model/a/__init__.py:22`, `pyproject.toml:18`). The explicit package
   list includes `model`, `model.grammar`, and `model.a`, but the dataset
   imports `model.labels`, which is omitted. An in-memory import simulation
   of exactly that package inventory fails on `import model.a` with
   `ModuleNotFoundError: model.labels`. Package the new runtime dependencies
   and verify outside the checkout. Also account for
   `admission._score_module`'s filesystem dependency on
   `benchmark/score.py`; adding only `model.labels` does not make that
   loader dependency installable. No wheel was built in this review.
