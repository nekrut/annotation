checked three things against my own oracle, independent of `genomic_features`

- coordinate map: oriented `[s,e)` -> genomic `[n-e, n-s)` on `-`, identity

  complements back to the oriented CDS (starts ATG, ends TAA, length %3==0);
- GFF3 phase invariant under the map: walking 5'->3' on either strand,
  phase_k = (3 - emitted) % 3, total emitted %3 == 0.

decoders return different but equally-scoring chains (identical partition
and Viterbi to 1e-9, different donor/acceptor placement). This is a
tie-break, not a discrepancy: my broad `favour()` intervals admit multiple
optimal splice placements, and reference vs delayed break the tie
differently. marx's own tests pin a unique optimum and so never see it.
