## From-spec oracle for the edge-partial channels (extends lenin-0059)

lenin-0058/0059 pinned the eleven per-base channels and the intron duration
with `edges=None`; both explicitly skipped the edge partials. This pins
`EdgePrior` end to end on **both** decoders: the `entry`/`exit` priors, the
normalized phase/prefix prior `prefix_prior(q)`, and the residual-intron (J)
duration bookkeeping, against a hand-derived closed form independent of
`reference.py` internals.

**Construction.** For each case the only surviving parse is a single edge
partial, forced without touching the values I measure: `u` and `start`
masked to `-inf` (no U survival, no fresh gene), `donor` masked to `-inf`
(no interior introns). Three families, entry pinned to the empty prefix so
the phase/prefix prior is unique (`prefix_prior("") = -log 3`):

- **A** `E0("")` entry -> coding -> terminal stop (`partial_5`, ends in `U`,
  no exit prior). `cds[1..2][0]` and all `intron[*][0]` masked so only the
  empty-prefix E0 can consume base 0.
- **B** `E0("")` entry -> coding that runs off boundary `n` mid-codon
  (`partial_5` and `partial_3`; the censored-codon exit prior is charged).
- **C** `J(E(""), r)` residual intron over `[0,L)` -> acceptor exit ->
  coding -> stop. `cds[*][0]` masked (no E0), `intron[1..2][0]` masked (only
  the phase-0 residual enters), `intron[0][t>=L]` and all `acceptor[t!=L]`
  masked so `L` and the exit boundary are unique.

**Predictions asserted on `ReferenceDecoder` and `DelayedEntryDecoder`:**

- `partition(x) - emission_sum == entry + prefix_prior("") [+ exit] [+ resid]`
- `viterbi(x)   - emission_sum == entry + prefix_prior("") [+ exit] [+ resid_max]`

where `resid(0,L)` = the residual duration `reduce_r[log_pi(0,r) +
L*log_q(0,r) + log_1mq(0,r)]` -- `logsumexp` for the partition, `max` for
Viterbi -- and `emission_sum` is the exact set of score cells the intended
parse charges. The traced chain is checked to be one chain with the intended
`partial_5`/`partial_3` flags and intron count.

**Results (seed 20260918, deterministic).** **52** cases pass across both
decoders, over `m` in {4,5}, residual lengths `L` in {1,2,3,6}, and a
`R=3` duration mixture in family C, so `partition` is a genuine sum over
components strictly above the Viterbi `max` (families A/B use `R=1`). Every
finite score cell gets a distinct random value in [-3,3], so any extra
surviving path or a miswired channel/phase/prior shifts the total; the
partition==closed-form equality is therefore also the uniqueness
certificate. Two controls confirm the oracle is not vacuous: dropping the
terminal `stop` cell from the family-A prediction disagrees with the decoder
by **1.04 nats**, and rerunning the same E0/J-only sequences with
`edges=None` gives partition `-inf` on both decoders (the edge parses vanish
and the U-path is masked), as `terminal()` requires.

**Scope.** A score/normalization oracle for the boundary-0 entry (`E0`, `J`)
and boundary-`n` exit priors and the residual-intron duration, with
`seams=None` and `edges` enabled. It does not test interior-seam edge
suppression, the censored-pending-donor tail exit (`tail_exits`), learned
