## Remaining section 3.3 gap: traceback still retains all boundaries

In [delayed.py at this revision](https://github.com/nekrut/annotation/blob/bfc3ca4b5d0db2b1fdf62a87fc56699e80732938/model/grammar/delayed.py),
`_run_chunk` returns a score dictionary and backpointer dictionary for
every boundary. `_run` concatenates all these into `layers` and `back`
across every seam. Public `viterbi` then follows this full retained history;
it never reloads a checkpoint and recomputes a previous block. The
mandatory-intron expansion in its traceback reconstructs skipped I states
but does not replay the earlier block's dynamic program.

The forward checkpoint handoff is working in the checks above. The
bounded-memory traceback replay required by proposal 3.3 and the
T-human-013 goal is still unimplemented. In particular, seams do not
reduce retained history; even `partition` retains every score layer.

With fixed m=20, R=3 and seams every 64 bases, the retention probe below
returns:

| N | Score layers, either mode | Retained score entries, either mode | Viterbi backpointer entries | Forward chunk calls |
|---:|---:|---:|---:|---:|
| 256 | 257 | 34,201 | 34,116 | 4 |
| 512 | 513 | 69,785 | 69,700 | 8 |
| 1,024 | 1,025 | 140,953 | 140,868 | 16 |

Both modes also retain N+1 backpointer dictionaries (empty in forward
mode). Instrumenting public `viterbi` confirms exactly one forward
`_run_chunk` per block and no repeated block calls. These are retained
object-entry counts from tiny inputs, not chromosome RAM measurements.

Before considering 3.3 complete, retain sparse checkpoints and only the
working block's traceback; revisit checkpoints to reconstruct preceding
blocks with identical emissions. Pending donor jumps must reach the true
donor boundary even across multiple blocks. A regression should discard
prior block scratch before reconstruction and compare scores/chains while
checking that retained traceback is bounded by block size. The existing
seam tests exercise forward resume and traceback through retained history.
The proposed chromosome memory accounting cannot yet be attributed to
this implementation.

### Two-intron closed-form check

```python
import itertools, math
from model.grammar import ReferenceDecoder, DelayedEntryDecoder, DurationMixture, Scores
NEG = -math.inf
pi = ((.6,.3,.1),(.2,.3,.5),(.3,.5,.2))
q = ((.15,.55,.95),(.2,.6,.9),(.1,.5,.8))
maxerr = 0.0
checks = 0
for m,e1,e2 in itertools.product((1,2,20),(0,1,7),(0,1,7)):
    l1,l2 = m+e1,m+e2
    x = "A" + "C"*l1 + "TGAAATA" + "C"*l2 + "A"
    n = len(x)
    introns = [(1,1+l1),(8+l1,8+l1+l2)]
    sc = Scores.zeros(n)
    for _,arr in sc.channels():
        arr[:] = [NEG]*n
    sc.start[0] = sc.stop[-1] = 0.
    for p in range(3):
        for t in range(n):
            if any(a <= t < b for a,b in introns):
                sc.intron[p][t] = 0.
            else:
                sc.cds[p][t] = 0.
    for a,b in introns:
        sc.donor[a] = sc.acceptor[b] = 0.
    dur = DurationMixture(m=m,pi=pi,q=q)
    parts = [[math.log(pi[p][r])+math.log1p(-q[p][r])+e*math.log(q[p][r])
              for r in range(3)] for p,e in ((1,e1),(2,e2))]
    wantz = sum(math.log(sum(math.exp(v) for v in row)) for row in parts)
    wantv = sum(max(row) for row in parts)
    wantr = [row.index(max(row)) for row in parts]
    ref = ReferenceDecoder(duration=dur)
    dl = DelayedEntryDecoder(duration=dur)
    outputs = [("reference",ref.partition(x,sc),ref.viterbi(x,sc))]
    for spacing in (None,1,3,7):
        seams = [] if spacing is None else range(spacing,n,spacing)
        outputs.append((spacing,dl.partition(x,sc,seams=seams),
                         dl.viterbi(x,sc,seams=seams)))
    for spacing,z,(v,chains) in outputs:
        assert math.isclose(z,wantz,abs_tol=1e-10), (m,e1,e2,spacing,z,wantz)
        assert math.isclose(v,wantv,abs_tol=1e-10), (m,e1,e2,spacing,v,wantv)
        assert len(chains) == 1
        c = chains[0]
        assert c.spliced(x) == "ATGAAATAA" and not (c.partial_5 or c.partial_3)
        assert [s.gff_phase for s in c.cds()] == [0,2,1]
        assert [(s.start,s.end,s.component) for s in c.introns()] == [
            (a,b,r) for (a,b),r in zip(introns,wantr)]
        maxerr = max(maxerr,abs(z-wantz),abs(v-wantv))
        checks += 1
print("27 pinned two-intron configurations;",checks,
      "decoder/seam-mode checks; max score error",maxerr,
      "; all intervals, phases, components and complete-chain flags match.")
```

### Retention and replay instrumentation

```python
from collections import Counter
from model.grammar import DelayedEntryDecoder, DurationMixture, EdgePrior, Scores

class Probe(DelayedEntryDecoder):
    def __init__(self, **kw):
        super().__init__(**kw)
        self.calls = []
    def _run_chunk(self, x, sc, viterbi, cp, t1):
        self.calls.append((cp.t, t1))
        return super()._run_chunk(x, sc, viterbi, cp, t1)

dur = DurationMixture(m=20, pi=((.2,.3,.5),)*3, q=((.2,.6,.9),)*3)
for n in (256,512,1024):
    x = "ATG" + "C"*(n-6) + "TAA"
    sc = Scores.zeros(n)
    for mode in (False,True):
        dec = Probe(duration=dur, edges=EdgePrior())
        layers, back, _ = dec._run(x, sc, mode, seams=range(64,n,64))
        print(n, mode, len(layers), sum(map(len,layers)),
              len(back), sum(map(len,back)), len(dec.calls))
        del layers, back
    dec = Probe(duration=dur, edges=EdgePrior())
    dec.viterbi(x, sc, seams=range(64,n,64))
    assert dec.calls == [(t,min(n,t+64)) for t in range(0,n,64)]
```
