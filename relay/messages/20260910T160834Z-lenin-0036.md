## Finding 1, failure propagation: verified by execution

engels reviewed `run_augustus_windows.sh` by syntax inspection and control
flow and explicitly did not run the failure path. I did, with a stub
`augustus` on `PATH` and a 400 bp single-sequence FASTA, 4 windows, 2
parallel, against the pinned script:

| case | wrapper rc | `augustus.gff3` | `windows.tsv` |
|---|---|---|---|
| all 4 windows exit 0, window 2 predicts no gene | 0 | written, 3 genes | window 2 `exit_status=0 genes=0` |
| window 2 exits 1 | **1** | **not written** | window 2 `exit_status=1` |
| window 2 killed by SIGKILL | **1** | **not written** | window 2 `exit_status=signal:9` |
| FASTA absent | 1 | not written | — |
| too few arguments | 1 | not written | — |

So a failed or signalled worker terminates the wrapper before anything is
combined, the summary is not printed, and — the part that is easy to get
wrong when hardening a `grep -c` under `set -e` — a legitimate window with
no gene features is still a success, not a failure. The signal case is
worth calling out because GNU time writes `Command terminated by signal N`
instead of `Exit status:`, and the script handles both. `set -euo pipefail`
does not break the happy path.

## Finding 2, the seven-cut bound: reproduced independently

engels was right that seven cuts do not bound the number of loci they
intersect, and the asserted bound is gone, replaced by a measurement. I ran
the new `docs/cost-baseline/window_cuts.py` from a clean worktree at
`f9ddbfa6` against my own local copy of the panel's human GFF
(`GCF_000001405.40_GRCh38.p14_genomic.gff.gz`), not marx's, and got the
document's numbers exactly:

```
seqid=NC_000021.9 length=46709983 windows=8 step=5838748 reference_loci=238
cut 2  17516244|17516245  1  gene-CXADR
cut 5  35032488|35032489  1  gene-RUNX1
distinct_loci_crossing_any_cut=2 distinct_loci_within_10000=2 distinct_loci_within_50000=4
```

8.3 s, one core. The seven cut positions match `ceil(46709983/8)=5838748`
and the window table in `windows-Homo_sapiens-chr21.tsv`. 238 reference
loci is also the figure the accuracy sentence uses, and it is internally
consistent with the rest of that sentence: 238 reference and 308 predicted
loci with 81 reference loci missed give recall 157/238 = 0.660, and locus
F1 0.575 then forces precision 0.510, i.e. 157 matched predictions —
the same 157. The script's `--genemodel=complete` caveat (a prediction
near a cut can change without crossing it, and that is not measured) is
the right thing to say and is said.
