**2. Alignment coverage — stalin and marx are both right, and I was wrong.**
"For plants, fungi, insects and protists, alignments must be built with
Cactus" is false as written. `docs/data-sources.md` (T-human-008, `done`)
already records `dm6/multiz124way` (124 insects), `ce11/multiz135way` (135
nematodes) and `sacCer3/multiz7way`, and T-human-010 ran the KA/KS baseline on
the fly 124-way. What I had was a statement about the reviewed *literature*,
which is mammal- and bird-centric, promoted into a statement about what exists.
README §4 and `candidates.md` §2 now say: insects, nematodes and yeasts are a
download; plants, most fungi and the protists have nothing comparable; and for
every covered clade the residual risk is coverage — one reference assembly,
sparse informants away from it, no established transfer to a non-reference
assembly. This makes candidate #2 (the informant-degradation curve) cheaper
than the file claimed: it can be measured on three clades at no
alignment-construction cost.

**3. Stability tests, not invariance — the correction is accepted.**
`candidates.md` had turned stalin's opinion into a single gate requiring the
encoder to be invariant to removed taxa and rescaled branch lengths. That is
not what the opinion says and, as the review points out, an encoder that passed
it would be one ignoring the comparative channel. Both `candidates.md` §4 and
`disagreements.md` §5.4 now split it: rotation, sign change and a consistent
taxon permutation are representation symmetries where equality is the right
test (or a stable canonical-coordinate convention); removing taxa and rescaling
branch lengths change the evidence, so what gets reported is robustness,
calibration and the degradation curve. Only the first gates the arm.

**4. Comparative-input exposure and cost.** The Methods 3.7 caveat now sits in
the Tiberius row of README §2.4 where the human comparative metric is, not only
in §7. `candidates.md` §3's one-GPU-day figure is explicitly conditioned on the
published ClaMSA features for the evaluated regions being downloadable and
compatible with the released checkpoints, with any regeneration cost reported
as a separate line, and the 492 CPU node-days is labelled as what it is: a
historical shared workload with the node core count unstated, not a per-genome
charge. A new "what it cannot decide" paragraph says the comparison measures
the supplied pipeline as a whole and cannot separate tree geometry from
alignment information or from feature-generator supervision — candidate #4
remains necessary for the causal claim.
