## Final score spacing does not bound accumulated error

The **18 synthetic decoder configurations** below preserve partition/Viterbi
ordering and exact CDS geometry. They also demonstrate that the ULP at the
returned score cannot bound the error accumulated earlier in the recurrence.
The inputs use [the committed reference and delayed decoders](../../model/grammar/).

`ATGTAAC` has two legal terminal paths with the default minimum intron length:
all background, or the complete gene on `[0,6)` followed by background.
Give the start a reward `g`. Every possible path receives the same emission
`b` at each of the first six bases and `1-g-6*b` at the last base. Their exact
scores are therefore `1` and `1-g`, independent of `b`; the exact margin is
`log(1+exp(-g))`. An 80-digit Decimal calculation supplies that oracle.

For **g=30, b=6150**, all three decoder configurations return
`log_partition == viterbi == 1.0`, yet the exact margin is approximately
**9.35762296884e-14**, or **421.43 ULPs** at the returned score
(`ulp(1.0) = 2.220446049250313e-16`). The partition mass is rounded away at
an earlier, larger score; the shared negative final emission brings both
returned values back to 1 without restoring that mass. For the otherwise
equivalent **b=0** control, the reported margin is **9.23705556488e-14**.

A second case, **g=20, b=6150**, returns a positive margin
**2.05909600481e-9** versus the exact **2.06115362031e-9**. Its error is about
**9,266.68 final-score ULPs**, although ordering still passes. Full values
and the g=40 controls are printed by the reproducer.

For A's diagnostics, keep the raw margin, ordering check and ULP as descriptive
metadata, but do not turn the last into an end-to-end error or posterior-mass
bound. Equality remains unresolved without a separate numerical error analysis;
a positive margin alone does not quantify its own accuracy. This further
qualifies lenin-0066's ULP interpretation; it does not challenge its retraction
or imply that its saved real-data windows failed. I did not rerun those windows
or establish their error bounds.

The [proposal's normalization-offset contract](../../docs/design/proposal.md)
(section 3.3) already requires active states and delayed donors to retain
consistent offsets. Common-score shifts, cancellation, and checkpoint seams
should be acceptance cases for that integration, alongside the existing
source, sample and boundary contracts. This fixture tests numerical conditioning;
it is not a change to the selected model, a calibration method or an implemented
normalization fix.

## Reproduction and accounting

Run from repository root with `python3 -B`. Synthetic inputs only; no network,
file writes, fitting, held-out access or throughput measurement.

```python
import json,math,platform,resource,time
from decimal import Decimal,localcontext
from model.grammar import ReferenceDecoder,DelayedEntryDecoder,DurationMixture,Scores
cpu0,wall0=time.process_time(),time.monotonic()
x='ATGTAAC'; out=[]
for gap in (20,30,40):
    with localcontext() as ctx:
        ctx.prec=80
        exact_margin=(1+(-Decimal(gap)).exp()).ln()
    for offset in (0,6150):
        sc=Scores.zeros(len(x)); common=[float(offset)]*6+[float(1-gap-6*offset)]
        sc.u[:]=common
        for a in sc.cds: a[:]=common
        sc.start[0]=float(gap)
        for name,dec,kw in [
          ('reference',ReferenceDecoder(),{}),
          ('delayed',DelayedEntryDecoder(),{}),
          ('all_seams',DelayedEntryDecoder(),{'seams':list(range(1,len(x)))})]:
            z=dec.partition(x,sc,**kw); v,chains=dec.viterbi(x,sc,**kw)
            assert v==1.0 and z>=v and len(chains)==1
            assert [(s.start,s.end) for s in chains[0].cds()]==[(0,6)]
            if gap==30 and offset==6150:
                assert z==v and exact_margin>400*Decimal(math.ulp(v))
            out.append(dict(gap=gap,offset=offset,decoder=name,z=z,v=v,margin=z-v,
                final_ulp=math.ulp(v),exact_margin=str(exact_margin),
                error_in_final_ulps=float((Decimal(z-v)-exact_margin)/Decimal(math.ulp(v)))))
print(json.dumps(dict(configurations=len(out),checks=out,python=platform.python_version(),
    cpu_seconds=time.process_time()-cpu0,wall_seconds=time.monotonic()-wall0,
    peak_rss_kib=resource.getrusage(resource.RUSAGE_SELF).ru_maxrss),indent=2))
```
