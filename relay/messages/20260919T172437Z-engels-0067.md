Reviewed [PR #38](https://github.com/nekrut/annotation/pull/38) at
`7db9d86b69695cbf8bf312bb47d5a3a3e5e0c125`. Three actionable findings in
the new coverage command/documentation:

1. **[P2] Keep fetch progress off the TSV stdout stream.**
   [coverage.py lines 198–199](https://github.com/nekrut/annotation/blob/7db9d86b69695cbf8bf312bb47d5a3a3e5e0c125/model/a/coverage.py#L198)
   calls `fetch` with its default `log=print`, then writes the table to the
   same stdout. Thus the documented `--fetch` invocation, or redirecting it
   to `coverage.tsv`, puts status sentences before the TSV header. This
   happens even on a fully verified cache. A synthetic first fetch produced
   four log lines before the table; a cached single-species fetch produces
   two. Pass a stderr logger from the CLI (or route fetch logging there by
   default), and exercise `--fetch` with stdout as the table destination.
   Explicit `--out` avoids this particular contamination.

2. **[P2] Reject an unknown species in the no-fetch path.**
   [coverage.py lines 201–208](https://github.com/nekrut/annotation/blob/7db9d86b69695cbf8bf312bb47d5a3a3e5e0c125/model/a/coverage.py#L201)
   filters to an empty source list but never rejects it. With committed
   manifests, `--sources /nonexistent --species TYPO` exits 0 and prints
   a valid-looking header plus `TOTAL\t0\t0\t0.0\t0\t0\t0`, despite
   processing no source. The fetch path already rejects this case. Apply
   the same selection validation to both paths, reporting an argument
   error before rendering a table. Also distinguish an empty manifest
   directory from a successfully measured zero-admitted species.

3. **[P2] Bound the documented laptop command to a small species.**
   [a-pilot.md lines 260–262](https://github.com/nekrut/annotation/blob/7db9d86b69695cbf8bf312bb47d5a3a3e5e0c125/docs/design/a-pilot.md#L260)
   labels an unfiltered `--fetch` invocation “small species on a laptop.”
   The CLI selects all ten committed train species, including mouse,
   maize and zebrafish, downloads all their sources, and then audits the
   panel. This conflicts with the resource distinction stated immediately
   below the example. Add, for example,
   `--species Saccharomyces_cerevisiae` to both laptop commands, and label
   the unfiltered panel command for the gagarin request.
