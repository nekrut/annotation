## Source-row phases and split-codon geometry

Fetched the ten **train** GFFs sequentially into memory, verified their
compressed MD5s against [panel.tsv](../../benchmark/panel.tsv), and verified
the [admission manifests](../../model/labels/manifests/) against their
summary checksums and source identities. Joined every admitted representative
by (sequence, strand, transcript), preserving raw CDS rows and ordering
them in transcriptional orientation.

All **179,227 admitted representatives**, comprising **1,098,075 CDS rows**,
pass independently computed row-count, span, CDS-length, phase-continuity,
minimum-gap and terminal-frame assertions. For each row, supplied phase is
`(-(missing_prefix + preceding_CDS_bases)) % 3`; the declared 3'-partial
target is exempt from a complete terminal frame. This verifies geometry
from the source GFF, not the FASTA sequence or the representative-selection
policy.

The audit quantifies two existing [section 3.6](../../docs/design/proposal.md)
adapter requirements:

- **Preserve continuation bases.** There are **479,874 noninitial CDS rows**
  with nonzero phase, across **124,000 admitted chains**. Applying
  `oriented_exon[phase:]` separately to each continuation row would delete
  **752,891 CDS bases**. This is a hypothetical loader mistake, not a bug
  in an implemented A loader. The count sums `min(phase, row_length)`,
  rather than assuming every row is at least as long as its phase.
- **Support split endpoint codons.** **287 admitted chains** have an intron
  inside their first three CDS bases; **125** have an intron inside their
  final three CDS bases with a complete 3' end. These are separate counts,
  not a count of their union. Contiguous genomic triplets alone cannot
  reconstruct those endpoint codons.

A concrete small-row fixture is Drosophila
`(NT_033778.4, -, rna-NM_166691.4)`. Its raw CDS rows, in transcriptional
order, are the following **zero-based half-open** intervals and phases:

```text
[24875764,24875780) phase 0
[24875658,24875659) phase 2
[24875337,24875593) phase 1
[24875164,24875272) phase 0
```

The one-base second row supplies part of a codon that crosses two introns.
It is the only admitted continuation row in this audit with phase greater
than row length. A row-local trimming operation would erase that entire
coding exon. The phase sum is therefore one base larger than the actual
number a Python slice would remove.

Two simple endpoint fixtures from the same audit:
S. cerevisiae `(NC_001134.8, +, rna-NM_001178267.1)` has CDS rows
`[168422,168424), [168808,169376)`, phases 0/1, so its start is split.
Zea mays `(NC_050096.1, +, rna-NM_001151142.3)` has rows
`[47656495,47656839), [47657260,47657261)`, phases 0/1, so its stop is split.

## Reproduction and scope

Run from the repository root with `python3 -B`; this writes no files,
fetches train GFFs only, verifies pins and assertions, and prints species
counts and fixtures. It follows the existing first-parent CDS identity
rule; no claim is made about alternate-parent parsing.

```python
import csv,gzip,hashlib,io,json,platform,resource,time,urllib.request
from collections import defaultdict
from pathlib import Path
from benchmark.fetch import asm_parent
cpu0,wall0=time.process_time(),time.monotonic()
out=[]
for p in sorted(csv.DictReader(open("benchmark/panel.tsv"),delimiter="\t"),key=lambda r:r["species"]):
    if p["split"]!="train": continue
    sp=p["species"]; root=Path("model/labels/manifests")
    path=root/(sp+".manifest.tsv.gz"); summary=json.loads((root/(sp+".summary.json")).read_text())
    assert hashlib.md5(path.read_bytes()).hexdigest()==summary["manifest_md5"]
    assert summary["gff_md5"]==p["md5_gff"]
    with gzip.open(path,"rt") as f: all_rows=list(csv.DictReader(f,delimiter="\t"))
    reps={(r["seqid"],r["strand"],r["transcript"]):r for r in all_rows if r["status"]=="admitted"}
    assert len(all_rows)==summary["representatives"] and len(reps)==summary["admitted"]
    stem=p["ftp_dir"]; url=asm_parent(p["accession"])+"/"+stem+"/"+stem+"_genomic.gff.gz"
    req=urllib.request.Request(url,headers={"User-Agent":"relay-benchmark/0.1 (https://github.com/nekrut/annotation)"})
    with urllib.request.urlopen(req,timeout=30) as response: raw=response.read()
    assert hashlib.md5(raw).hexdigest()==p["md5_gff"]
    cds=defaultdict(list)
    with io.TextIOWrapper(gzip.GzipFile(fileobj=io.BytesIO(raw))) as f:
        for line in f:
            if line.startswith("#"): continue
            v=line.rstrip("\n").split("\t")
            if len(v)<9 or v[2]!="CDS": continue
            a=dict(part.strip().split("=",1) for part in v[8].split(";") if "=" in part)
            tid=(a.get("Parent") or a.get("transcript_id") or a.get("ID") or "%s:%s:%s"%(v[0],v[3],v[6])).split(",")[0]
            key=(v[0],v[6],tid)
            if key in reps: cds[key].append((int(v[3])-1,int(v[4]),int(v[7])))
    assert set(cds)==set(reps)
    c=dict(admitted=len(reps),cds_rows=0,nonzero_continuation_rows=0,affected_chains=0,trimmed_bases=0,phase_exceeds_row_length=0,split_starts=0,split_stops=0)
    examples={}
    for key,r in reps.items():
        rows=sorted(cds[key],reverse=key[1]=="-")
        lengths=[b-a for a,b,h in rows]; total=sum(lengths)
        assert len(rows)==int(r["rows"]) and total==int(r["cds_len"])
        assert (min(a for a,b,h in rows),max(b for a,b,h in rows))==(int(r["cds_start"])-1,int(r["cds_end"]))
        prefix=int(r["missing_prefix"]); consumed=0; affected=False; split_start=False; split_stop=False
        for i,((a,b,h),length) in enumerate(zip(rows,lengths)):
            assert h==(-(prefix+consumed))%3,(sp,key,i,h,prefix,consumed)
            if i:
                pa,pb,_=rows[i-1]; gap=a-pb if key[1]=="+" else pa-b
                assert gap==0 or gap>=summary["m"],(sp,key,gap)
                c["nonzero_continuation_rows"]+=int(h!=0)
                c["trimmed_bases"]+=min(h,length); c["phase_exceeds_row_length"]+=int(h>length); affected|=h!=0
                split_start|=gap>0 and 0<consumed<3 and "partial_5" not in r["reasons"]
                split_stop|=gap>0 and 0<total-consumed<3 and "partial_3" not in r["reasons"]
            consumed+=length
        assert "partial_3" in r["reasons"] or (prefix+consumed)%3==0
        c["cds_rows"]+=len(rows); c["affected_chains"]+=int(affected)
        c["split_starts"]+=int(split_start); c["split_stops"]+=int(split_stop)
        for name,condition in (("split_start",split_start),("split_stop",split_stop),("short_row",any(h>b-a for a,b,h in rows))):
            if condition and name not in examples:
                examples[name]=dict(identity=key,rows_0halfopen_phase=rows)
    item=dict(species=sp,**c,examples=examples)
    out.append(item); print(json.dumps(item),flush=True)
print(json.dumps(dict(totals={k:sum(r[k] for r in out) for k in c},
    python=platform.python_version(),cpu_seconds=time.process_time()-cpu0,
    wall_seconds=time.monotonic()-wall0,peak_rss_kib=resource.getrusage(resource.RUSAGE_SELF).ru_maxrss)),flush=True)
```
