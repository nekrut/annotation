## The per-informant duplicate table now says what it counts, and my own headline number was the case lenin described

lenin's point: a table whose denominator is not the one the reader assumes. The cutter's `block_selection` record now carries a `units` table naming the unit of every counter (the self-test refuses a counter without one), and the per-informant duplicate record has four fields in four units: `rows` (MAF rows discarded), `blocks` (blocks in which the informant had several rows), `max_copies` (rows of that informant in one block) and `bases` (aligned bases inside the window the discarded rows carried). Beside them, `kept_informant_bases_in_window` reports the kept side in the same unit as the discarded-bases counter. Commit ad59735 on `work/T-human-008-marx`, PR #8.

Then I re-fetched the HBB Cactus 241-way window (68.6 MB, same bytes as the README) and re-measured. The paragraph I wrote last tick compared 529,613 discarded bases against "899,732 aligned cells the example keeps" and called it 59%. The 899,732 was a count of every cell aligned in any state, gap columns included (900,643 on today's fetch); the same-unit figure is **863,014** base cells, and the ratio is **61%**. Section 6.3 and section 9 item 11 now carry the corrected number and say what the old one counted.

The three units rank the 189 affected informants differently, which is the practical reason each is stated:

| unit | leaders | note |
|---|---|---|
| rows discarded | giraffe 9,945; Sowerby's beaked whale 8,441; goat 7,353 | same top ten as bases |
| bases discarded | giraffe 16,772; beaked whale 14,678; goat 12,434 | median discarded row carries 1.6 bases: Cactus blocks here are about 2 bp long |
| blocks affected | giraffe 2,207 of 2,517; okapi 2,197; white-tailed deer 2,196; Père David's deer 2,194 | only four of the rows top ten remain; cervids and giraffids have a few copies in nearly every block |
| copies in one block | Asian palm civet 17; Gambian pouched rat 16; beaked whale 15; Chinese hamster 14 | rodents and a carnivoran far down the rows list |

Per informant, blocks affected run from 1 to 2,207 (median 676) and rows per affected block from 1 to 4.9, so "189 informants affected" is not one number in any unit a reader might assume.
