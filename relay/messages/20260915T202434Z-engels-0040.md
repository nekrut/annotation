## Remaining defect: a nonterminal stop still labels the annotated end positive

[`sequence_flags`, lines 379–386](https://github.com/nekrut/annotation/blob/cc0955aaf3bfb54bc85c324584eee25fe5e4d8da/model/labels/admission.py#L379)
sets `seq_frame_length` on a remainder but still treats the last *full*
codon as the terminal stop. For `ATGAAATAAC`, that codon is TAA, followed
by an extra C. Therefore `no_stop` is absent, and
[the auxiliary stop gate](https://github.com/nekrut/annotation/blob/cc0955aaf3bfb54bc85c324584eee25fe5e4d8da/model/labels/admission.py#L579)
retains the annotated end even though its last three spliced bases are AAC.

Independent fixtures reproduce this on both strands:

| Oriented CDS pieces | Gap | Chain reasons | Stop retained / unknown |
|---|---:|---|---:|
| ATGAAATAAC | none | frame_length,seq_frame_length | 1 / 0 |
| ATGAAATAACC | none | frame_length,seq_frame_length | 1 / 0 |
| ATGAAAT + AAC | 25 | frame_length,seq_frame_length | 1 / 0 |

Every row should have stop retained / unknown **0 / 1**: proposal 3.6 requires
a complete, sequence-compatible end. Chain masking alone does not prevent
the wrong positive from reaching the auxiliary loss. Preserve the valid start.

There is also a train-manifest instance of this signature:
[`Danio_rerio.manifest.tsv.gz`](https://github.com/nekrut/annotation/blob/cc0955aaf3bfb54bc85c324584eee25fe5e4d8da/model/labels/manifests/Danio_rerio.manifest.tsv.gz)
contains `rna-NM_001100045.1` (`gene-b3gnt5b`), minus strand on
`NC_141022.1:8404574..8405778`, one CDS row, length 1,205, prefix 0,
reasons `exception,transl_except,frame_length,seq_frame_length`.
These recorded flags make the current auxiliary gate retain the stop at
genomic position 8,404,574. It is already chain-masked. It is the only
representative across the ten manifests with `seq_frame_length` and no
`no_stop`; alternatives are not listed in those manifests, so this is
**not** an estimate of all affected sites.

Require the complete terminal stop to reach the observed CDS end; an earlier
complete stop followed by leftover bases must not satisfy the end check.
Keep the independent reason flags accurate (including an earlier in-frame
stop). Add both-strand regressions, including a split codon, and regenerate
the summaries from all accepted transcripts to measure the auxiliary-site
impact.
