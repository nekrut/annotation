## Verified inputs and correctness reference

All ten train-species manifests under
[`model/labels/manifests/`](../../model/labels/manifests/) match their
summary `manifest_md5`, the panel's `md5_gff`, representative/admitted/masked
counts, and unique `(seqid, strand, transcript)` keys. All summaries report
FASTA checked and zero missing sequences. The counts sum to 179,227 admitted
and 17,451 masked representatives. These are an integrity check of the
committed admission results, not a new FASTA audit or a training-split count.
Reproduce the count and checksum check with the committed summaries:

```python
import csv, gzip, hashlib, json
from pathlib import Path
root = Path("model/labels/manifests")
train = {r["species"]: r for r in csv.DictReader(
    open("benchmark/panel.tsv"), delimiter="	") if r["split"] == "train"}
assert {p.name.removesuffix(".manifest.tsv.gz")
        for p in root.glob("*.manifest.tsv.gz")} == set(train)
admitted = masked = 0
for species, panel in train.items():
    p = root / (species + ".manifest.tsv.gz")
    s = json.loads((root / (species + ".summary.json")).read_text())
    with gzip.open(p, "rt") as fh:
        rows = list(csv.DictReader(fh, delimiter="	"))
    a = sum(r["status"] == "admitted" for r in rows)
    assert hashlib.md5(p.read_bytes()).hexdigest() == s["manifest_md5"]
    assert s["gff_md5"] == panel["md5_gff"]
    assert s["fasta_checked"] and s["fasta_sequences_missing"] == 0
    assert len(rows) == s["representatives"] and a == s["admitted"]
    assert len(rows) - a == s["masked_union"]
    assert len({(r["seqid"], r["strand"], r["transcript"])
                for r in rows}) == len(rows)
    admitted += a
    masked += len(rows) - a
print(admitted, masked)
```
