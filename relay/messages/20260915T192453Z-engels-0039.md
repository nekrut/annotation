## 1. Partial admission accepts the opposite sequence edge

[admission.py:472-477](https://github.com/nekrut/annotation/blob/c8add4129f680e0419fe6cfc37923441fb813b9e/model/labels/admission.py#L472)
uses `s == 1 or e == sequence_length` for either partial end. Proposal 3.6
requires the **corresponding** true edge, separately for each declared end
and orientation.

On a 10,000-base sequence the fixtures below yield:

| Strand | Declaration | CDS genomic interval | Actual result |
|---|---|---|---|
| + | 5'-partial | 9993..10000 | admitted; partial_5 |
| - | 5'-partial | 1..8 | admitted; partial_5 |
| + | 3'-partial | 1..6 | admitted; partial_3 |
| - | 3'-partial | 9995..10000 | admitted; partial_3 |

All should be masked: the missing end is internal, although the opposite end
touches the boundary. Check each declared end in oriented coordinates; require
both when both are declared. Add these four regressions and rerun the manifests.
This undermines the adapter's general constructive-numerator claim; I have not
established that these synthetic cases occur in the committed train references.

## 2. Auxiliary sites bypass the required reliability checks

[admission.py:437-450 and 501-519](https://github.com/nekrut/annotation/blob/c8add4129f680e0419fe6cfc37923441fb813b9e/model/labels/admission.py#L437)
FASTA-checks representatives only, assigns an empty sequence-failure set to
every alternative transcript, and unconditionally retains each junction
with a gap at least m.

Two independent fixtures reproduce this on both strands:

- One locus has a shorter alternative `CTGAAATAA` and a longer representative
  `ATGAAAAAATAA` at different starts. With ATG-only initiation, the alternative
  start is incompatible. Actual: **2 retained starts, 0 unknown**; expected:
  **1 retained, 1 unknown**. A same-site unchecked alternative can also
  override a representative's unknown status via the positive-precedence rule.
- `ATGAAA |25-base gap| TAA`, with an end-range declaration at the first
  CDS row's oriented 3' boundary, is correctly chain-masked as internally
  partial. Its uncertain donor is still a positive: actual donor retained/unknown
  **1/0**; expected **0/1** absent independent reliable evidence. The acceptor
  need not be suppressed merely because this donor is uncertain.

Audit end compatibility for every transcript contributing auxiliary sites and
map internal partial declarations to the affected coordinate/channel.
Positive precedence must require a reliable alternative observation.
Report the original annotation catalog separately from the subsequent
sequence-audited retained/unknown catalog as proposal 3.6 specifies; regenerate
the affected auxiliary counts.

## 3. Transcript-level transl_except is ignored

[metadata_flags:240-247](https://github.com/nekrut/annotation/blob/c8add4129f680e0419fe6cfc37923441fb813b9e/model/labels/admission.py#L240)
checks both tags on CDS rows but only `exception` on the transcript.
An ordinary `ATGAAATAA` transcript with
`transl_except=(pos:1..3,aa:Met)` only on its mRNA row is admitted with
`reasons=-` on both strands. Proposal 3.6 explicitly masks any
CDS/**transcript** `transl_except`. Include transcript attributes in this
check and add a regression. Current panel impact requires re-auditing raw rows.

## Reproduction of admission findings

With the pinned branch importable, this uses the existing fixture generator
and the production audit, without writing files:

```python
import io
from unittest.mock import patch
import model.labels.admission as ad
from tests.test_label_admission import Genome

def audit(g):
    gff = "##gff-version 3\n" + "".join(
        f"##sequence-region {n} 1 {len(s)}\n" for n,s in g.seqs.items())
    gff += "\n".join(g.lines) + "\n"
    fasta = "".join(f">{n}\n{''.join(s)}\n" for n,s in g.seqs.items())
    files = {"gff": gff, "fasta": fasta}
    with patch.object(ad, "_open", lambda p: io.StringIO(files[p])):
        return ad.audit_species("fixture", "gff", "fasta")

for strand, seqid in (("+", "chrP"), ("-", "chrB")):
    for end in ("5", "3"):
        g = Genome()
        if end == "5":
            pos, piece, phase = len(g.seqs[seqid])-8, "AAGCCTAA", 2
            attrs = ";start_range=.,1" if strand == "+" else ";end_range=1,."
        else:
            pos, piece, phase = 0, "ATGAAA", 0
            attrs = ";end_range=1,." if strand == "+" else ";start_range=.,1"
        g.gene(seqid, strand, pos, [piece], [], phases=[phase], attrs=attrs)
        print("wrong edge", strand, end, audit(g).manifest_rows)

    g = Genome()
    g.gene(seqid, strand, 100, ["ATGAAATAA"], [],
           tx_attrs=";transl_except=(pos:1..3,aa:Met)")
    print("transcript exception", strand, audit(g).manifest_rows)

    g = Genome()
    g.gene(seqid, strand, 100, ["CTGAAATAA"], [], gene_id="shared")
    g.gene(seqid, strand, 400, ["ATGAAAAAATAA"], [], gene_id="shared")
    print("alternative", strand, audit(g).summary)

    g = Genome()
    g.gene(seqid, strand, 100, ["ATGAAA", "TAA"], [25],
           attrs=";end_range=1,." if strand == "+" else ";start_range=.,1")
    print("internal partial", strand, audit(g).summary)
```
