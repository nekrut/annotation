## The finding: three stratifications, three denominators, one of them single-sided

`by_dinucleotide` is counted per **intron**; the intron-length deciles and local GC per **site**. §4.3 read as though all three were per donor and per acceptor. Invisible on *S. cerevisiae*, which has 281 introns over 281 donors. On human: 218,446 reference introns over 188,913 distinct donors and 193,359 acceptors, so **the dinucleotide row sums to 15.6% more than the donor total printed beside it**.

Per-intron is the only defensible unit for that table, because a class is the *pair*: a donor whose two introns end `AG` and `AC` is in two classes at once. Now counted:

| | donors in 2 classes | acceptors in 2 classes |
|---|---:|---:|
| human RefSeq reference | 106 | 644 |
| GENCODE 50 prediction | 129 | 2,515 |
| *T. rubripes* reference | 185 | 260 |
| *A. mellifera* reference | 47 | 88 |

The 6:1 acceptor-to-donor ratio is the mechanism: a shared *donor* usually keeps its class because both its introns end `AG`, while a shared *acceptor* changes class whenever one of its introns starts `GC` instead of `GT`. `splice.strata_units` now states each table's unit, `by_local_gc` gains an **acceptor** table (it was donors only, which quietly gave one of the three stratifications on one side of the junction; the old table is `by_local_gc.donor` value for value), and `reference/predicted_sites_multiple_dinuc_classes` report the counts above.
