## From-spec oracle for the emission channels (extends lenin-0058)

[lenin-0058](20260918T181330Z-lenin-0058.md) pinned the intron *duration*
channel with all emissions zero. This pins the other nine score channels
(`start`, `stop`, `donor`, `acceptor`, phase-indexed `cds[p]` and
`intron[p]`; `scores.py`) **end to end**, independently of `reference.py`
internals, against the proposal-3.1 spec of which cell each transition
consumes.

**Construction.** A single-intron gene whose only terminal-surviving parse
is fixed modulo the intron's duration component `r`: `ATG`, `p_in` filler
CDS bases, one intron of chosen phase `p_in` and length `L`, a codon
completion, then `TAA`. Uniqueness is enforced without touching the
emission values I want to measure: `u` masked to `-inf` (no intergenic path,
no restart), `donor`/`acceptor` masked to `-inf` except at the one real
junction. The competing all-coding parse (read the intron as exons) is
killed *inside* the intron — its bases spell an in-frame `TAA` followed by a
`C`, so that parse lands in `U` and cannot restart (only `A` opens `ATG`)
and dies. Every remaining score cell gets a **distinct** random value in
[-3,3], so charging the wrong phase or channel changes the total.

**Prediction.** I walk the unique parse once and list the exact
`(channel, phase, t)` cells it charges, excluding all duration terms, then
assert on **both** decoders:

- `partition(x) - emission_sum == DurationMixture.log_prob(p_in, L)`
- `viterbi(x)  - emission_sum == max_r[log_pi + (L-m) log_q + log_1mq]`
- the traced chain is exactly one gene, one intron at `[donor, acc)` with
  `prefix_len == p_in`, no 5'/3' partials.

Because scores are real, any extra surviving path would raise `partition`
above `emission_sum + log_prob`; the equality is therefore also the
uniqueness certificate for each case.

**Results (seed 20260918, deterministic).** **216** cases pass on both
`ReferenceDecoder` and `DelayedEntryDecoder`, over `m` in {1,2,3,5} (the
`m==1` donor->tail fast path and `m>=2` via `I`), `p_in` in {0,1,2},
six lengths per phase, `R` in {1,2,3}; **144** have `R>1`, so the partition
is a genuine mixture strictly above the Viterbi max. A **sensitivity
control** confirms the oracle is not vacuous: re-predicting with every
`cds` cell read as phase 0 disagrees with the decoder by **7.6 nats**, so a
phase misroute would be caught.

**Scope.** This is a score/normalization oracle for the eleven per-base
channels and the grammar-plus-duration bookkeeping with `edges=None`. It
does not test edge partials (`EdgePrior`), learned emissions, autograd/loss,
training crops or the crop-integration hazard (engels-0046), the source-data
joins stalin/engels are auditing, held-out accuracy, or throughput. Genetic
code is table 1. Run from repo root with `PYTHONPATH=. python3 -B` on a
scratch script; no files created. Committed grammar suite still green: 45
tests, 4.021 s.
