## Training crops must retain intron age and latent component weights

[Proposal sections 3.3 and 3.6](../../docs/design/proposal.md) permit
truth-derived training boundary conditions, including an intron's pending
minimum-length entry. The crop is not a new biological sequence edge.
For a known upstream donor, coding state c and k intronic bases already
consumed, this synthetic check conditions on survival to that boundary:

- k < m: initialize I(c,k), preserving the remaining mandatory prefix.
- k >= m: initialize T(c,r), with normalized weights proportional to
  pi[p,r] * q[p,r]**(k-m). Keep the component latent.
- Retain the full c, including S versus E and unfinished prefix identities.
  An S state is needed for crops inside introns splitting the initiator.
- At an acceptor immediately at the crop start, T may exit before emitting
  another intronic base. The true-edge residual J may not.

For zero neural scores, an intron of total length L has crop completion
log weight `log Pr(L|p) - log sum_r pi[p,r]*q[p,r]**max(k-m,0)`.
This is conditional on the known upstream chain state and survival, not
a whole-chromosome likelihood. The numerator and denominator of a
conditional crop loss must share the declared boundary distribution;
neither receives an artificial entry/exit score at a crop seam.
For learned mixtures the relative boundary weights depend on parameters;
this scalar check does not validate their autograd treatment.

## Results and reproducible counterexamples

**924 crop cases** (798 inside mandatory prefixes, 126 in tails), including
**42 crops beginning at an acceptor**, match the closed form in both an
explicitly seeded reference recurrence and a resumed delayed checkpoint.
Maximum absolute log-weight error: **4.440892098500626e-16**.
Cases cover tables 1/6, seven CDS split positions (including both split
initiator positions), three intron lengths 20/21/25, three duration
components, and every consumed intron age.

Three counterexamples make the consequences concrete:

1. A 19-base total intron, cropped after its first base, has no legal path
   with m=20. Replacing I(c,1) by a fresh T mixture gives finite log weight
   **-4.8905989377825145**, admitting an impossible target.
2. A 25-base intron cropped after 24 bases has conditional completion log
   weight **-2.244871202267154**. Resetting its surviving components to pi
   changes this to **-1.903808973036678**.
3. At the acceptor of a 20-base intron, T gives log weight
   **-1.1086626245216111**; replacing it with J gives no legal target path.

The delayed check preserves the full checkpoint (active scores, pending
donors, rolling emissions and masks), and continues on the original
absolute coordinates. It does **not** implement a standalone cropped
delayed API. In particular, injecting an I state into delayed active
scores is unsupported: pending minimum-length histories belong in its
donor ring. Real-data adapters, unknown crop-boundary labels, learned
potentials/gradients, reverse-strand coordinate joins and end-to-end
training remain untested here.

Run from the repository root with `python3 -B`; no files are created:

```python
import json, math, platform, time
from model.grammar import ReferenceDecoder, DelayedEntryDecoder, DurationMixture, Scores, TABLES
from model.grammar.reference import logsumexp
NEG = -math.inf
class Crop(ReferenceDecoder):
    def __init__(self, code, dur, init):
        super().__init__(code, dur)
        self.init = init
    def initial(self):
        return self.init

def slice_scores(sc, start):
    out = Scores.zeros(sc.n-start)
    src = dict(sc.channels())
    for name, arr in out.channels():
        arr[:] = src[name][start:]
    return out

def fixture(cut, length):
    coding = 'ATGAAATGA'
    x = coding[:cut] + 'C'*length + coding[cut:]
    sc = Scores.zeros(len(x))
    for _, arr in sc.channels():
        arr[:] = [NEG]*len(x)
    p = 0
    for t in range(len(x)):
        if cut <= t < cut+length:
            sc.intron[p][t] = 0.
        else:
            sc.cds[p][t] = 0.
            p = (p+1)%3
    sc.start[0] = sc.stop[-1] = sc.donor[cut] = sc.acceptor[cut+length] = 0.
    p = cut%3
    c = ('S', coding[:cut]) if cut<3 else ('E', coding[cut-p:cut] if p else '')
    return x, sc, c

t0, cpu0 = time.monotonic(), time.process_time()
dur = DurationMixture(m=20, pi=((.2,.3,.5),)*3, q=((.2,.6,.9),)*3)
cases = mandatory = tail = immediate = 0
maxerr = 0.
for table in (1,6):
    for cut in (1,2,3,4,5,7,8):
        for length in (20,21,25):
            x, sc, c = fixture(cut,length)
            p = len(c[1])
            dl = DelayedEntryDecoder(TABLES[table],dur)
            checkpoints,_,_,_ = dl._run(x,sc,False,seams=range(1,len(x)))
            assert math.isclose(dl.partition(x,sc),dur.log_prob(p,length),abs_tol=1e-11)
            for age in range(1,length+1):
                survival = logsumexp([dur.log_pi(p,r)+max(age-dur.m,0)*dur.log_q(p,r) for r in range(dur.R)])
                if age < dur.m:
                    init = {('I',c,age):0.}
                    mandatory += 1
                else:
                    init = {('T',c,r):dur.log_pi(p,r)+(age-dur.m)*dur.log_q(p,r)-survival for r in range(dur.R)}
                    tail += 1
                a = cut+age
                expected = dur.log_prob(p,length)-survival
                zr = Crop(TABLES[table],dur,init).partition(x[a:],slice_scores(sc,a))
                cp = checkpoints[a].copy()
                cp.layer = {s:w-survival for s,w in cp.layer.items()}
                cp.pending = type(cp.pending)((s,{c:w-survival for c,w in parked.items()}) for s,parked in cp.pending)
                _,_,out = dl._run_chunk(x,sc,False,cp,len(x),retain=False)
                zd = out.layer.get(('U',),NEG)
                assert math.isfinite(zr) and math.isfinite(zd)
                maxerr = max(maxerr,abs(zr-expected),abs(zd-expected))
                assert abs(zr-expected)<1e-11 and abs(zd-expected)<1e-11, (table,cut,length,age,zr,zd,expected)
                cases += 1
                immediate += (age==length)

# Resetting age to a fresh tail permits an intron whose true total is <m.
x, sc, c = fixture(4,19)
age = 1; a = 4+age
fresh = {('T',c,r):dur.log_pi(1,r) for r in range(dur.R)}
good = Crop(TABLES[1],dur,{('I',c,age):0.}).partition(x[a:],slice_scores(sc,a))
bad = Crop(TABLES[1],dur,fresh).partition(x[a:],slice_scores(sc,a))
assert good == NEG and math.isfinite(bad)
# Resetting mixture weights after a long surviving prefix changes a valid target.
x, sc, c = fixture(4,25)
age=24; a=4+age
survival=logsumexp([dur.log_pi(1,r)+(age-20)*dur.log_q(1,r) for r in range(dur.R)])
init={('T',c,r):dur.log_pi(1,r)+(age-20)*dur.log_q(1,r)-survival for r in range(dur.R)}
good_tail=Crop(TABLES[1],dur,init).partition(x[a:],slice_scores(sc,a))
bad_tail=Crop(TABLES[1],dur,fresh).partition(x[a:],slice_scores(sc,a))
assert abs(good_tail-bad_tail)>.1
# A sequence-edge residual J cannot close before its first observed intron base.
x, sc, c = fixture(4,20); a=24
jinit={('J',c,r):dur.log_pi(1,r) for r in range(dur.R)}
jwrong=Crop(TABLES[1],dur,jinit).partition(x[a:],slice_scores(sc,a))
correct=Crop(TABLES[1],dur,fresh).partition(x[a:],slice_scores(sc,a))
assert jwrong == NEG and math.isfinite(correct)
print(json.dumps(dict(crop_cases=cases,mandatory_prefix_cases=mandatory,tail_cases=tail,
    acceptor_at_crop_start_cases=immediate,max_log_weight_error=maxerr,
    short_intron_reset_log_weight=bad,age24_correct_log_weight=good_tail,
    age24_fresh_mixture_log_weight=bad_tail,immediate_acceptor_correct_log_weight=correct,
    python=platform.python_version(),cpu_seconds=time.process_time()-cpu0,
    wall_seconds=time.monotonic()-t0)))
```
