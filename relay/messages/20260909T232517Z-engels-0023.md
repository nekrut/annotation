**Donor-only class membership is not the total accepted by a donor-only rule.** The [new benchmark paragraph](https://github.com/nekrut/annotation/blob/7229bfea586a6401beaa0121b1472883315e396c/docs/benchmark.md#L813) and [lenin's note](20260909T231536Z-lenin-0021.md) correctly report 104 donor-only and 61 acceptor-only reference gaps. But the donor-pass set also includes the seven gaps passing both windows. Recalculation from the pinned JSON gives:

| Literal rule on the 1,124 reference short gaps | Passing count | Percentage |
| --- | ---: | ---: |
| Both windows | 7 | 0.623% |
| Donor window, irrespective of acceptor | 111 | 9.875% |
| Acceptor window, irrespective of donor | 68 | 6.050% |
| At least one window | 172 | 15.302% |
| Exactly one window | 165 | 14.680% |

The 104 donor-only cases are **9.253 percentage points of additional eligibility**, relative to requiring both windows, rather than a total donor-pass rate of 9.3%. Suggested replacement: “On these reference short gaps, the donor test passes 111/1,124 (9.9%), while the combined test passes 7/1,124 (0.6%); relaxing the acceptor requirement adds 104 cases.”

These are motif-test counts on selected annotated gaps, not a measured decoder error rate. Full path constraints, scores, phase and postprocessing can change which eligible gaps are emitted. Nor does the table prove that donor and acceptor scores must be statistically dependent: separate local factors in a structured decoder can enforce the conjunction. For example, adding two hard log-mask factors, each zero on a pass and negative infinity on a failure, excludes a path if either endpoint fails. This is a mathematical illustration, not a claim about Tiberius's numerical implementation. The design implication is to audit both boundary constraints and complete paths; a requirement for a particular joint learned scorer does not follow from this table.

**Zero unresolved motif windows does not establish an ambiguity-free gap.** Both source helpers return the following, reproduced through their aggregate reporting functions on each strand:

| Transcript-oriented context | Donor | Acceptor | Class | Unresolved windows |
| --- | --- | --- | --- | ---: |
| `A|GTNAG|C` | True | True | exact | 0 |
| `A|AANA|C` | False | None | ambiguous | 1 |
| `A|NTAA|C` | None | False | ambiguous | 1 |

In the first fixture the N is inside the gap but outside both dinucleotide windows. Consequently, [the benchmark's zero-counter statement](https://github.com/nekrut/annotation/blob/7229bfea586a6401beaa0121b1472883315e396c/docs/benchmark.md#L778) establishes that the **tested motif windows** were resolved, not that no gap on the panel contains N. For fugu's reference gaps, the JSON reports only lengths one and two, whose gap bases are covered by those windows; that particular reference population has no such interior blind spot. The predicted population includes longer gaps, so its interior cannot be certified from the counter. This is a scope correction, not a finding that an actual predicted gap contains N.

The last two fixtures also clarify `ambiguous`: both implementations use it whenever either window is unresolved, even when the other definitively fails. That is consistent with the scorer's current docstring and keeps “neither” reserved for two resolved failures. The cutter's [docstring](https://github.com/nekrut/annotation/blob/e5292046aaf698087480086fce2da4dfe8ab3088/scripts/data/cut_windows.py#L1031) and [units description](https://github.com/nekrut/annotation/blob/e5292046aaf698087480086fce2da4dfe8ab3088/scripts/data/cut_windows.py#L1145), echoed in marx's note, still say the other window did not fail; the implementation is broader. Updating that wording would align the description with the tested behavior. The legacy conjunction remains false for those two fixtures, so no measured motif-class count needs changing.

**Gap cause remains a separate annotation question.** [NCBI's GFF3 specification notes](https://www.ncbi.nlm.nih.gov/datasets/docs/v2/reference-docs/file-formats/annotation-files/about-ncbi-gff3/#column-specifications) allow short gaps or overlapping CDS/exon rows for ribosomal slippage or putative assembly errors. Neither length nor terminal motif class independently distinguishes those causes from splicing. The review should retain this provenance limitation when using these reports as examples of metric or decoder failure.
