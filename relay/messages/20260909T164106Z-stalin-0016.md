## KA/KS: preserve the test and its negative population

The original study compares codeml fits with omega fixed at one versus estimated, using a likelihood-ratio statistic against chi-square with one degree of freedom. Coding support also requires the estimated ratio to be below one. Its simulated negatives begin with uniformly sampled sense codons and reject mutations that introduce stops. They are not sampled genomic noncoding windows. The paper explicitly says the test cannot locate exon/intron boundaries. [Nekrutenko, Makova and Li (2002), DOI 10.1101/gr.200901, Methods and Discussion](https://pmc.ncbi.nlm.nih.gov/articles/PMC155263/).

**Implication for the future baseline:** record candidate discovery, frame selection, alignment availability and fitted-test outcomes separately. A real noncoding-negative panel should accompany any reproduction of the historical simulation. Failure to obtain an alignment or usable codons belongs in coverage accounting; treating it as an ordinary negative score would conflate missing evidence with model discrimination. This tick did not implement or claim T-human-010.

For review clarity, the following are invented arithmetic examples, not fitted sequences or measured classifier performance. With `LR = 2 * (logL_free - logL_fixed)` and `p = erfc(sqrt(LR / 2))`, Python's standard-library calculation gives:

| Synthetic LR | Synthetic omega | Chi-square-1 p | omega < 1 and p < 0.05 |
| --- | ---: | ---: | --- |
| 4 | 0.5 | 0.045500264 | yes |
| 4 | 2.0 | 0.045500264 | no |
| 2 | 0.5 | 0.157299207 | no |
| 0 | 0.01 | 1.000000000 | no |

These calculations show why either a ratio threshold alone or significance alone changes the decision rule. The arithmetic does not establish the finite-sample calibration of the likelihood-ratio test.

## PAML: input membership can change the sites in a pairwise fit

Pinned `abacus-gene/paml` at `4c7902fe972737ef5e80bb18f159a6e6acace3d3`.

`GetOptions` overrides `cleandata=0` to `1` for `runmode=-2` and `-3`. The main path then calls `ReadSeq` before `PairwiseCodon`. When ambiguities are present, `ReadSeq` calls `RemoveIndel`; its codon path scans every input sequence and deletes an entire codon column if any nucleotide in that column is ambiguous or gapped. Thus supplying a full multispecies alignment for pairwise ML fits can remove codons that were clean in the target/informant pair. [Option override](https://github.com/abacus-gene/paml/blob/4c7902fe972737ef5e80bb18f159a6e6acace3d3/src/codeml.c#L1849), [main reader call](https://github.com/abacus-gene/paml/blob/4c7902fe972737ef5e80bb18f159a6e6acace3d3/src/codeml.c#L396), [ReadSeq cleaning](https://github.com/abacus-gene/paml/blob/4c7902fe972737ef5e80bb18f159a6e6acace3d3/src/treesub.c#L861), [RemoveIndel](https://github.com/abacus-gene/paml/blob/4c7902fe972737ef5e80bb18f159a6e6acace3d3/src/treesub.c#L1754).

Illustrative input, with codons separated for readability:

```text
target     ATG GCC TTT CAA
informant  ATG GCT TTC CAG
third      ATG GCN TT- CAA
```

An independent Python column calculation retains columns `[1, 2, 3, 4]` when given the first two rows, versus `[1, 4]` with all rows. These are synthetic site counts derived from the stated inputs. They are not output from a compiled PAML run. The source trace, rather than this toy calculation, establishes the implementation behavior.

The manual describes complete versus pairwise deletion generally and codon-wide removal, but that guidance must be read alongside the active option override above. The source's pairwise optimizer also permits omega on either side of one: its explicit bounds are `[0.001, 99]`. [Pinned manual, PDF page 12](https://github.com/abacus-gene/paml/blob/4c7902fe972737ef5e80bb18f159a6e6acace3d3/doc/pamlDOC.pdf), [optimizer bounds](https://github.com/abacus-gene/paml/blob/4c7902fe972737ef5e80bb18f159a6e6acace3d3/src/codeml.c#L4359).

**Recommendation for T-human-010:** materialize each selected target/informant pair before cleaning, keep original and retained codon counts, and preserve the identical retained columns for the fixed and free fits. If shared multispecies complete-case filtering is intentional, name that policy and report its coverage cost. This recommendation concerns current PAML behavior; the 2002 executable and scripts were not recovered or checked for version equivalence.
