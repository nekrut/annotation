## Publication addition and evaluation scope

Yang, Huang and Li (2026), [Improving spliced alignment by modeling splice sites with deep learning](https://doi.org/10.1186/s13015-025-00293-7), describes a 7,026-parameter CNN using 202-base windows, with splice scores consumed during alignment. It supports vertebrates/insects; no plant model was trained. Training uses annotated GT/AG positives and opposite-gene-strand negatives, sampled at 1:3. The paper describes an 80/20 gene split on odd chromosomes and testing on even chromosomes.

Table 1 marks seven vertebrate and six insect training species; the cross-species subsection reverses those counts. Human is unstarred, whereas fruitfly is starred, so the latter is not a held-out species.

## Released training code splits individual site examples

All source observations below concern revision [`49f9e8c586ba0a8c049a8f54007509d26c298499`](https://github.com/lh3/minisplice/tree/49f9e8c586ba0a8c049a8f54007509d26c298499), not an independently reconstructed historical run.

The [reader](https://github.com/lh3/minisplice/blob/49f9e8c586ba0a8c049a8f54007509d26c298499/reader.c#L227) creates one record per site-window line. In [train.c](https://github.com/lh3/minisplice/blob/49f9e8c586ba0a8c049a8f54007509d26c298499/train.c#L53), conversion passes sequence tensors and labels onward; genomic identifiers are absent from the training call. The caller sets the validation fraction to 0.2. [kann_train_fnn1b](https://github.com/lh3/minisplice/blob/49f9e8c586ba0a8c049a8f54007509d26c298499/kann.c#L854) randomly shuffles those examples and reserves a fraction for validation. This is an internal site-level split, not an implemented gene-group split.

**Inference:** the default training path does not guarantee gene-disjoint early-stopping validation; nearby windows from a gene could occur in both subsets. External dataset preparation and the historical checkpoint's precise membership were not reconstructed. This finding does not negate the separately described chromosome-level test split.

## Calibration needs its own provenance

The [README](https://github.com/lh3/minisplice/blob/49f9e8c586ba0a8c049a8f54007509d26c298499/README.md#L74) trains on odd-chromosome windows and calibrates against annotations on even chromosomes. Its multi-species example uses `anno1-all.bed.gz` for both genomes, despite naming separate annotations during training, and calls `script/merge-cali.js` although the tracked directory is `scripts/`. These are documentation inconsistencies; I did not execute the commands or measure their impact.

The [calibration implementation](https://github.com/lh3/minisplice/blob/49f9e8c586ba0a8c049a8f54007509d26c298499/predict.c#L143) estimates each bin's annotated fraction relative to the overall annotated fraction, adds 0.001 pseudocounts, applies logarithmic scaling and enforces monotonicity. The [merge script](https://github.com/lh3/minisplice/blob/49f9e8c586ba0a8c049a8f54007509d26c298499/scripts/merge-cali.js) weights the calibration counts supplied by the user. The calibrated score therefore depends on annotation selection and calibration composition as well as neural weights.

**Benchmark implication:** pin weights, calibration files, annotation versions and the calibration species/coordinates separately. A raw-score ROC and annotation-calibrated alignment accuracy are distinct evaluation stages; using test annotations to calibrate an alignment experiment would violate a label-unexposed holdout. The inspected material does not establish that this happened in the published human alignment run.

The [Zenodo model description](https://zenodo.org/records/15931054/files/00README.md?download=1) independently lists seven vertebrates and six insects, consistent with Table 1. It identifies `vi2-7k.kan` and its calibration companion, but does not give a separate calibration-membership manifest. The wolf label differs between the release description (`mCanLor`) and article (`mCanLup`); preserve accession identifiers before joining manifests. The [release listing](https://zenodo.org/records/15931054) reports a 30.7 kB model archive and 371.3 MB compressed human scores. These are reported file sizes, not local measurements; no model, training set or genomic scores were downloaded.

**Design implication:** include a small local splice scorer as a comparator for the proposed geometry-aware model, with a shared downstream decoder. Its alignment gains motivate that comparison, but cannot substitute for exact coding-boundary and complete-gene evaluation. Preserve candidate recall and noncanonical splice-site strata.
