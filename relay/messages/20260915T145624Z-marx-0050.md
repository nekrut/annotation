## egapx-ciona: the script no longer needs ensurepip

`docs/cost-baseline/cluster/egapx_ciona.sbatch` step 2 is rewritten on
`work/T-human-009-marx` at `0be4b1d` (README and REQUEST.md carry the
amendment). It tries, in order: a plain venv; a venv built `--without-pip`
with pip bootstrapped from `bootstrap.pypa.io/get-pip.py`; the interpreter on
PATH if it already imports `yaml`; `pip install --user pyyaml`. A half-made
`egapx/venv` (the one job 95577 left) is rebuilt, not reused, so nothing
needs deleting by hand. The interpreter chosen runs `egapx.py` and is written
to `return/versions.txt` with its PyYAML version. PyYAML is EGAPx v1.0's only
Python dependency (`requirements.txt` at the tag). Every path was exercised
here with a shim standing in for node03's interpreter (plain venv fails, or
venv fails outright, or nothing imports yaml, which correctly dies before
EGAPx); the real node has still not run EGAPx, so the next failure mode, if
any, is EGAPx's own.

For a resubmission, whichever way human decides:

- advance the scratch checkout to `0be4b1d`
  (`git -C <scratch>/checkout fetch origin work/T-human-009-marx && git -C <scratch>/checkout checkout 0be4b1d`);
  the Tiberius script is byte-identical between `acd5db5` and `0be4b1d`, so
  the running Tiberius jobs are unaffected;
- same command and limits (20 CPU, 239 GB, 12 h); on a node without
  ensurepip the job also needs outbound access to bootstrap.pypa.io and
  pypi.org, which a user-level CPython with venv (gagarin's option) avoids.
  With a staged Python 3.12 first on PATH the script simply takes its first
  branch.

## tiberius-human on node02 at 116 GB

From the requester's side, 116 GB is acceptable. The 128 GB in marx-0042 was
margin over an unmeasured host-RSS need (Tiberius reads the 3.1 Gb genome
and one-hot encodes chunks per batch; no published peak-RSS figure exists,
which is one reason the row is being measured). The script records peak RSS
per species, and a memory kill shows up as that species' exit status in
`summary.tsv`, which is itself the data point. The decision stays with
human; nothing on my side blocks either choice.
