## Independent partial-edge calculation agrees on nonempty input

All 16 existing unittest cases pass, including the duration-shape and
one-base-intron regressions. I independently scored left-edge chains by
enumerating the 21 missing codon prefixes and concrete resolutions of the
observed CDS, translating the concatenation directly, and applying the
closed-form residual-intron component weight. This uses neither the
transition generator nor the duration log helpers.

The driver below checks 480 configurations (tables 1/6; R 1/3; m 1/2/20;
observed flank lengths 0/1/19/20/21; eight CDS strings including ambiguity),
each against both decoders: 960 decoder checks. Forward and Viterbi maximum
absolute errors are both `1.0658141036401503e-14`. The CDS coordinates,
phase, uncertainty flag, partial flags and selected intron component also
agree. There are 384 positive-flank configurations. The other 96 select
an immediate residual-intron exit and expose the representation issue below.
This validates the implemented residual law, not a claim that every boundary
convention is already settled.

## Two boundary cases missed by decoder-to-decoder agreement

**Empty input admits a path without observed CDS.** Both decoders return
`logZ = 0.22314355131420976 = log(1.25)` on `x=""`,
`Scores.zeros(0)` and default `EdgePrior()`. The all-U empty path has
weight 1; the E0 prefixes add another 0.25 because `terminal()` permits
E0 to exit without consuming its mandatory first CDS base. Proposal 3.1
requires discarding paths without observed CDS. Either explicitly reject
empty sequences at the API boundary or make E0 nonterminal, leaving
`logZ=0` and no chains on an accepted empty sequence. This is an empty-input
edge case, not evidence of an error on ordinary nonempty contigs.
With accepted `EdgePrior(2.,2.)`, it also becomes the Viterbi winner:
score `2.90138771133189`, a CDS segment `[0,0)`, both partial flags set.

**Nonempty input can emit a zero-length intron.** On `AAATAA`, reward every
CDS base by 10 and the acceptor at position 0 by 10; all other scores are
zero, default m=20 and default edge priors. Both decoders return score
`67.515093350212` and one partial-5 chain containing
`intron [0,0), component 0` followed by `CDS [0,6), phase 0`.
All input scores in this example are finite.

The initial J state can close immediately at t=0. The shared `_chains()`
initializes its intron as `[0,0)` and appends that segment before consuming
the first CDS base. The arithmetic follows the implemented transition
relation; this is not another delayed-entry discrepancy. The scored
zero-observed-residual hypothesis needs an explicit convention: if intended,
omit its empty intron from emitted genomic intervals while preserving any
needed latent boundary metadata; if a residual entry requires an observed
intronic flank (compare proposal 3.6), require at least one consumed intronic
base before J exits. The latter changes partition scores and must be made
in both recurrences, not just traceback. In either case, the exported
interval contract should not treat `[0,0)` as an observed intron.

Minimal reproduction (Python 3.11+, reviewed grammar importable):

```python
from model.grammar import ReferenceDecoder, DelayedEntryDecoder, EdgePrior, Scores

for cls in (ReferenceDecoder, DelayedEntryDecoder):
    dec = cls(edges=EdgePrior())
    print(cls.__name__, dec.partition("", Scores.zeros(0)))
    x = "AAATAA"
    sc = Scores.zeros(len(x)).favour([(0, len(x))], [])
    sc.acceptor[0] = 10.
    print(dec.viterbi(x, sc))
    print(cls(edges=EdgePrior(2., 2.)).viterbi("", Scores.zeros(0)))
```

## Reproduction of the independent check

Run with the reviewed revision's grammar importable. The coding oracle below
explicitly includes the currently implemented immediate-J-exit possibility at
flank length zero, so its agreement does not resolve that policy choice.

```python
import itertools, math, random
from model.grammar import ReferenceDecoder, DelayedEntryDecoder, DurationMixture, EdgePrior, Scores, TABLES
NEG = -math.inf
rng = random.Random(202609151744)
prefixes = [''] + list('ACGT') + [''.join(q) for q in itertools.product('ACGT', repeat=2)]
seqs = ('A', 'AA', 'AAA', 'TAA', 'AATAA', 'AAAATAA', 'NRTGA', 'NNTAA')
bases = {b:b for b in 'ACGT'} | {'N':'ACGT','R':'AG','Y':'CT'}

def oracle(x, flank, sc, table, dur, edges):
    obs = x[flank:]
    prior = sum(math.log(len(bases[b])) for b in obs)
    stops = {'TAA','TAG','TGA'} if table == 1 else {'TGA'}
    choices = []
    for initial in prefixes:
        p = len(initial)
        for actual in itertools.product(*(bases[b] for b in obs)):
            q = initial
            score = edges.entry - math.log(3) - p*math.log(4) - prior
            partial3 = True
            for j,b in enumerate(actual):
                t = flank+j
                score += sc.cds[len(q)][t]
                q += b
                if len(q) == 3:
                    if q in stops:
                        if j != len(actual)-1:
                            break
                        partial3 = False
                        score += sc.stop[t]
                    q = ''
            else:
                if partial3:
                    score += edges.exit
                if flank == 0:
                    choices.append((score, p, None, partial3))
                for r in range(dur.R):
                    extra = (math.log(dur.pi[p][r]) + flank*math.log(dur.q[p][r])
                             + math.log(1-dur.q[p][r]) + sc.acceptor[flank]
                             + sum(sc.intron[p][:flank]))
                    choices.append((score+extra, p, r, partial3))
    best = max(choices)
    top = best[0]
    total = top + math.log(sum(math.exp(v[0]-top) for v in choices))
    return total, best

counts = {'configs':0, 'decoder_checks':0, 'zero_intron_winners':0, 'positive_residual_winners':0}
max_f = max_v = 0.
for table,R,m,flank,obs in itertools.product((1,6),(1,3),(1,2,20),(0,1,19,20,21),seqs):
    pi = tuple(tuple(v/sum(row) for v in row) for row in
               [[rng.uniform(.1,1.) for _ in range(R)] for _ in range(3)])
    q = tuple(tuple(rng.uniform(.1,.9) for _ in range(R)) for _ in range(3))
    dur = DurationMixture(m=m, pi=pi, q=q)
    edges = EdgePrior(math.log(.4), math.log(.6))
    x = 'C'*flank + obs
    sc = Scores.zeros(len(x))
    for arr in (sc.u,sc.start,sc.donor,sc.acceptor):
        arr[:] = [NEG]*len(x)
    sc.acceptor[flank] = 10.
    for arr in [sc.stop,*sc.cds,*sc.intron]:
        arr[:] = [rng.uniform(-1,1) for _ in x]
    for arr in sc.cds:
        arr[:flank] = [NEG]*flank
    ef, (ev,p,r,partial3) = oracle(x,flank,sc,table,dur,edges)
    for cls in (ReferenceDecoder,DelayedEntryDecoder):
        dec = cls(TABLES[table],dur,edges)
        af = dec.partition(x,sc)
        av,chains = dec.viterbi(x,sc)
        assert math.isclose(ef,af,abs_tol=1e-10), (table,R,m,flank,obs,ef,af)
        assert math.isclose(ev,av,abs_tol=1e-10), (table,R,m,flank,obs,ev,av)
        assert len(chains) == 1
        c = chains[0]
        assert c.partial_5 and c.partial_3 == partial3
        assert c.uncertain == any(len(bases[b])>1 for b in obs)
        assert [(s.start,s.end,s.gff_phase) for s in c.cds()] == [(flank,len(x),(-p)%3)]
        want = [] if r is None else [(0,flank,p,r)]
        assert [(s.start,s.end,s.prefix_len,s.component) for s in c.introns()] == want
        max_f,max_v = max(max_f,abs(ef-af)),max(max_v,abs(ev-av))
        counts['decoder_checks'] += 1
    counts['configs'] += 1
    counts['zero_intron_winners'] += flank == 0 and r is not None
    counts['positive_residual_winners'] += flank > 0
print(counts, 'max_abs_forward',max_f,'max_abs_viterbi',max_v)
```
