## Gold boundary support must be explicit

Stalin's acceptor shift and partial-end observations are valid interface
requirements. An additional case matters for the **constrained numerator**:
enabling `EdgePrior` while restricting only emission/phase/site channels
still admits an undeclared partial-start path for a complete CDS starting
at the true sequence edge.

On `ATGAAATAA`, allow only the correct CDS phase at each base, the start at
0 and stop at 8, and forbid all other channels. With the default edge prior,
both merged decoders return `log(7/6) = 0.15415067982725836`, rather than
the complete chain's log weight 0. The extra weight is an E0 entry with
empty prefix: `exp(entry)/3 = 1/6`. A soft `Scores.favour` check, even
one comparing coordinates, does not establish equality to the intended
gold-path set.

For the numerator, constrain the initial and terminal state support using
the known boundary labels while retaining the same edge scores as the
denominator. A complete known chain touching the 5' edge starts from U;
a declared CDS-entry partial starts from E0 with its declared missing-prefix
length, summing compatible latent prefixes. Complete 3' endings terminate
in U; declared CDS-ending partials terminate in S/E. These are target
constraints, never annotation-dependent inference priors. Masks, observed
intronic edge flanks, and training crops need their own support rules;
the narrow test mixin below is not a general loader for those cases.

## Reproduction

Run this block with `python3 -B` from the repository root. It creates no
files. Both decoders agree with the closed-form duration and edge-prior
weight on **464 synthetic cases / 928 decoder configurations**, and their
Viterbi chains agree in coordinates, partial flags and raw GFF phases.
Cases include both strands, codes 1 and 6, missing prefixes 0/1/2, all
complete/partial end combinations, no intron or a 20/21-base intron at
every internal CDS cut, and delayed-decoder seams at every base.
Acceptor coordinates are converted from the catalog's last intron base
to the decoder's first following CDS base. Metadata and sequence checks
pass before decoding each case.

Latest sweep on Python 3.14.4: 0.1754 local CPU seconds (0.1754 wall
seconds). A preceding equivalent sweep consumed 0.1793 CPU seconds.
These are synthetic correctness timings, not pilot throughput. Python
3.11 validation, a differentiable numerator, masks/crop integration, and
checks against original panel FASTAs remain outstanding.

```python
import itertools, platform, time
from math import inf, isclose, isfinite, log
from model.grammar import ReferenceDecoder, DelayedEntryDecoder, DurationMixture, EdgePrior, Scores, TABLES
from model.labels.admission import Row, Transcript, metadata_flags, sequence_flags, revcomp

class GoldEdges:
    # Test-only restriction for known CDS boundaries at the true sequence edges.
    # Unconstrained regions and training crops require their own state support.
    def __init__(self, *args, five=False, three=False, prefix=0, **kw):
        self.five, self.three, self.prefix = five, three, prefix
        super().__init__(*args, **kw)
    def initial(self):
        if not self.five:
            return {('U',): 0.}
        return {s: v for s, v in super().initial().items()
                if s[0] == 'E0' and len(s[1]) == self.prefix}
    def terminal(self, state):
        allowed = state[0] in ('S', 'E') if self.three else state == ('U',)
        return super().terminal(state) if allowed else -inf

class GoldReference(GoldEdges, ReferenceDecoder): pass
class GoldDelayed(GoldEdges, DelayedEntryDecoder): pass

def site(kind, g, n, strand):
    oriented = g - 1 if strand == '+' else n - g
    return oriented + (kind == 'acceptor')

t0, cpu0 = time.monotonic(), time.process_time()
dur = DurationMixture(m=20, pi=((.2, .8),)*3, q=((.2, .6),)*3)
edges = EdgePrior()
cases = 0
for strand, table, five, three in itertools.product(('+', '-'), (1, 6), (False, True), (False, True)):
    for prefix in ((0, 1, 2) if five else (0,)):
        coding = (('CCC' if five else 'ATG') + 'AAA' + ('CC' if three else 'TGA'))[prefix:]
        for cut, gap in [(0, 0)] + [(c, g) for c in range(1, len(coding)) for g in (20, 21)]:
            x = coding if not gap else coding[:cut] + 'C'*gap + coding[cut:]
            n = len(x)
            cds = [(0,n)] if not gap else [(0,cut),(cut+gap,n)]
            introns = [] if not gap else [(cut,cut+gap)]
            seq = x if strand == '+' else revcomp(x)
            rows, phase = [], prefix
            for i, (a,b) in enumerate(cds):
                lo, hi = (a+1,b) if strand == '+' else (n-b+1,n-a)
                attrs = {}
                if i == 0 and five: attrs['start_range' if strand == '+' else 'end_range'] = '.,.'
                if i == len(cds)-1 and three: attrs['end_range' if strand == '+' else 'start_range'] = '.,.'
                rows.append(Row(i+1,'chr',strand,lo,hi,str((-phase)%3),attrs))
                phase = (phase+b-a)%3
            tx = Transcript('tx','gene','chr',strand,0,rows=rows)
            mt = metadata_flags(tx,20,table)
            sf, _ = sequence_flags(tx,seq,mt.prefix,mt.five,mt.three,table)
            assert not (mt.flags-{'partial_5','partial_3'}) and not sf, (tx,mt,sf)
            assert (mt.prefix,mt.five,mt.three) == (prefix,five,three)

            sc = Scores.zeros(n)
            for _, arr in sc.channels(): arr[:] = [-inf]*n
            p = prefix
            for i, (a,b) in enumerate(cds):
                for t in range(a,b): sc.cds[p][t] = 0.; p = (p+1)%3
                if i < len(introns):
                    ia, ib = introns[i]
                    for t in range(ia,ib): sc.intron[p][t] = 0.
                    dg = ia+1 if strand == '+' else n-ia
                    ag = ib if strand == '+' else n-ib+1
                    assert site('donor',dg,n,strand) == ia
                    assert site('acceptor',ag,n,strand) == ib
                    sc.donor[ia] = sc.acceptor[ib] = 0.
            if not five: sc.start[0] = 0.
            if not three: sc.stop[-1] = 0.
            expected = (edges.entry-log(3) if five else 0.) + (edges.exit if three else 0.)
            if gap: expected += dur.log_prob((prefix+cut)%3,gap)
            ref = GoldReference(TABLES[table],dur,edges,five=five,three=three,prefix=prefix)
            dl = GoldDelayed(TABLES[table],dur,edges,five=five,three=three,prefix=prefix)
            zr, zd = ref.partition(x,sc), dl.partition(x,sc,seams=list(range(1,n)))
            assert isfinite(zr) and isclose(zr,expected,abs_tol=1e-11), (x,zr,expected)
            assert isclose(zr,zd,abs_tol=1e-11), (x,zr,zd)
            vr, cr = ref.viterbi(x,sc)
            vd, cd = dl.viterbi(x,sc,seams=list(range(1,n)))
            assert isclose(vr,vd,abs_tol=1e-11) and cr == cd and len(cr) == 1
            chain = cr[0]
            assert (chain.partial_5,chain.partial_3) == (five,three)
            assert [(s.start,s.end) for s in chain.cds()] == cds
            assert [(s.start,s.end) for s in chain.introns()] == introns
            assert [s.gff_phase for s in chain.cds()] == [int(r.phase) for r in rows]
            cases += 1
print({'synthetic_cases':cases,'decoder_checks':2*cases,
       'wall_seconds':round(time.monotonic()-t0,4),
       'local_cpu_seconds':round(time.process_time()-cpu0,4),
       'python':platform.python_version()})

# Complete edge-touching chain: emissions alone also admit a partial start.
x = 'ATGAAATAA'
sc = Scores.zeros(len(x))
for _, arr in sc.channels(): arr[:] = [-inf]*len(x)
for t in range(len(x)): sc.cds[t%3][t] = 0.
sc.start[0] = sc.stop[-1] = 0.
for cls, gold in ((ReferenceDecoder,GoldReference),(DelayedEntryDecoder,GoldDelayed)):
    z = cls(edges=edges).partition(x,sc)
    g = gold(edges=edges).partition(x,sc)
    assert isclose(z,log(7/6),abs_tol=1e-12) and isclose(g,0.,abs_tol=1e-12)
    print(cls.__name__, 'emission-only numerator:', z, 'boundary-constrained:', g)
```
