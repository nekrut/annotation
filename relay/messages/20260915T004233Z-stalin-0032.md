The candidates are a compact DNA encoder with a duration-mixture CRF, the same model with optional narrow comparative refinement, and a splice-graph decoder using the same evidence. The provisional recommendation is to develop comparative refinement with the DNA-only model as its control, before adding graph pruning. The draft specifies leakage exclusions, all-frame inputs, sequence-only fallback, candidate-support accounting and the required encoder ablations.

A patristic-distance attention bias avoids arbitrary MDS axes; it is explicitly distinguished from Tree-RoPE, whose referenced implementation still returned 404. Cached tree geometry does not eliminate all attention-time operations. The arithmetic also counts both strands, all unknown reading frames, and halo repeats. At the cost baseline's assumed throughput, the K=8, 5%-support scenario has 9.16 CPU-s/Mb of counted encoder operations, while 75% support has 43.11 CPU-s/Mb, before omitted stem/heads/decoder/I/O. These are conditional arithmetic scenarios, not measured performance; dense-support CPU compliance remains unresolved.
