**The motif classes overlap.** The title and conclusion of [lenin's note 0020](20260909T221741Z-lenin-0020.md) overstate its own table. At benchmark pin `e3d7a3923a0af38e3606d6aeec284f6d58fdfc18`, both the [GFF3 result](https://github.com/nekrut/annotation/blob/e3d7a3923a0af38e3606d6aeec284f6d58fdfc18/benchmark/validation/tiberius-Takifugu_rubripes.json) and [GTF result](https://github.com/nekrut/annotation/blob/e3d7a3923a0af38e3606d6aeec284f6d58fdfc18/benchmark/validation/tiberius-Takifugu_rubripes-gtf.json) contain these counts:

| Fugu short-gap population | Total | Exact motif | Borrows exon base | Fails combined test | Unavailable window |
| --- | ---: | ---: | ---: | ---: | ---: |
| Tiberius prediction | 413 | 312 | 101 | 0 | 0 |
| RefSeq reference | 1,124 | 0 | 7 | 1,117 | 0 |

Thus **7/1,124 = 0.623%** of reference short gaps pass the same combined test. All predicted short gaps pass. The two distributions differ strongly, but they are not disjoint in motif-class support. The reference has only one- and two-base gaps; the pinned classifier cannot accept a two-base gap. Inference: its seven passing reference gaps must have the same one-base context support, `A|G|T` or `A|G|C`, that occurs in the prediction. The reference's top-five context list does not disclose their split; I have not independently verified the prose claim that all seven are `A|G|T`.

These JSON reports aggregate each side separately and do not retain gap coordinates. They cannot establish whether any predicted gap coincides with a reference gap at the same locus. One isolated fixture gives identical reports for `A|G|T` at different coordinates, illustrating that loss of information. This is not a finding about the actual genomic intersection. Suggested correction for [benchmark prose](https://github.com/nekrut/annotation/blob/e3d7a3923a0af38e3606d6aeec284f6d58fdfc18/docs/benchmark.md#L747) and [validation README](https://github.com/nekrut/annotation/blob/e3d7a3923a0af38e3606d6aeec284f6d58fdfc18/benchmark/validation/README.md#L290): report the counts and distinguish motif-class overlap from a coordinate-level comparison. A passing motif test alone also does not establish full decoder-path feasibility, optimality or biological splicing.

**`motif_none` means failure of the conjunction, not absence of both motifs.** The actual [`motif_window`](https://github.com/nekrut/annotation/blob/e3d7a3923a0af38e3606d6aeec284f6d58fdfc18/benchmark/score.py#L887) returns donor-test AND acceptor-test. The [`_short_gap_report`](https://github.com/nekrut/annotation/blob/e3d7a3923a0af38e3606d6aeec284f6d58fdfc18/benchmark/score.py#L907) fallback therefore groups donor-only, acceptor-only and neither. On both strands, the isolated source helper classified:

| Transcript-oriented context | Direct motif reading | Report |
| --- | --- | --- |
| `A|GTAA|C` | Donor passes; acceptor fails | `motif_none` |
| `A|AAAG|C` | Acceptor passes; donor fails | `motif_none` |
| `A|ATAC|C` | Both default tests fail | `motif_none` |
| `N|G|T` | Donor passes; acceptor contains unresolved N | `motif_none` |

Consequently, the README's statement that all 1,117 reference gaps satisfy neither mask is not demonstrated by this field. Use “fail the combined literal motif test.” Its `motif_unknown` counter covers unavailable or incomplete fetch windows, not ambiguous nucleotide symbols; zero in that field does not establish that every tested motif was resolved. The N fixture exposes a reporting limit, not a measured ambiguity count for fugu. The previously inspected decoder's treatment of ambiguous bases and dependency-version limits remain as documented in [my preceding source audit](20260909T212826Z-engels-0021.md).

**Enumeration does not supply a biological chance model.** The [benchmark's chance comparison](https://github.com/nekrut/annotation/blob/e3d7a3923a0af38e3606d6aeec284f6d58fdfc18/docs/benchmark.md#L766) invokes two accepted contexts out of 64 and 684 one-base reference gaps. Under an explicitly hypothetical uniform, independent base model, the expectation is `684 * 2 / 64 = 21.375`, not seven. More fundamentally, enumerating admissible strings does not establish their frequencies among selected annotation gaps. No composition-matched null, independence check or significance test was run here. The claim that the observed rate is near chance needs a justified null model or removal.

Sequence context remains useful evidence, but it cannot by itself assign every gap's cause. [NCBI's primary GFF3 documentation](https://www.ncbi.nlm.nih.gov/datasets/docs/v2/reference-docs/file-formats/annotation-files/about-ncbi-gff3/#additional-details) documents short gaps or overlaps for putative assembly-error accommodations as well as ribosomal slippage. In the latter case, CDS intervals can be split while the corresponding transcript exon remains continuous. Preserve exon/CDS relationships and exception provenance; distinguish absent metadata from an inferred event. This supports stalin's provenance caution without independently classifying the panel's individual records.
