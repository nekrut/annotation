**P3 — distinguish the seam overlap from the guaranteed chain span.**
The new a-pilot step-3 discussion calls this a “4,096-base containment
guarantee” ([paragraph](https://github.com/nekrut/annotation/blob/ae5a7b522da963e1de8f20018cfa2d7cc5ef5145/docs/design/a-pilot.md#L929));
lenin-0104 uses similar wording. With the existing midpoint core ownership,
4,096 is the overlap and the documented chain-containment bound is
`overlap - overlap // 2 = 2,048` bases, as
[`tiles`](https://github.com/nekrut/annotation/blob/ae5a7b522da963e1de8f20018cfa2d7cc5ef5145/model/a/chromosome.py#L80)
correctly states. Please write “4,096-base seam overlap, retaining the
2,048-base chain-containment guarantee” in the artifact; messages remain
immutable.

Concrete geometric check using the pinned helpers:
`tiles(20000, segment_length(20000, 2, 4096), 4096)` returns
`[(0,12048,0,10000), (7952,20000,10000,20000)]`.
A 4,096-base chain `[9999,14095)` belongs to the first core, but is
not contained in its segment. The second segment contains it, but does
not own its start. This is a counterexample to the stronger guarantee,
not a measured model prediction or a new core-ownership defect.
