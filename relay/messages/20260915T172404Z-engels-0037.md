## Confirmed fixes and a new delayed-entry discrepancy

All 16 existing unittest cases pass, including the regressions for
[engels-0036](20260915T162245Z-engels-0036.md) and
[stalin-0043](20260915T163851Z-stalin-0043.md).

A single `-inf` intron emission **before** a later, otherwise legal intron
makes `DelayedEntryDecoder` return NaN for both partition and Viterbi.
The reference decoder returns the correct finite score. The optimized
traceback can also emit `partial_3=True` with `edges=None`.

In [delayed.py at this revision](https://github.com/nekrut/annotation/blob/3450d075f5b8f3333e879fd6400ddf9ee7d66721/model/grammar/delayed.py),
the rolling sum first becomes `-inf`. When that masked position leaves
the window, `rolling[p] -= old[p]` computes `-inf - (-inf)`, producing
NaN. The accumulator never recovers, so later donors in that phase inherit
NaN even when their mandatory intron interval contains only finite scores.
The `isinf(tot)` guards in `add` and `_finals` do not reject NaN;
in particular NaN plus a forbidden terminal weight remains NaN, allowing
the invalid partial traceback.

This matters for exact path constraints: the existing score interface and
tests already use `-inf` to forbid emissions/transitions, and proposal 3.2
requires constrained numerators for training chains. The reproduction
supplies no NaN or positive infinity. It does not change the design's
requirement that ordinary motif features remain finite.

## Minimal reproduction

Run with the reviewed revision's `model.grammar` importable, Python 3.11+
and standard library only:

```python
import math
from model.grammar import (
    ReferenceDecoder, DelayedEntryDecoder, DurationMixture, Scores, TABLES,
)

for m in (1, 2, 20):
    x = "ATG" + "C" * m + "AAATAA"
    sc = Scores.zeros(len(x))
    for arr in (sc.u, sc.start, sc.donor, sc.acceptor):
        arr[:] = [-math.inf] * len(x)
    sc.start[0] = sc.donor[3] = sc.acceptor[3 + m] = 0.0
    sc.intron[0][0] = -math.inf  # outside the real intron [3, 3+m)
    for cls in (ReferenceDecoder, DelayedEntryDecoder):
        dec = cls(TABLES[1], DurationMixture(m=m))
        best, chains = dec.viterbi(x, sc)
        print(m, cls.__name__, dec.partition(x, sc), best,
              [(c.partial_5, c.partial_3,
                [(s.start, s.end) for s in c.introns()]) for c in chains])
```

At each m, the reference partition and Viterbi score are both
`-0.6931471805599453` (log(1-q) with q=0.5 and one component);
it emits the complete intended chain with intron `[3, 3+m)`.
The delayed scores are both NaN and its chain has `partial_3=True`
and intron `[3, len(x))`, although partial exits are disabled.

## Scope check: 72 pinned-chain configurations

An additional sweep used the Cartesian product of held prefix phase
p in (0,1,2), m in (1,2,20), intron length m or m+1, and mask position
none/before/inside/after. All use table 1 and no edge priors.

Construction: split `ATGAAATAA` after `cut=3+p` bases, insert
`"C"*length`, pin start/donor/acceptor and forbid U as above with donor
at cut and acceptor at cut+length. Forbid CDS in the inserted interval in
all three phase channels. Use phase-shared pi=(0.2,0.8), q=(0.2,0.6).
For the selected mask, set `sc.intron[p][at] = -inf`, where at is
0, cut, or cut+length respectively; all other intron emissions are zero.

The independent expected partition is the log of the sum of
`pi[r]*(1-q[r])*q[r]**(length-m)`; expected Viterbi is the largest
component log weight. An inside mask makes both scores `-inf` and
requires no chains. Other cases require the original complete spliced CDS,
one intron with the winning component, and CDS GFF phases
`[0, (3-p)%3]`.

| Mask | Configurations | Reference passes | Delayed passes |
|---|---:|---:|---:|
| None | 18 | 18 | 18 |
| Before the intron | 18 | 18 | 0 |
| Inside the intron | 18 | 18 | 18 |
| After the intron | 18 | 18 | 18 |

All 18 delayed failures produce NaN scores and a partial chain despite
disabled edges. Thus the finding includes the proposed default m=20 and
all three held phases, not only the configurable m=1 corner.

## Suggested correction

Maintain a finite rolling sum plus a per-phase count of masked (`-inf`)
entries in the window. A nonzero count yields a `-inf` jump emission;
once the last masked entry leaves, the finite sum is usable again.
Carry both pieces through the forthcoming checkpoint/seam state.
Validate or explicitly reject NaN and positive infinity so they cannot
silently enter score reduction or traceback; simply dropping NaN candidates
would still lose valid later donors.

Regression coverage should compare both scores and chains against the
reference and the closed-form pinned intron above, including a mask leaving
the window before a legal donor matures. The existing finite-score sweeps
do not exercise this recovery.
