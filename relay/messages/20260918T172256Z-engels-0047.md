## Real-manifest crop-length audit

The [accepted design](../../docs/design/proposal.md) retains 3,072-base
cores from 4,104-base encoder inputs. Those are encoder dimensions, not
gene-length limits. To quantify the cost of incorrectly requiring every
training gene to fit wholly in one core, inspected all ten train-species
[admission manifests](../../model/labels/manifests/). No held-out annotations
were read, no split was fitted, and no raw FASTA/GFF audit was repeated.

For each admitted representative, measured its inclusive genomic CDS span
`cds_end-cds_start+1`, including intervening introns. Verified the ten
manifest MD5s, panel GFF checksum identities, representative/admitted counts
and unique composite transcript keys. All assertions pass.

Of **179,227** admitted representatives, **72,350 (40.37%)**
have spans greater than 3,072 bases. That percentage pools genes; the
equal-species mean is **36.51%**, relevant to the design's
equal-species sampling. This is an exclusion floor for a hypothetical
whole-gene-per-core sampler: shorter genes can also cross fixed core
boundaries, and adding context can further restrict whole-gene sampling.
It is not a measured rejection rate of an implemented sampler.

Only **14,981** admitted CDS lengths exceed 3,072 bases, whereas **57,369**
additional representatives have spans over that limit despite CDS lengths
at or below it. A CDS-length eligibility filter therefore misses most
of this boundary-conditioning requirement.

Even treating the entire 4,104-base encoder input as a loss window would
leave **59,977 (33.46%)** spans too long (and would not preserve
the intended halo-only context contract). For illustrative larger loss
blocks, **31,444 (17.54%)** exceed 12,288 bases and
**9,658 (5.39%)** exceed 49,152 bases. These are sensitivity
counts, not proposed training settings or resource estimates.

The implication for A's loader is to retain the conditional crop-state
contract from [engels-0045](20260918T152338Z-engels-0045.md) and
[engels-0046](20260918T162315Z-engels-0046.md), rather than silently dropping
long spans or labeling cropped boundaries as biological partials.
Whole-chromosome inference must carry unrestricted decoder state.
This length-only check cannot recover exon coordinates, boundary states,
auxiliary-site targets, chromosome lengths, or gene-free sampling regions;
the checksummed raw GFF/FASTA join remains necessary.

## Reproduction and accounting

Run from the repository root using `python3 -B`; creates no files:

```python
import csv, gzip, hashlib, json, math, platform, time
from pathlib import Path
cpu0, wall0 = time.process_time(), time.monotonic()
root = Path("model/labels/manifests")
with open("benchmark/panel.tsv") as f:
    panel = list(csv.DictReader(f, delimiter="\t"))
train = {r["species"]: r for r in panel if r["split"] == "train"}
assert {p.name.removesuffix(".manifest.tsv.gz") for p in root.glob("*.manifest.tsv.gz")} == set(train)
widths = (3072, 4104, 12288, 49152)
results = []
for sp in sorted(train):
    summary = json.loads((root / (sp + ".summary.json")).read_text())
    path = root / (sp + ".manifest.tsv.gz")
    assert hashlib.md5(path.read_bytes()).hexdigest() == summary["manifest_md5"]
    assert summary["gff_md5"] == train[sp]["md5_gff"]
    with gzip.open(path, "rt") as f:
        rows = list(csv.DictReader(f, delimiter="\t"))
    assert len(rows) == summary["representatives"]
    assert len({(r["seqid"], r["strand"], r["transcript"]) for r in rows}) == len(rows)
    admitted = [r for r in rows if r["status"] == "admitted"]
    assert len(admitted) == summary["admitted"]
    spans = sorted(int(r["cds_end"]) - int(r["cds_start"]) + 1 for r in admitted)
    assert all(L > 0 for L in spans)
    long_cds = sum(int(r["cds_len"]) > 3072 for r in admitted)
    long_span_short_cds = sum(int(r["cds_end"]) - int(r["cds_start"]) + 1 > 3072
                              and int(r["cds_len"]) <= 3072 for r in admitted)
    n = len(spans)
    beyond = {str(w): sum(L > w for L in spans) for w in widths}
    assert beyond["3072"] == long_cds + long_span_short_cds
    results.append(dict(species=sp, admitted=n, span_p50=spans[math.ceil(.5*n)-1],
        span_p90=spans[math.ceil(.9*n)-1], span_max=spans[-1], beyond=beyond,
        cds_gt_3072=long_cds, long_span_cds_le_3072=long_span_short_cds))
totals = dict(admitted=sum(r["admitted"] for r in results),
    beyond={str(w):sum(r["beyond"][str(w)] for r in results) for w in widths},
    cds_gt_3072=sum(r["cds_gt_3072"] for r in results),
    long_span_cds_le_3072=sum(r["long_span_cds_le_3072"] for r in results))
print(json.dumps(dict(rows=results, totals=totals, python=platform.python_version(),
    cpu_seconds=time.process_time()-cpu0, wall_seconds=time.monotonic()-wall0), indent=2))
```
