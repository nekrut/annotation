## Assembly metadata check before reserving development chromosomes

The [accepted design](../../docs/design/proposal.md), section 2, requires
whole train-species chromosomes reserved for development and background
sampling beyond gene-centered windows. Joined all ten train
[admission manifests](../../model/labels/manifests/) to their pinned
assemblies' NCBI assembly reports, fetched in memory. Verified each report
against NCBI's sibling `md5checksums.txt`, each manifest against its summary,
the panel GFF checksum identities, representative/admitted counts, and
every representative's accession and inclusive coordinates against report
sequence lengths. All checks pass after correcting an assembly-unit
assumption described below. No held-out annotation or raw GFF/FASTA was read.

For this **report inventory only**, candidate sequences have role
`assembled-molecule`, `unlocalized-scaffold`, or `unplaced-scaffold`,
length at least 10,000, and unit `C57BL/6J` for mouse or
`Primary Assembly` for the other nine. This inventory is not a replacement
for the benchmark's GFF-region selection or an approved development split.

Across the ten species, the manifests contain **295** seqids; the report
inventory contains **995**, including **700** absent from the representative
manifests totaling **44,445,020 bases**. "Without representatives" does not
mean gene-free or suitable negative labels. Some may lack eligible annotation;
the raw GFF/FASTA join must establish their status and reconcile the actual
benchmark sequence denominator. A loader that enumerates only admission
rows cannot make that determination.

Three concrete selection hazards:

- Drosophila's report assigns four assembled chromosome-arm sequences to
  `NT_` accessions: 2L=`NT_033779.5` (2,483 admitted), 2R=`NT_033778.4`
  (2,629), 3L=`NT_037436.4` (2,554), 3R=`NT_033777.3` (3,151).
  Requiring an `NC_` prefix would discard **10,817** admitted targets.
- Mouse's nuclear assembly unit is **C57BL/6J**, not the literal string
  `Primary Assembly`. My first inventory assertion exposed this assumption
  and stopped; the corrected pass uses the explicit unit above. Among its
  admitted targets, **48** lie on **12** unlocalized scaffolds assigned to
  chromosomes 1, 5, 7, X or Y. Grouping only individual accessions does not
  enforce the planned parent-chromosome split.
- Neurospora's seven main assembled molecules have location/type
  **Linkage Group**. Requiring the literal type `Chromosome` would omit
  all **9,722** admitted targets. Conversely, `assembled-molecule` alone
  also includes Dictyostelium's **Ddp5 plasmid**, `NC_001889.1`, with
  **6** already-admitted targets. This is a reconciliation item for the raw
  reference and nuclear-scope rule before freezing the sequence manifest;
  no admission labels or scoring policy changed here.

Loader implication: bind identities to assembly accessions and explicit
sequence roles, declare Drosophila arm grouping, and keep assigned
unlocalized scaffolds with their parent group. Record a separate policy for
unplaced sequences. Derive the full sequence universe from checksummed source
data, then join admission masks; do not infer chromosomes from accession
prefixes or infer background from missing admission rows. A split manifest
must cover both orientations and be fixed before fitting.

Run from the repository root with `python3 -B`; the code makes read-only
network requests and creates no files:

```python
import csv,gzip,hashlib,json,platform,time,urllib.request
from collections import Counter
from pathlib import Path
cpu0,wall0=time.process_time(),time.monotonic()
root=Path("model/labels/manifests")
with open("benchmark/panel.tsv") as f:
    panel=[r for r in csv.DictReader(f,delimiter="\t") if r["split"]=="train"]
def get(url):
    req=urllib.request.Request(url,headers={"User-Agent":"relay-benchmark/0.1 (https://github.com/nekrut/annotation)"})
    with urllib.request.urlopen(req,timeout=25) as resp: return resp.read()
out=[]
for p in sorted(panel,key=lambda r:r["species"]):
    sp=p["species"]; summary=json.loads((root/(sp+".summary.json")).read_text())
    manifest=root/(sp+".manifest.tsv.gz")
    assert hashlib.md5(manifest.read_bytes()).hexdigest()==summary["manifest_md5"]
    assert summary["gff_md5"]==p["md5_gff"]
    with gzip.open(manifest,"rt") as f: rows=list(csv.DictReader(f,delimiter="\t"))
    assert len(rows)==summary["representatives"]
    assert sum(r["status"]=="admitted" for r in rows)==summary["admitted"]
    accession=p["accession"]; prefix,digits=accession.split("_"); digits=digits.split(".")[0]
    stem=p["ftp_dir"]
    base="https://ftp.ncbi.nlm.nih.gov/genomes/all/"+prefix+"/"+"/".join(digits[i:i+3] for i in (0,3,6))+"/"+stem
    name=stem+"_assembly_report.txt"; raw=get(base+"/"+name)
    digest=hashlib.md5(raw).hexdigest()
    sums={line.split()[-1].removeprefix("./"):line.split()[0]
          for line in get(base+"/md5checksums.txt").decode().splitlines() if line.strip()}
    assert sums[name]==digest
    assert "# RefSeq assembly accession: "+accession in raw.decode()
    records=[line.split("\t") for line in raw.decode().splitlines() if line and not line.startswith("#")]
    assert all(len(r)==10 for r in records)
    by_ref={r[6]:r for r in records if r[6]!="na"}
    assert len(by_ref)==sum(r[6]!="na" for r in records)
    represented={r["seqid"] for r in rows}
    assert represented<=by_ref.keys(), (sp,represented-by_ref.keys())
    primary_unit="C57BL/6J" if sp=="Mus_musculus" else "Primary Assembly"
    eligible={r[6]:r for r in records if r[7]==primary_unit
              and r[1] in {"assembled-molecule","unlocalized-scaffold","unplaced-scaffold"}
              and int(r[8])>=10000 and r[6]!="na"}
    assert represented<=eligible.keys(),(sp,represented-eligible.keys())
    for r in rows:
        assert 1<=int(r["cds_start"])<=int(r["cds_end"])<=int(by_ref[r["seqid"]][8])
    roles=Counter(by_ref[r["seqid"]][1] for r in rows if r["status"]=="admitted")
    chromosomes=[r for r in eligible.values() if r[1]=="assembled-molecule" and r[3]=="Chromosome"]
    non_nc=[r for r in chromosomes if not r[6].startswith("NC_")]
    admitted=Counter(r["seqid"] for r in rows if r["status"]=="admitted")
    absent=set(eligible)-represented
    out.append(dict(species=sp,report_md5=digest,url=base+"/"+name,
        representative_seqids=len(represented),eligible_seqids=len(eligible),
        no_representative_seqids=len(absent),no_representative_bp=sum(int(eligible[s][8]) for s in absent),
        assembled_chromosome_seqids=len(chromosomes),
        non_NC_chromosomes=[dict(name=r[0],seqid=r[6],assigned=r[2],admitted=admitted[r[6]]) for r in non_nc],
        admitted_by_role=dict(roles),primary_unit=primary_unit,
        nonchromosomal_molecules=[dict(seqid=r[6],name=r[0],type=r[3],admitted=admitted[r[6]]) for r in eligible.values() if r[1]=="assembled-molecule" and r[3]!="Chromosome"],
        nonassembled_represented=[dict(seqid=s,role=by_ref[s][1],assigned=by_ref[s][2],admitted=admitted[s])
           for s in sorted(represented) if by_ref[s][1]=="unlocalized-scaffold"],
        report_bytes=len(raw)))
print(json.dumps(dict(rows=out,python=platform.python_version(),
    cpu_seconds=time.process_time()-cpu0,wall_seconds=time.monotonic()-wall0),indent=2))
```
