**Paper scope.** [Brůna et al. (2021), DOI 10.1093/nargab/lqaa108](https://doi.org/10.1093/nargab/lqaa108), describes target-genome training, not a frozen cross-species model. For Arabidopsis, worm and fly, protein databases exclude either the target species, its family or its order; the other nine targets use order exclusion. These exclusions concern supporting proteins, not whether target DNA participates in parameter estimation.

Table 3 reports sensitivity against two reference populations: all annotated multi-exon genes, and complete multi-exon genes whose introns have RNA-seq support. Two illustrative rows:

| Target | Gene sensitivity, all (%) | Gene sensitivity, reliable (%) | Reliable fraction (%) |
| --- | ---: | ---: | ---: |
| A. thaliana | 70.2 | 78.8 | 83.5 |
| T. nigroviridis | 10.4 | 67.7 | 11.2 |

These are published sensitivities, not F1 scores. The change of denominator must accompany the figures; it is not an improvement obtained by rerunning the predictor. The paper itself distinguishes the reference populations. [Table 3 and methods](https://academic.oup.com/nargab/article/3/1/lqaa108/6066535).

**What the released selector establishes.** Inspected the paper-linked [BRAKER2-exp repository](https://github.com/gatech-genemark/BRAKER2-exp/tree/34e9d1dfd7228128968063f76b37d29c73a39efc), pinned at `34e9d1dfd7228128968063f76b37d29c73a39efc`.

The [table wrapper](https://github.com/gatech-genemark/BRAKER2-exp/blob/34e9d1dfd7228128968063f76b37d29c73a39efc/bin/complete_supported_subset_table.sh) takes a separately prepared complete annotation, changes its `gap` feature label to `intron`, and calls the selector with `--no_phase`. It reports sensitivity for the supported and all-multi-exon sets. The [selector](https://github.com/gatech-genemark/BRAKER2-exp/blob/34e9d1dfd7228128968063f76b37d29c73a39efc/bin/select_by_introns.pl) groups annotation rows by transcript ID, requires at least one explicit intron, and requires every listed intron's contig, coordinates and strand to occur in the evidence. Phase is omitted in this invocation. Evidence scores are not thresholded by this helper. It neither reads genomic sequence nor independently checks CDS endpoints. Completeness is an upstream input contract; this helper does not establish it. The repository's README points to preprint supplementary methods, so this pin alone does not establish the exact code used for every final-paper result.

**Executed checks.** The actual, unmodified Perl selector passed **32 transcript-selection outcomes**: eight scenarios, on each strand, with phase checking enabled and disabled. Inputs and output used anonymous memory descriptors; no fixture or source files were created. The scenarios were:

- Exact matching introns: retained.
- Shifted outer CDS boundaries with unchanged introns: retained.
- One missing intron match, or evidence on the opposite strand: rejected.
- Evidence phase differing from annotation: rejected by default, retained with `--no_phase`.
- Matching evidence rows with zero in the score column: retained.
- Multiple CDS rows without explicit intron rows, or a single-exon transcript: rejected.

Both modes completed without stderr. This checks the selection rule, not read-mapping quality, reference completeness, or genome-scale accuracy. The zero-score fixture tests the absence of a threshold inside this helper; it does not imply that the published VARUS inputs contained such records. The ordinary-GTF fixture tests the documented enriched-input requirement, not support for arbitrary GTF files.

**Review implication.** I would record target-genome adaptation, protein exclusion rank, and reference selection as separate benchmark fields. Intron support is useful evidence, but it should not be described as independently confirmed complete CDS structure. My inference is that the reliable subset can differ in both label quality and gene difficulty; the reported sensitivity change alone cannot separate those effects. This extends the existing endpoint/provenance cautions without asserting an error in BRAKER2's published predictions.
