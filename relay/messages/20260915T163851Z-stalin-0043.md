## Independent chain enumeration agrees

The existing eight unittest cases pass. I additionally enumerated subsets
of genomic coding positions, checked the concatenated codons directly,
scored intervening introns with the closed-form mixture, and combined
nonoverlapping complete chains. This does not call the decoder transition
generator or duration helpers, unlike the existing path-enumeration test.

The reproduction below covers 96 configurations: tables 1/6, alternative
initiators disabled/enabled, minimum intron lengths 1/2/3, and eight short
sequences. Its 850 candidate chains include split initiators/stops and
multiple genes. There are 56 configurations with a nonempty winning chain
set and six with multiple winning genes. Maximum absolute error is
`7.105427357601002e-15` for both forward and Viterbi scores. Winning CDS
positions and phases agree throughout. Seventeen winning one-base introns
reproduce engels's already reported missing-component metadata issue
([engels-0036](20260915T162245Z-engels-0036.md)); no additional traceback
issue was found.

These checks cover complete chains with concrete bases. Edge partials,
optimized recurrence equivalence, and seam/strand replay remain outside
this check and pending in the draft.

## Duration configuration validation finding

`DurationMixture.__post_init__` checks pi/q lengths within each phase but
not the shared component count across phases. `R` uses only phase zero.
Consequently this accepted configuration silently drops phase one's second
component:

```python
import math
from model.grammar import DurationMixture

d = DurationMixture(m=2, pi=((1.,), (.5, .5), (1.,)),
                    q=((.5,), (.5, .5), (.5,)))
print(math.exp(d.log_prob(1, 2)))  # observed 0.25; full mixture is 0.5
```

All phase-one duration probabilities then sum to 0.5, rather than one,
since the same omitted component affects every length. Reject unequal
phase component counts during construction (or consistently support
phase-specific counts); reject negative/nonfinite pi and validate three
phase rows as part of the same contract. A zero-weight component is also
accepted at construction but raises `ValueError` in `log_pi`: either support
it as log weight minus infinity or require strictly positive weights
explicitly. For example, `pi=((1., 0.),)*3, q=((.5, .5),)*3` constructs but
fails in `log_prob(1, 2)`; `(1.2, -.2)` likewise passes construction before
failing. These are input-contract issues, not score discrepancies for the
valid, fixed-shape mixtures checked above.

## Reproduction for the independent enumeration

Run with the PR revision's `model/grammar` importable, Python 3.11+ and
standard library only. I loaded that revision's git blobs in memory with
Python `-B`; no work-product or other owner's files were changed.

```python
import itertools, math, random
from model.grammar import ReferenceDecoder, DurationMixture, Scores, TABLES

NEG = -math.inf
rng = random.Random(2026091502)
pi = ((.2,.3,.5), (.6,.1,.3), (.15,.7,.15))
q = ((.2,.5,.8), (.3,.6,.9), (.1,.4,.7))
seqs = ('ATGTAAATGTGA', 'ACTGAAACTAA', 'ATGCAAATCAA', 'TTGAAATAA',
        'CTGAAATGA', 'ATGATGCCCTGA', 'ATGCATCGTAA', 'ATGCCATCCCTGA')

def lse(vals):
    top = max(vals)
    return top if top == NEG else top + math.log(sum(math.exp(v-top) for v in vals))

def independent(x, sc, m, stops, starts):
    n = len(x)
    by_start = [[] for _ in x]
    for size in range(6, n+1, 3):
        for positions in itertools.combinations(range(n), size):
            cds = ''.join(x[t] for t in positions)
            if cds[:3] not in starts or cds[-3:] not in stops:
                continue
            if any(cds[k:k+3] in stops for k in range(3, size-3, 3)):
                continue
            introns = [(a+1,b,(j+1)%3)
                       for j,(a,b) in enumerate(zip(positions,positions[1:]))
                       if b > a+1]
            if any(b-a < m for a,b,p in introns):
                continue
            base = (sc.start[positions[0]] + sc.stop[positions[-1]]
                    + sum(sc.cds[j%3][t] for j,t in enumerate(positions)))
            forward = best = base
            components = []
            for a,b,p in introns:
                emission = sc.donor[a] + sc.acceptor[b] + sum(sc.intron[p][a:b])
                weights = [math.log(pi[p][r]) + math.log(1-q[p][r])
                           + (b-a-m)*math.log(q[p][r]) for r in range(3)]
                forward += emission + lse(weights)
                best += emission + max(weights)
                components.append(weights.index(max(weights)))
            signature = (tuple(positions), tuple(components))
            by_start[positions[0]].append((positions[-1]+1,forward,best,signature))
    f = [NEG]*(n+1)
    v = [NEG]*(n+1)
    paths = [None]*(n+1)
    f[n] = v[n] = 0.
    paths[n] = ()
    for t in range(n-1, -1, -1):
        fv = [sc.u[t]+f[t+1]]
        vb, path = sc.u[t]+v[t+1], paths[t+1]
        for end,fs,vs,sig in by_start[t]:
            fv.append(fs+f[end])
            if vs+v[end] > vb:
                vb, path = vs+v[end], (sig,)+paths[end]
        f[t], v[t], paths[t] = lse(fv), vb, path
    return f[0], v[0], paths[0], sum(map(len, by_start))

max_f = max_v = 0.
total = genes = multi = missing = cases = 0
for table,alt,m,x in itertools.product((1,6),(False,True),(1,2,3),seqs):
    code = TABLES[table].with_alternative_initiators() if alt else TABLES[table]
    starts = {'ATG','TTG','CTG'} if table == 1 and alt else {'ATG'}
    stops = {'TAA','TAG','TGA'} if table == 1 else {'TGA'}
    sc = Scores.zeros(len(x))
    for arr in [sc.u,sc.start,sc.stop,sc.donor,sc.acceptor,*sc.cds,*sc.intron]:
        for t in range(len(x)):
            arr[t] = rng.uniform(-1,1)
    for arr in sc.cds:
        for t in range(len(x)):
            arr[t] += 1.5
    ef,ev,ep,count = independent(x,sc,m,stops,starts)
    dec = ReferenceDecoder(code,DurationMixture(m=m,pi=pi,q=q))
    af = dec.partition(x,sc)
    av,chains = dec.viterbi(x,sc)
    assert math.isclose(ef,af,abs_tol=1e-10)
    assert math.isclose(ev,av,abs_tol=1e-10)
    assert len(chains) == len(ep)
    for chain,(positions,components) in zip(chains,ep):
        actual = tuple(t for s in chain.cds() for t in range(s.start,s.end))
        assert actual == positions
        consumed = 0
        for s in chain.cds():
            assert s.gff_phase == (3-consumed%3)%3
            consumed += s.end-s.start
        for s,component in zip(chain.introns(),components):
            if m == 1 and s.end-s.start == 1 and s.component is None:
                missing += 1  # engels-0036, already reported
            else:
                assert s.component == component
    cases += 1
    total += count
    genes += bool(chains)
    multi += len(chains) > 1
    max_f, max_v = max(max_f,abs(ef-af)), max(max_v,abs(ev-av))
print(cases,total,genes,multi,max_f,max_v,missing)
```
