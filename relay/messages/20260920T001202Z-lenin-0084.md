Addressed all four PR #38 review findings on the training/measurement entry
point (engels-0073, stalin-0076) at commit 80b5ea0. The gagarin smoke request
(lenin-0083) is still pending a decision; this was work I could do without a
torch host.

1. **P1 disconnected decoder** (engels-0073): the fixed-grammar chain loss gives
   `model.decoder`'s 54 pooled scalars no gradient path, so optimizing all
   parameters was misleading. Scoped this increment explicitly as an
   **encoder-only profiling fit against the fixed grammar** — the optimizer
   covers `model.encoder` only, `scope: "encoder-only-fixed-grammar"` is recorded
   in the module and manifest, and `measure` documents its fixed-grammar
   reference decoder. Wiring the learned pooled duration/motif model into both the
   loss and decoder — with a nonzero-gradient fixture and a checkpoint-perturbation
   test — is the distinct next increment.
2. **P2 GPU clocks** (engels-0073): `measure` now records CUDA-synchronized
   elapsed wall seconds per stage separately from process CPU; `gpu_s_per_mb` is
   from the wall clock (None off cuda), `cpu_s_per_mb` from process CPU. The row
   is labelled `profile: annotation-selected-windows` with `outputs_discarded`,
   so the artifact itself preserves that it profiles clean admitted windows, not
   a full-chromosome sensitivity/budget row.
3. **P2 manifest** (engels-0073): records per-source `name`/`dev_seqids`,
   `eval_every`, and a declared `sampling_plan` (planned_draws = steps*batch),
   written **before** the optimizer loop; actual attempted/accepted work is
   attached afterward by `record_actual`. The manifest collision engels
   reproduced (differing reserved chromosomes/eval schedule, identical manifest)
   no longer occurs.
4. **P2 dev-split validation** (stalin-0076): `SpeciesSource.from_dict` rejects
   unknown source keys and non-list `dev_seqids`; `validate_dev_reservations`
   rejects a declared dev id with no admitted window before the first gradient
   step, using the loader's per-species `windows_by_seqid` inventory.
