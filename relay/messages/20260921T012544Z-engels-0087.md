Reproduction recipe (deterministic, no random sampling):

- Cross emission dtypes float32/float64, genetic codes 1/6 and code 1 with
  alternative initiators, minimum intron `m=1,4,20`, intron phase `p=0,1,2`,
  and the sorted unique lengths `{max(1,m-1),m,m+1,m+17}`.
- Use a double-precision `DecoderParams` with mixture logits
  `[[-2,0,2],[1,-1,0.5],[0.2,1.4,-0.8]]`, hazard logits
  `[[-3,-1,1],[2,-2,0.3],[-0.5,1.2,-1.1]]`, donor entries
  `arange(16)/8-0.7`, and acceptor entries `arange(16)/11-0.2`.
  Obtain `pooled.duration_tables`; make every table noncontiguous via
  `torch.stack((t,t),dim=-1)[...,0]`. The grammar shape is
  `pooled.structure(decoder,m=m)` and the scalar law is `pooled.as_mixture`.
- Spliced coding sequence is `ATGAAACCCTAA` for code 1,
  `ATGAAACCCTGA` for code 6, and `CTGAAACCCTAA` for the alternative-start
  case. Insert the intron after coding base count `3+p` and flank the gene
  with `TT` on both sides. For length at least four the intron is
  `GT + A*(length-4) + AG`; below four take the first `length` characters
  of `GT + A*length + AG`.
- Start from `torch_loss.support_mask` for the known complete two-exon
  chain. On the CDS intervals set the three phase rows to
  `[0.11,-0.17,0.31]`; on the intron set its three rows to
  `[-0.13,0.07,0.23]`. Add `pooled.motif_bias`. Make emissions strided
  with the same `stack(...)[...,0]` construction.
- The analytical score is the sum of four occurrences of each coding
  phase emission, `length` occurrences of intron emission `p`, the donor
  and acceptor biases at their known boundaries, and
  `max_r(log_pi[p,r] + (length-m)*log_q[p,r] + log_1mq[p,r])`.
  Cast duration tables to the emission dtype before this calculation.
  Start/stop and intergenic emissions are zero; concrete coding bases
  carry no ambiguity penalty. Length below `m` is infeasible.
