[a-pilot section 3.3](https://github.com/nekrut/annotation/blob/7962be3/docs/design/a-pilot.md#33-first-fitted-checkpoint-and-development-scores),
[the scoring README](../artifacts/T-human-014/smoke-local-20260920/fit-cpu-v3/score-final/README.md)

regime for C. elegans. However, the same
[chr V score JSON](../artifacts/T-human-014/smoke-local-20260920/fit-cpu-v3/score-final/score_NC_003283.11_seg19_ov4096_w12288_float64.json)
reports reference intron-length decile cuts
`[45, 46, 48, 51, 56, 95, 199, 370, 695]`. These are calculated over
unique reference introns by
[`splice` / `deciles`](https://github.com/nekrut/annotation/blob/7962be3/benchmark/score.py#L764).
The 615-base predicted median is about eleven times the reference's
50th-percentile cutoff, between its 80th- and 90th-percentile cutoffs.

The floor concentration is sharply reduced, but almost half of v3's

next revision's diagnosis. These distributions do not by themselves

Reproducer for the table, run from the repository root with Python's
standard library only; it writes no files:

```python
from pathlib import Path
import gzip, json, statistics
root = Path('relay/artifacts/T-human-014/smoke-local-20260920')
name = 'NC_003283.11_seg19_ov4096_w12288_float64'
for version in (2, 3):
    d = root / f'fit-cpu-v{version}' / 'score-final'
    score = json.loads((d / f'score_{name}.json').read_text())
    cds = {}
    with gzip.open(d / f'{name}.gff3.gz', 'rt') as fh:
        for line in fh:
            if line.startswith('#'):
                continue
            p = line.rstrip().split('\t')
            if len(p) != 9 or p[2] != 'CDS':
                continue
            attrs = dict(x.split('=', 1) for x in p[8].split(';') if '=' in x)
            cds.setdefault((p[0], p[6], attrs['Parent']), []).append(
                (int(p[3]), int(p[4])))
    introns = set()
    for (seqid, strand, parent), exons in cds.items():
        exons.sort()
        introns.update((seqid, a[1]+1, b[0]-1, strand)
                       for a, b in zip(exons, exons[1:])
                       if b[0]-a[1]-1 >= 20)
    lengths = [e-s+1 for _, s, e, _ in introns]
    assert len(lengths) == score['splice']['predicted_introns']
    print(version, len(lengths), statistics.median(lengths),
          sum(x == 20 for x in lengths), sum(x <= 56 for x in lengths),
          sum(x > 695 for x in lengths),
          score['splice']['intron_length_decile_cuts'])
```
