## A zero reported margin does not certify a unique parse

The ordering check in lenin-0065 is useful, and exact equality should not
be rejected. Its proposed *unique-parse* flag and exact posterior-1
interpretation need a qualification: a floating-point zero margin is not
a count of legal paths.

The executable synthetic check below passes **15 configurations**:
[reference](../../model/grammar/reference.py), [delayed](../../model/grammar/delayed.py),
and delayed with a seam at every interior base, for each of five cases.

- `ATGTAA`, no edge partials, minimum intron 20, has exactly two legal
  terminal paths: all background, or one complete gene. Counting finite
  transitions with integer arithmetic confirms this independently of
  forward/max score reduction. At start reward 40, both decoders return
  `log_partition == viterbi == 40`, although the other path has positive
  mathematical mass. An 80-digit Decimal oracle gives a positive margin
  of about `4.2483542553e-18`.
- With reward 30 and zero base offset, the reported margin is
  `9.2370555649e-14`. Adding the same 6,150 score to each base emission
  of either legal path leaves the mathematical posterior unchanged,
  but both returned scores become `36930.0` and the margin rounds to
  zero. The Decimal margin remains about `9.3576229688e-14`.
- The equal-score control returns the expected positive margin `log(2)`.

This also limits what can be inferred about the saved
[mouse equality case](../../model/labels/manifests/numerator-check/Mus_musculus.json).
The current [checker](../../model/labels/numerator_check.py) uses finite
`Scores.favour` rewards with zero background emissions. Its all-background
path remains legal even when a gene wins. The saved equality is not proof
that only one terminal path is feasible. I did not rerun the mouse source
window or estimate its unresolved posterior mass.

## A positive margin does not certify multiple gene structures

A second fixture hard-masks one complete chain with one 20-base intron,
using the checker's existing duration mixture. It has exactly **three**
finite joint paths, all with identical CDS/intron geometry, one for each
duration component. Its component weights are `0.05, 0.003, 0.0002`.

All three decoder configurations return:

- partition `log(0.0532) = -2.9336968826345386`;
- Viterbi `log(0.05) = -2.9957322735539913`;
- margin `0.06203539091945265`.

The best **joint** path has posterior `0.05/0.0532 =
0.9398496240601504`; the single allowed **gene structure**, summed over
components, has posterior 1. This matches the documented joint Viterbi
semantics; it is not a decoder defect.

For A integration, retain the ordering diagnostic and raw margin, but
describe equality as unresolved at the returned precision. Do not convert
it into a unique-parse certification or use `exp(viterbi - log_partition)`
as a structure confidence. Structure confidence needs a constrained
partition summing the duration/base latent alternatives compatible with
that structure, with the same scores and boundary support.

## Reproduction and accounting

Run from repository root with `python3 -B`; synthetic inputs only, no
network or file writes. The integer path counter uses the reference
transition graph; it independently counts paths, not an independent
implementation of the biological grammar. The source geometry and
closed-form mixture weights supply the structure oracle.

```python
import json,math,platform,resource,time
from decimal import Decimal,localcontext
from model.grammar import ReferenceDecoder,DelayedEntryDecoder,DurationMixture,Scores
from model.labels.numerator_check import DUR
cpu0,wall0=time.process_time(),time.monotonic()
def path_count(x,sc,dur):
    dec=ReferenceDecoder(duration=dur)
    counts={s:1 for s,w in dec.initial().items() if math.isfinite(w)}
    for t in range(len(x)):
        nxt={}
        for s,n in counts.items():
            for k,w,_ in dec.transitions(s,x,t,sc):
                if math.isfinite(w):
                    nxt[k]=nxt.get(k,0)+n
        counts=nxt
    return sum(n for s,n in counts.items() if math.isfinite(dec.terminal(s)))
def configurations(x,sc,dur):
    for name,dec,kw in [
        ("reference",ReferenceDecoder(duration=dur),{}),
        ("delayed",DelayedEntryDecoder(duration=dur),{}),
        ("delayed_all_seams",DelayedEntryDecoder(duration=dur),{"seams":list(range(1,len(x)))})]:
        z=dec.partition(x,sc,**kw)
        v,chains=dec.viterbi(x,sc,**kw)
        assert math.isfinite(z) and math.isfinite(v) and z>=v
        yield name,z,v,chains
out=[]
for gap,offset in [(0,0),(30,0),(30,6150),(40,0)]:
    x="ATGTAA"; sc=Scores.zeros(len(x))
    sc.u[:]=[offset]*len(x)
    for a in sc.cds: a[:]=[offset]*len(x)
    sc.start[0]=gap
    dur=DurationMixture()
    assert path_count(x,sc,dur)==2
    with localcontext() as ctx:
        ctx.prec=80
        other=(-Decimal(gap)).exp()
        exact_margin=(1+other).ln()
        exact_missing=other/(1+other)
        assert exact_margin>0 and exact_missing>0
    for name,z,v,chains in configurations(x,sc,dur):
        assert v==len(x)*offset+gap
        assert abs(z-(v+math.log1p(math.exp(-gap))))<=2*math.ulp(v if v else 1.0)
        if (gap,offset) in [(30,6150),(40,0)]: assert z==v
        out.append(dict(case="two_structures",gap=gap,offset=offset,decoder=name,
            legal_joint_paths=2,log_partition=z,viterbi=v,reported_margin=z-v,
            exact_margin=str(exact_margin),best_path_missing_mass=str(exact_missing)))
x="ATG"+"C"*20+"AAATAA"; n=len(x); neg=-math.inf
sc=Scores.zeros(n); sc.u[:]=[neg]*n
for a in sc.cds+sc.intron: a[:]=[neg]*n
sc.start[:]=[neg]*n; sc.start[0]=0.0
sc.stop[:]=[neg]*n; sc.stop[-1]=0.0
sc.donor[:]=[neg]*n; sc.donor[3]=0.0
sc.acceptor[:]=[neg]*n; sc.acceptor[23]=0.0
for j,t in enumerate(list(range(3))+list(range(23,n))): sc.cds[j%3][t]=0.0
for t in range(3,23): sc.intron[0][t]=0.0
assert path_count(x,sc,DUR)==3
weights=[p*(1-q) for p,q in zip(DUR.pi[0],DUR.q[0])]
for name,z,v,chains in configurations(x,sc,DUR):
    assert math.isclose(z,math.log(sum(weights)),abs_tol=1e-14)
    assert math.isclose(v,math.log(max(weights)),abs_tol=1e-14)
    assert len(chains)==1
    c=chains[0]
    assert [(s.start,s.end) for s in c.cds()]==[(0,3),(23,29)]
    assert [(s.start,s.end) for s in c.introns()]==[(3,23)]
    assert c.introns()[0].component==0 and not c.partial_5 and not c.partial_3
    out.append(dict(case="one_structure_three_components",decoder=name,
        legal_joint_paths=3,legal_structures=1,log_partition=z,viterbi=v,
        reported_margin=z-v,best_joint_posterior=math.exp(v-z),
        structure_posterior=1.0))
print(json.dumps(dict(configurations=len(out),checks=out,
    python=platform.python_version(),cpu_seconds=time.process_time()-cpu0,
    wall_seconds=time.monotonic()-wall0,
    peak_rss_kib=resource.getrusage(resource.RUSAGE_SELF).ru_maxrss),indent=2))
```
