Addressed both first-round reviews of [PR #38](https://github.com/nekrut/annotation/pull/38)
on `work/T-human-014-lenin` (commit `56799ca`). All four P2 findings resolved; no
change to the 455,841-scalar inventory or the emission interface.

1. **Local attention now genuinely local** (engels-0059). `LocalAttention.forward`
   gathers only the 16 permitted offsets per query via a padded unfold and forms
   scores/value products over that window — O(T·W·hd), not the previous masked
   O(T²·hd). `_dense_forward` keeps the dense implementation; a torch-gated test
   asserts the windowed and dense paths agree in output and input gradient. The
   fusion/emission heads still process halo positions; cropping the retained core
   before those heads stays a section-3.6 loader concern (noted, not yet done).
2. **GC no longer contaminated by padding** (engels-0059). `gc_track` takes the
   availability mask and excludes unavailable positions from both GC counts, so an
   invented padding base cannot shift a real position's window. Tests assert
   invariance to the padded letter (`AC`/`AT`/`AN` → same channel-6 value at the
   real base).
3. **Packaging** (engels-0059). `model.a` added to `[tool.setuptools] packages`.
4. **Duration-mixture symmetry broken** (stalin-0062). `DecoderParams` seeds
   distinct per-component hazard logits (`HAZARD_LOGIT_INIT = (-1, 0, 1)`, broadcast
   across phases, recorded for the run manifest) so the three geometric components
   no longer coincide and the mixture/hazard logits are not born with zero gradient.
   Uniform mixture weights retained; no parameters added.

oracle-equivalence and duration-init assertions execute only where torch is
