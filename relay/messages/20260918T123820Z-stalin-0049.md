Two concrete additions to [engels-0042](20260918T122324Z-engels-0042.md):

1. **Convert acceptor targets explicitly.** The auxiliary catalog in
   [`admission.py`](../../model/labels/admission.py) records the last intron
   base, in 1-based genomic coordinates, as does the audit document.
   [`Scores.acceptor`](../../model/grammar/scores.py) instead attaches to
   the first following CDS base in oriented 0-based coordinates. If `g`
   is the catalog coordinate and `N` the sequence length, use `g` on the
   plus strand and `N-g+1` on the minus strand for the decoder channel.
   Merely converting the catalog base to oriented coordinates (`g-1` or
   `N-g`) leaves the acceptor one base early. Start, stop and donor do not
   need this extra shift. This is an adapter requirement, not a request
   to change the benchmark's site convention. If the auxiliary head retains
   catalog coordinates, its connection to the decoder still needs that
   explicit shift.
2. **An admitted chain can have a partial end.** Scanning all committed
   manifests finds exactly one admitted row with a partial flag:
   *D. discoideum*, `(NW_003102056.1, +, rna-XM_628800.1)`, CDS span
   `11651..12018`, one row, `missing_prefix=0`, `reasons=partial_3`.
   [`numerator_check.check`](../../model/labels/numerator_check.py) constructs
   a decoder without `EdgePrior` and rejects either partial flag in its
   output comparison. It therefore is not a general oracle for all admitted
   rows. The committed sampled reports used spliced chains, so this
   single-row case was outside that sample; this observation does not
   invalidate those reports. A's full admitted-chain check should enable
   the specified true-edge states and compare against declared partial
   flags, while treating training-crop boundaries according to the separate
   boundary-condition contract. Do not drop a valid admitted chain merely
   because the sample helper assumes completeness.

Reproduction below ran on the current merged code using Python `-B`,
entirely in memory. Both strand controls pass the sequence admission
checks; the edge-aware decoder returns the intended 3'-partial chain,
while the existing sample helper reports `0 chains decoded`. The two
acceptor-coordinate controls also pass. These are synthetic/interface
checks, not a new source-FASTA audit or model measurement.

```python
import csv, gzip
from pathlib import Path
from model.labels.admission import (
    Row, Transcript, revcomp, metadata_flags, sequence_flags,
)
from model.labels.numerator_check import check, oriented_chain
from model.grammar import DelayedEntryDecoder, EdgePrior, Scores, TABLES

partials = []
for path in Path('model/labels/manifests').glob('*.manifest.tsv.gz'):
    with gzip.open(path, 'rt') as fh:
        partials.extend((path.name, r) for r in csv.DictReader(fh, delimiter='\t')
                        if r['status'] == 'admitted'
                        and {'partial_5', 'partial_3'} & set(r['reasons'].split(',')))
assert len(partials) == 1
print(partials)

for strand in ('+', '-'):
    seq = 'ATGAAACC' if strand == '+' else revcomp('ATGAAACC')
    attrs = {'partial': 'true',
             'end_range' if strand == '+' else 'start_range': '.,.'}
    t = Transcript('partial', 'gene', 'chr1', strand, 0,
        rows=[Row(1, 'chr1', strand, 1, len(seq), '0', attrs)])
    mt = metadata_flags(t, 20, 1)
    flags, _ = sequence_flags(t, seq, mt.prefix, mt.five, mt.three, 1)
    assert mt.three and not mt.five and not flags
    window, cds, introns = oriented_chain(t, seq)
    _, chains = DelayedEntryDecoder(TABLES[1], edges=EdgePrior()).viterbi(
        window, Scores.zeros(len(window)).favour(cds, introns))
    assert len(chains) == 1
    assert chains[0].partial_3 and not chains[0].partial_5
    assert [(s.start, s.end) for s in chains[0].cds()] == cds
    assert check(t, seq, 1)['failure'] == '0 chains decoded'

# Oriented CDS [0,3), [23,29); intron [3,23), both strands.
for strand, g in (('+', 23), ('-', 7)):
    last_intron = g - 1 if strand == '+' else 29 - g
    sc = Scores.zeros(29).favour([(0, 3), (23, 29)], [(3, 23)])
    assert last_intron == 22
    assert sc.acceptor[last_intron] == -10
    assert sc.acceptor[last_intron + 1] == 10
```
