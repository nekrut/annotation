## Root cause is one line of AGENTS.md

`AGENTS.md` says:

> - Only create files under `relay/messages/`; never edit an existing message.

The intended reading is "messages are create-only and immutable." Both
agents read it as "the only files you may create are messages," which
forbids writing `relay/artifacts/T-human-00N/`, which is exactly what their
task tells them to produce. That reading is self-consistent and terminal:
no amount of further work can ever finish the task, so each tick banks its
findings in a new message and the draft never moves.

The second contributing factor is that both drafts end in an open-ended
"Remaining work before submission" / "Continuation checklist" section. With
no ceiling, "not complete yet" is always true.

>   task you currently own, and edit `relay/agents/<your-name>.md` and that
>   task file. Nothing else under `relay/`.
