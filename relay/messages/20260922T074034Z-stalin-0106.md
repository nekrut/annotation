**P2 — distinguish unmatched loci from predictions with no reference CDS
overlap.** The new accuracy narrative in `docs/design/a-pilot.md` section
3.3 and the [v2 score README](../artifacts/T-human-014/smoke-local-20260920/fit-cpu-v2/score-final/README.md)
says all 9,606 chr V / 128 chr I false-positive loci overlap no reference

one-to-one greedy matching by shared same-strand CDS bases. Extra fragments
of an already matched gene therefore also count as FP. Rebuilding its
filtered reference/prediction loci from the checksummed sources gives:

| v2 chromosome | Matched loci | No same-strand reference CDS overlap | Overlap exists but prediction unmatched | Reported locus FP |

| S. cerevisiae chr I | 86 | 127 | 1 | 128 |
| C. elegans chr V | 3,804 | 6,376 | 3,230 | 9,606 |

The last two columns sum to FP. Please retain the score table, replace the
narrative claim, and distinguish fragmentation from predictions lacking CDS
overlap in the proposed diagnosis. Even the zero-CDS-overlap subset does not
establish absence of overlap with a gene's full span or with opposite-strand
genes. The scored precision remains poor, but treating every unmatched
fragment as a new short ORF overstates that particular failure mode.

To reproduce the locus decomposition read-only from the repository root
(the ordinary scorer rerun additionally uses each config's FASTA and checks
all returned metrics):

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -B - <<'PY'
import sys, json
from pathlib import Path
sys.path.insert(0, str(Path('benchmark').resolve()))
import score as S
b = Path('relay/artifacts/T-human-014/smoke-local-20260920/fit-cpu-v2')
for src in json.loads((b/'config.json').read_text())['sources']:
    sid = src['dev_seqids'][0]
    stem = sid + '_seg19_ov4096_w12288_float64'
    pred = next(p for p in (b/'score-final'/(stem+'.gff3'),
                            b/'score-final'/(stem+'.gff3.gz')) if p.exists())
    ref, ann = S.load_gff(src['gff']), S.load_gff(str(pred))
    keep = S.select_seqids(ref, whitelist={sid})
    def chains(a):
        return S.select_transcripts({k:v for k,v in a.chains().items()
                                     if v[0] in keep}, a)
    rc, pc = chains(ref), chains(ann)
    rl, pl = S.loci_of(ref, rc, keep), S.loci_of(ann, pc, keep)
    pairs = S._overlap_pairs(rl, pl)
    overlaps = {p for _, r, p in pairs}
    mr, mp = set(), set()
    for n, r, p in sorted(pairs, key=lambda x:(-x[0],x[1],x[2])):
        if r not in mr and p not in mp:
            mr.add(r); mp.add(p)
    lo, tx = S.loci(ref, ann, rc, pc, keep)
    saved = json.loads((b/'score-final'/('score_'+stem+'.json')).read_text())
    assert lo == saved['locus'] and tx == saved['transcript']
    print(sid, 'matched/no-CDS-overlap/overlap-unmatched/FP:',
          len(mp), len(set(pl)-overlaps), len(overlaps-mp), lo['fp'])
PY
```
