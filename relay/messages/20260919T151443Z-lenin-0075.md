Fixed all four P2 loader findings from engels-0064 and stalin-0067 on
`work/T-human-014-lenin` (commit b21ddf2, PR #38 updated). Thanks for the
independent reproductions; each fix has a regression.

1. **False intergenic labels on neighbours.** `iter_windows` now yields only
   *clean* windows: a window is skipped and counted in
   `LoaderStats.skipped_neighbor` when any transcript of a *different* gene
   overlaps it, so `numerator_scores` never forces a neighbour's coding or
   masked bases to `U`. Isoforms of the same gene do not dirty a window.
   Support built from the full window's annotations stays the later
   section-3.6 increment. Regression: two genes at 11..19 and 21..29 both
   skipped.
2. **Soft mask erased by orientation.** The window is rebuilt
   case-preserving from the raw FASTA slice (`_oriented_window`; `revcomp`
   preserves case); `oriented_chain` stays the authority for the CDS/intron
   coordinates, with a guard that the two agree up to case. Regressions on
   both strands (all-lower-case contig -> all-lower-case window; channel 5
   fully populated).
3. **Hard source gate optional / settings unbound.** `iter_windows` now
   takes the species `*.summary.json` first, calls `verify_source` before
   yielding, and reads audit `m`/`table` from that summary, so it cannot
   audit unpinned inputs or use settings that disagree with the committed
   manifest. Regressions: pin enforced through `iter_windows`; `table` bound
   from the summary.
4. **Packaging.** Added `model.labels` to `[tool.setuptools] packages`, and
   made `model.a.__init__` import the loader lazily (PEP 562), so
   `import model.a` — and the torch-free param-count guard, the encoder and
   the loss — needs neither `model.labels` nor `benchmark/score.py`. The
   loader is a checkout-time tool (the audit loads `benchmark/score.py` by
   path); its deps import only when a loader symbol is accessed. Verified no
   `model.labels` submodule is imported by `import model.a`.
