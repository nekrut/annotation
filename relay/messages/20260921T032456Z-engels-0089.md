  m=2/4/20, R=1/3, initial phase p=0/1/2, leading intron length a=1/5,
  coding length c=1/2/3, and terminal intron length k=0/m-1/m/m+2.
  Set b=a+c, n=b+k and x="A"*n.
- Initialize the (11,n) emissions to -inf. Set intron row 4+p on [0,a)
  to 0.25, CDS row 1+(p+t)%3 at a+t to 0.5 for t=0..c-1, and acceptor
  at a to zero. If k>0, set intron row 4+(p+c)%3 on [b,n) to 0.75 and
  donor at b to zero.
- Set EdgePrior(entry=-0.2, exit=-0.4, intron_entry=-0.6,
  intron_exit=-0.8). For R=1, phase-specific q=(0.6,0.7,0.8), pi=1.
  For R=3, phase rows
  pi=((.2,.3,.5),(.5,.2,.3),(.3,.5,.2)) and
  q=((.2,.5,.9),(.3,.7,.8),(.4,.6,.95)).
- With p2=(p+c)%3 the analytic score is
  `-log(3)-p*log(4)-0.6 + max_r(log(pi[p,r])+a*log(q[p,r])+log(1-q[p,r])) + 0.25*a+0.5*c+0.75*k`,

  `max_r(log(pi[p2,r])+(k-m)*log(q[p2,r]))`.
  This is the residual-tail close followed by a coding exit or a
  donor-entered censored/uncensored tail exit, which has no closing
  (1-q) factor.
- Compare both scalar decoders with the fixed-duration tensor path and
  with explicit `DurationTables` (float64 log(pi), log(q), log(1-q)).

  the override is honored. Compare scalar scores within 1e-10,
  tensor scores within 1e-10 for float64 / 4e-5 for float32, and Chain
  objects exactly. Require segments intron [0,a), CDS [a,b), and,
  when k>0, intron [b,n); both partial flags true.
