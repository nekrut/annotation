## Transcript-ID collisions can admit an incompatible chain

The parser distinguishes `(seqid, strand, tid)`, as does the manifest.
But [_components](https://github.com/nekrut/annotation/blob/c8add4129f680e0419fe6cfc37923441fb813b9e/model/labels/admission.py#L363)
stores only `tid`, and
[metadata/sequence caches](https://github.com/nekrut/annotation/blob/c8add4129f680e0419fe6cfc37923441fb813b9e/model/labels/admission.py#L433)
and [auxiliary representative membership](https://github.com/nekrut/annotation/blob/c8add4129f680e0419fe6cfc37923441fb813b9e/model/labels/admission.py#L501)
also use only `tid`. A later record silently overwrites an unrelated
representative's metadata or FASTA result.

Independent two-sequence fixtures reproduce all three consequences on **both
strands**, with a repeated transcript ID and separate loci:

| Case | Actual | Required |
|---|---|---|
| chrP has `CTGAAATAA`, chrB has `ATGAAATAA`; FASTA order P then B | Both admitted, no reasons | P masked `no_initiator`; B admitted |
| Same GFF, FASTA order B then P | Both masked `no_initiator` | Same result as above, independent of FASTA order |
| Both sequences have `ATGAAATAA`; only P has CDS `exception` | Both admitted, no reasons | P exception-masked; B admitted |
| P's repeated-ID chain overlaps another P locus; B's copy is isolated | All three receive `topology`, while summary says 2 topology-masked | Only the two overlapping P representatives topology-masked |

The first case directly invalidates the claimed constructive legal-numerator
guarantee: the selected ordinary complete target lacks the only enabled
initiator, but its actual sequence failure has been overwritten.

Use the complete parsed identity consistently in every cache, membership set
and lookup, including `topo_masked`, `meta`, `seqf` and `rep_ids`.
Add repeated-ID regressions across both sequences and orientations, and
require invariance to FASTA order. Regenerate the manifests and summaries.

## Impact visible in the committed train manifests

I decompressed all ten manifests and independently recomputed connected
components from each row's sequence, strand, gene and inclusive CDS span.
Their 196,678 rows contain **nine repeated transcript IDs, all in fly**,
covering 18 distinct oriented records. No other species manifest repeats
an ID. Topology components and memberships match for the other nine species.

For fly, the manifest spans yield **234 components and 530 affected
representatives**, but **539 rows carry `topology`**: nine isolated
opposite-strand records inherited their partner's mask. For example,
`rna-NM_176521.1` occurs on `NT_033777.3` at minus-strand
21375060..21377032 and plus-strand 21360390..21361088. Only the minus
record belongs to an overlapping component; both receive `topology`.

The audit document already notes 539 versus 530, but attributes this to IDs
on different sequences. These nine pairs actually share a sequence and
differ in strand; the extra flags are a cache-key bug, not additional
topology conflicts. Each extra row has other recorded masking reasons,
so **nine spurious topology flags does not imply nine recoverable chains**.
A fresh source audit with independent keys is needed to measure corrected
admitted counts and metadata/sequence reasons; I did not rerun source
genome downloads or claim corrected train counts.

import io
from unittest.mock import patch
import model.labels.admission as ad
from tests.test_label_admission import Genome

def audit(g, order=("chrP", "chrB")):
    gff = "##gff-version 3\n" + "".join(
        f"##sequence-region {n} 1 {len(s)}\n" for n, s in g.seqs.items())
    gff += "\n".join(g.lines) + "\n"
    fasta = "".join(f">{n}\n{''.join(g.seqs[n])}\n" for n in order)
    with patch.object(ad, "_open",
                      lambda p: io.StringIO(gff if p == "gff" else fasta)):
        return ad.audit_species("fixture", "gff", "fasta")

def repeat_id(g):
    g.lines = [
        line.replace("t2", "t1") if line.split("\t")[0] == "chrB" else line
        for line in g.lines
    ]

def show(label, g, order=("chrP", "chrB")):
    r = audit(g, order)
    print(label, r.summary["topology_masked"],
          [(x["seqid"], x["transcript"], x["status"], x["reasons"])
           for x in r.manifest_rows])

for strand in ("+", "-"):
    g = Genome()
    g.gene("chrP", strand, 100, ["CTGAAATAA"], [])
    g.gene("chrB", strand, 100, ["ATGAAATAA"], [])
    repeat_id(g)
    show(("sequence", strand, "P-B"), g)
    show(("sequence", strand, "B-P"), g, ("chrB", "chrP"))

    g = Genome()
    g.gene("chrP", strand, 100, ["ATGAAATAA"], [],
           attrs=";exception=ribosomal slippage")
    g.gene("chrB", strand, 100, ["ATGAAATAA"], [])
    repeat_id(g)
    show(("metadata", strand), g)

    g = Genome()
    g.gene("chrP", strand, 100, ["ATGAAA", "TAA"], [60])
    g.gene("chrB", strand, 100, ["ATGAAATAA"], [])
    repeat_id(g)
    g.gene("chrP", strand, 120, ["ATGCCCTAA"], [])
    show(("topology", strand), g)
