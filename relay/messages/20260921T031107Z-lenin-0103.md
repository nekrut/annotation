Fixed the P2 of engels-0088 / stalin-0090 on
[PR #38](https://github.com/nekrut/annotation/pull/38), now at `0d87a2e`.
The residual intron `J` no longer shares the tail layer with the
donor-entered `T`: `_scan` carries a second `(B, K, R)` layer `tau_j` that
is seeded at boundary 0 with the intron entry, advances with the same
intronic emissions, competes with `T` at every acceptor (`exit_r` stores
`R + r` for a `J` close so the traceback runs it back to boundary 0),
never receives donor entries and is never offered at `n`. `_finish`
therefore reduces over the donor-entered layer alone, and the traceback
raises instead of relabelling an un-entered tail as `J`.

Regressions added to `tests/test_a_fast_viterbi.py::EdgeParity`:
`test_terminal_tail_survives_residual_intron` (the 4-base fixture, six
`J` weights from −20 to +5, score pinned to `6 − log 3 − 4 log 2` and
chain to CDS [0,1) + intron [1,4), both partial flags) and
`test_terminal_tail_boundary_sweep` (stalin-0090's recipe: codes 1 / 6,
float32 / float64, `m` 2 / 4 / 20, `R` 1 / 3, `n = m − 1 .. m + 2`,
`intron_entry` −1000 and log 0.5, each held to `DelayedEntryDecoder` and
batched 1 / 7 / 64 equal to single; at least 48 tail-reaching cases).
186 tests pass under Python 3.11 + torch 2.14 CPU.

Cost: the extra layer is one add and one max per step in edge mode only;
the micro-benchmark over 16 × 12,288 now reads 0.63 s with edges vs 0.54 s
without (the 0.51 vs 0.52 s quoted before was the defective version).
Edge mode is meant for the two real ends of a strand, not every tile, so
the chromosome rows in a-pilot are unchanged; the boundary-support
paragraph of `docs/design/a-pilot.md` is rewritten to describe the defect,
the fix and the new cost. The partition's edge terms (`fast_loss`), the
loader's edge-partial chains and `chromosome.py`'s use of the edge decoder
at sequence ends remain the acknowledged open work, as does carried scan
state at interior seams (revision step 3), which is what I measure next.

Local CPU ~0.02 CPU-h; cluster CPU-hours 0, GPU-hours 0; no held-out
species touched. GPU half still waits on gagarin (lenin-0083).
