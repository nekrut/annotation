## Crop-local pending donors and censored training targets

This extends [engels-0045](20260918T152338Z-engels-0045.md) to a
test-only delayed checkpoint constructed directly in crop coordinates.
For consumed intron age k<m, park the known donor at -k and supply k
pending-ring slots and k zero history-emission slots. Only the first
pending slot holds the known S/E coding state. The pre-crop emissions
are conditioned away; their placeholders must not charge them again.
After m-k newly observed intron bases the donor enters the latent tails.
For k>=m, initialize the existing survival-weighted tail distribution.

An internal training crop can also **end inside an intron**, including
one with no observed CDS in that crop. This is a conditional training
target, not the true biological-edge entry/exit prior. At a known
intron-ending crop boundary, sum compatible pending/tail states without
an acceptor, hazard-exit factor, or artificial edge penalty.
For width w, the duration contribution is
`log S(k+w) - log S(k)`, with
`S(a)=sum_r pi_r*q_r**max(a-m,0)`; add only observed intron emissions.
Its mixture-logit gradient is sigma(k+w)-sigma(k), and its
survival-logit gradient is
`[max(k+w-m,0)*sigma_r(k+w)-max(k-m,0)*sigma_r(k)]*(1-q_r)`.
Here sigma(a) is the normalized vector underlying S(a).

**Coordinate hazard:** the merged delayed decoder's pending-exit
summation uses `range(s,n)`, assuming whole-sequence donor coordinates.
It cannot be reused unchanged after rebasing a pre-crop donor to s<0:
Python negative indices can double-count crop emissions (or raise an
index error for a short crop). At age 2, width 5, the reproducer gives
**0.42 instead of 0.15**. The test-only crop finalizer uses
`range(max(s,0),n)`. This is an integration requirement, not a bug in
the existing whole-sequence API's supported inputs. Traceback would also
need explicit boundary handling; this experiment does not implement it.

## Results and reproduction

**924 completed crops + 252 intron-censored crops = 1,176 cases /
2,352 decoder configurations** agree with closed forms, maximum absolute
score error **8.881784197001252e-16**. Completed cases cover both tables
1/6, seven coding splits including split initiators, lengths 20/21/25,
and every consumed intron age. Censored cases cover seven coding splits,
ages 1/2/19/20/21/24 and widths 1/2/7/19/20/25. Three duration components
and nonzero phase-dependent intron emissions are used throughout.
Delayed continuation checkpoints at every interior boundary.

**3,024 central finite differences** for the censored duration gradients
pass, maximum absolute error **2.2283952461066292e-10**.
Forbidding one observed emission rejects the target in all **2,352**
configurations. These are scalar oracles, not learned-loss/autograd tests.
The seed requires known donor age and exact coding prefix; unknown
boundaries, real-data adapters, reverse-strand joins, traceback and
throughput remain outside this check.

Run from the repository root with `python3 -B`; creates no files:

```python
import itertools, json, math, platform, time
from collections import deque
from model.grammar import ReferenceDecoder, DelayedEntryDecoder, DurationMixture, Scores, TABLES
from model.grammar.delayed import Checkpoint
from model.grammar.reference import logsumexp
NEG = -math.inf
M = 20
THETA = [-1., .2, .9, -1.3, .1, 1.4]

def duration(v):
    z = logsumexp(v[:3])
    pi = tuple(math.exp(t-z) for t in v[:3])
    q = tuple(1/(1+math.exp(-t)) for t in v[3:])
    return DurationMixture(m=M, pi=(pi,)*3, q=(q,)*3)

def survival(d, p, age):
    return logsumexp([d.log_pi(p,r)+max(age-M,0)*d.log_q(p,r) for r in range(d.R)])

def seed(d, c, age):
    if age < M:
        return {('I',c,age):0.}
    p = len(c[1]); norm = survival(d,p,age)
    return {('T',c,r):d.log_pi(p,r)+(age-M)*d.log_q(p,r)-norm for r in range(d.R)}

class Crop(ReferenceDecoder):
    def __init__(self, code, d, c, age, censored):
        super().__init__(code,d)
        self.seed, self.c, self.censored = seed(d,c,age), c, censored
    def initial(self):
        return self.seed
    def terminal(self,s):
        allowed = s[0] in ('I','T') and s[1] == self.c if self.censored else s == ('U',)
        return 0. if allowed else NEG

def delayed(code,d,c,age,x,sc,censored):
    cp = Checkpoint.initial({} if age < M else seed(d,c,age))
    if age < M:
        cp.pending = deque((s,{c:0.} if s == -age else {}) for s in range(-age,0))
        cp.window = deque([0.,0.,0.] for _ in range(age))
    dec = DelayedEntryDecoder(code,d)
    # Resume at every interior boundary using copies of the checkpoint.
    for end in range(1,len(x)+1):
        _,_,cp = dec._run_chunk(x,sc,False,cp.copy(),end,retain=False)
    if not censored:
        return cp.layer.get(('U',),NEG)
    vals = [w for s,w in cp.layer.items() if s[0] == 'T' and s[1] == c]
    # Only observed crop emissions belong to a donor preceding the crop.
    for s,parked in cp.pending:
        if c in parked:
            vals.append(parked[c]+sum(sc.intron[len(c[1])][max(0,s):len(x)]))
    return logsumexp(vals) if vals else NEG

def fixture(cut,remaining,censored):
    cds = 'ATGAAATGA'; p = cut%3
    c = ('S',cds[:cut]) if cut < 3 else ('E',cds[cut-p:cut] if p else '')
    x = 'C'*remaining + ('' if censored else cds[cut:])
    sc = Scores.zeros(len(x))
    for _,arr in sc.channels(): arr[:] = [NEG]*len(x)
    for t in range(remaining): sc.intron[p][t] = .07*((t%5)-2)+.03*p
    if not censored:
        phase = p
        for t in range(remaining,len(x)):
            sc.cds[phase][t] = 0.; phase = (phase+1)%3
        sc.acceptor[remaining] = sc.stop[-1] = 0.
    return x,sc,c

def calc(v,table,c,age,x,sc,censored,which):
    d = duration(v)
    if which == 'reference':
        return Crop(TABLES[table],d,c,age,censored).partition(x,sc)
    return delayed(TABLES[table],d,c,age,x,sc,censored)

def gradient(v,p,age,width):
    d = duration(v); out = []
    weights = []
    for k in (age,age+width):
        a = max(k-M,0)
        w = [math.exp(d.log_pi(p,r)+a*d.log_q(p,r)-survival(d,p,k)) for r in range(d.R)]
        weights.append((a,w))
    (a,wa),(b,wb) = weights
    return [wb[r]-wa[r] for r in range(d.R)] + [
        (b*wb[r]-a*wa[r])*(1-d.q[p][r]) for r in range(d.R)]

def fd(f):
    out = []
    for j in range(6):
        lo,hi = THETA.copy(),THETA.copy(); h = 1e-5
        lo[j] -= h; hi[j] += h
        out.append((f(hi)-f(lo))/(2*h))
    return out

cpu0,wall0 = time.process_time(),time.monotonic()
completed=censored_cases=checks=masked=0; score_err=grad_err=0.
d = duration(THETA)
cases = [(table,cut,age,length-age,False)
    for table,cut,length in itertools.product((1,6),(1,2,3,4,5,7,8),(20,21,25))
    for age in range(1,length+1)]
cases += [(1,cut,age,width,True)
    for cut,age,width in itertools.product((1,2,3,4,5,7,8),(1,2,19,20,21,24),(1,2,7,19,20,25))]
for table,cut,age,width,censored in cases:
    x,sc,c = fixture(cut,width,censored); p = len(c[1])
    emit = sum(sc.intron[p][:width])
    expected = emit + (survival(d,p,age+width) if censored else d.log_prob(p,age+width)) - survival(d,p,age)
    for which in ('reference','delayed'):
        f = lambda v: calc(v,table,c,age,x,sc,censored,which)
        error = abs(f(THETA)-expected)
        assert error < 1e-11, (table,cut,age,width,censored,which,error)
        score_err = max(score_err,error)
        if censored:
            err = max(abs(a-b) for a,b in zip(fd(f),gradient(THETA,p,age,width)))
            assert err < 2e-8, (cut,age,width,which,err)
            grad_err = max(grad_err,err); checks += 6
    # Forbid one observed emission: neither seeded recurrence may recover a path.
    arr,t = (sc.intron[p],width//2) if width else (sc.cds[p],0)
    arr[t] = NEG
    for which in ('reference','delayed'):
        assert calc(THETA,table,c,age,x,sc,censored,which) == NEG
        masked += 1
    censored_cases += censored
    completed += not censored
# Original pending-exit summation cannot be reused for negative donor coordinates.
x,sc,c = fixture(4,5,True)
correct = sum(sc.intron[1][0:5])
naive = sum(sc.intron[1][j] for j in range(-2,5))
assert abs(correct-naive) > .1
print(json.dumps(dict(completed_crops=completed,censored_crops=censored_cases,
    decoder_configurations=2*len(cases),masked_rejections=masked,
    censored_finite_differences=checks,max_score_error=score_err,
    max_gradient_error=grad_err,pending_exit_correct=correct,
    pending_exit_naive_negative_indices=naive,
    python=platform.python_version(),cpu_seconds=time.process_time()-cpu0,
    wall_seconds=time.monotonic()-wall0)))
```
