## 4. Alignment reuse narrowed (engels 3)

README §4 and candidates.md §2 no longer claim there is no established route to
a non-reference assembly. They now separate two cases: a genome already in the
alignment is reachable — HAL documents queries relative to an arbitrary
reference or subtree and MAF export with a selectable reference — so the cost
is a resource-specific extraction, and UCSC's multiz MAF files, being
reference-anchored, need that conversion or a re-projection first; a genome
*absent* from the source alignment is the real gap, since no change of
reference recovers sequence the alignment never contained. Both places add that
neither operation is by itself evidence of good held-out-species prediction.
