## GENSCAN confidence is an exon marginal under a specified model

Equation 3 sums the probabilities of all parses containing a particular phase-specific exon, using forward/backward calculations. The highest-probability parse is a separate quantity. The reported confidence experiment used the Burset/Guigo set, which overlaps training; the paper's independent GeneParser tests report accuracy separately. [Burge and Karlin (1997), DOI 10.1006/jmbi.1997.0951, pp. 81 and 87](https://www.cs.rice.edu/~devika/comp470/papers/burge97prediction.pdf).

## Independent evidence uses an averaging convention that matters

HMR195 contains selected complete single-gene human/mouse/rat sequences; alternative splicing, pseudogenes and noncanonical splice sites were excluded. Exon boundaries were checked against independent mRNA alignments; start/stop annotations remained unconfirmed. [Rogic, Mackworth and Ouellette (2001), DOI 10.1101/gr.147901, Methods](https://www.cs.rice.edu/~nakhleh/COMP571/Fall05/GeneFinding/Evaluation.pdf#page=12).

Table 6 says CRp is averaged over sequences within each partition. Therefore, multiplying these values by exon counts does not recover pooled correct-exon counts. The highest bin holds 481/977 = 49.23% of predictions (my count arithmetic), not 49.23% of reference exons. This is evidence for useful ranking, not a matched replication of the original calibration curve. ## A decoder-design check: marginal confidences cannot be multiplied freely

This is my mathematical illustration, not a predictor measurement. Let four binary events mean that each of four proposed exons is correct. Two valid joint distributions give every event probability 0.95:

- Shared failure: all four are correct with probability 0.95; all four fail with probability 0.05. Their joint correctness is 0.95.
- Separate failures: all four are correct with probability 0.80; each of the four outcomes with exactly one failed exon has probability 0.05. Their joint correctness is 0.80.

The independence product is `0.95**4 = 0.81450625`; independence is an additional assumption. The general intersection bounds give `max(0, sum(p_i) - 3) = 0.80` and `min(p_i) = 0.95`, and these examples attain them. Even joint correctness of listed exons need not establish transcript correctness if extra/missing exons or ends are possible.

The exact rational-arithmetic check ran in memory:

```python
from fractions import Fraction as F
shared = {(1, 1, 1, 1): F(95, 100), (0, 0, 0, 0): F(5, 100)}
separate = {(1, 1, 1, 1): F(80, 100)}
for i in range(4):
    state = [1] * 4
    state[i] = 0
    separate[tuple(state)] = F(5, 100)
for distribution in (shared, separate):
    assert sum(distribution.values()) == 1
    for i in range(4):
        assert sum(p for s, p in distribution.items() if s[i]) == F(95, 100)
assert shared[(1, 1, 1, 1)] == F(95, 100)
assert separate[(1, 1, 1, 1)] == F(80, 100)
```

My recommendation for later design/evaluation: retain distinct exon-marginal and complete-structure confidence fields; evaluate calibration and error-versus-retained-prediction curves on held-out species; declare pooled versus per-sequence averaging; and report reference recall beside retention of predictions. Freeze any confidence threshold or recalibration on training/validation data. These are proposals for the eventual design, not changes to another owner's benchmark.
