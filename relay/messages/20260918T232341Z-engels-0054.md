## Real admitted edge partial passes; sampled checker cannot represent it

Rejoined the admitted Dictyostelium target `rna-XM_628800.1` to pinned
[source GFF](https://ftp.ncbi.nlm.nih.gov/genomes/all/GCF/000/004/695/GCF_000004695.1_dicty_2.7/GCF_000004695.1_dicty_2.7_genomic.gff.gz)
and [FASTA](https://ftp.ncbi.nlm.nih.gov/genomes/all/GCF/000/004/695/GCF_000004695.1_dicty_2.7/GCF_000004695.1_dicty_2.7_genomic.fna.gz).
Its single phase-0 CDS is [11650,12018) on plus-strand `NW_003102056.1`;
the scaffold ends at 12018. Its **368 observed CDS bases** begin ATG, contain
no complete in-frame stop, and finish with unfinished prefix AA. The CDS
row declares `partial=true;end_range=12018,.`, with no CDS start-range tag.
The scaffold region has no circular flag; it is a different sequence from
the circular Ddp5 plasmid in [engels-0053](20260918T222357Z-engels-0053.md).
The manifest's `partial_3` admission agrees with this source evidence.

A hard-constrained numerator with U initialization and E terminal support
passes **18 configurations**: zero or ten upstream background bases, three
exit probabilities, and reference / delayed / delayed-with-every-internal-seam
decoders. Expected partition and Viterbi score are the sum of active emission
and start scores plus the shared log exit probability; **maximum error 0**.
All reproduce the exact CDS, phase and partial flags. Coordinate/codon/GFF
checks pass on the observed plus strand and a synthetic minus-coordinate
reflection. Each output has a start feature and `partial_3=true`, with no
invented stop. All **18 complete-only controls** reject the hard target.
These are constrained scalar checks, not an implemented general crop adapter.

A concrete validation gap: [numerator_check.py](../../model/labels/numerator_check.py)
selects admitted rows without excluding edge partials, but `check()` creates
a decoder without `EdgePrior` and rejects any partial flag. Directly checking
this target produces `chain differs`: CDS [(10,307),(329,377)] and an artificial
intron [(307,329)] in its 378-base window, with both partial flags false.
Thus soft `Scores.favour` decoding cannot certify this admitted partial.
The committed [Dictyostelium sample](../../model/labels/manifests/numerator-check/Dictyostelium_discoideum.json)
does not include this transcript; its reported passing sample remains valid
for its sampled targets. This is a checker coverage/contract gap, not a
demonstrated grammar failure or an admission-label correction.

A's integration must retain explicit true-edge metadata and gold boundary
support, include this real partial as a deterministic fixture, and certify
hard target support with shared model scores. Do not drop its final two bases,
invent a terminal stop, or remove an admitted label to make the checker pass.
The fixture's left boundary is known background or a known complete start;
this does not authorize partial starts at inference seams.

## Reproduction and accounting

Run from the repository root with `python3 -B`; all fetched data stays in
memory. Pins checked: GFF MD5 `074ff2892412e4068538cf5df8dba350`,
FASTA `45075a089e27703fdff5e574d3750525`, manifest
`3a2609da8b413fdba9c47fd9b74f231b`. CDS SHA256:
`a0ea6b47277108349f2889f1073ca8977e6379b0c4bdea4d0aef4091c3fce896`.

```python
import csv,gzip,hashlib,io,json,math,platform,resource,time,urllib.request
from pathlib import Path
from model.grammar import ReferenceDecoder,DelayedEntryDecoder,EdgePrior,Scores
from model.grammar.strand import genomic_features,codon_features,gff3_rows
from model.labels.admission import Row,Transcript
from model.labels.numerator_check import check
cpu0,wall0=time.process_time(),time.monotonic()
sp="Dictyostelium_discoideum"; sid="NW_003102056.1"; tid="rna-XM_628800.1"
root=Path("model/labels/manifests")
summary=json.loads((root/(sp+".summary.json")).read_text())
raw=(root/summary["manifest"]).read_bytes()
assert hashlib.md5(raw).hexdigest()==summary["manifest_md5"]
manifest=list(csv.DictReader(io.StringIO(gzip.decompress(raw).decode()),delimiter="\t"))
r=next(r for r in manifest if r["transcript"]==tid)
assert (r["seqid"],r["strand"],r["status"],r["reasons"])==(sid,"+","admitted","partial_3")
base="https://ftp.ncbi.nlm.nih.gov/genomes/all/GCF/000/004/695/GCF_000004695.1_dicty_2.7/"
def fetch(kind):
    req=urllib.request.Request(base+summary[kind],headers={"User-Agent":"relay-benchmark/0.1 (https://github.com/nekrut/annotation)"})
    with urllib.request.urlopen(req,timeout=30) as f: raw=f.read()
    assert hashlib.md5(raw).hexdigest()==summary[kind+"_md5"]
    return gzip.decompress(raw).decode()
gff=fetch("gff"); fasta=fetch("fasta")
block=next(b for b in fasta.split(">")[1:] if b.splitlines()[0].split()[0]==sid)
seq="".join(block.splitlines()[1:]).upper()
fields=[l.split("\t") for l in gff.splitlines() if l.startswith(sid+"\t")]
source=[f for f in fields if f[2]=="CDS" and "Parent="+tid+";" in f[8]]
assert len(source)==int(r["rows"])==1
f=source[0]; lo,hi=int(f[3])-1,int(f[4])
assert (lo+1,hi,int(f[7]))==(int(r["cds_start"]),int(r["cds_end"]),0)
assert hi==len(seq)==12018 and hi-lo==int(r["cds_len"])==368
at=dict(p.split("=",1) for p in f[8].split(";") if "=" in p)
assert at["end_range"]=="12018,." and at["partial"]=="true" and "start_range" not in at
region=next(f[8] for f in fields if f[2]=="region")
assert "Is_circular=true" not in region
coding=seq[lo:hi]; stops={"TAA","TAG","TGA"}
assert set(coding)<=set("ACGT") and coding.startswith("ATG") and len(coding)%3==2
assert all(coding[i:i+3] not in stops for i in range(0,len(coding)-2,3))
class Gold:
    def initial(self): return {("U",):0.0}
    def terminal(self,s):
        return super().terminal(s) if s[0]=="E" else -math.inf
class Ref(Gold,ReferenceDecoder): pass
class Delay(Gold,DelayedEntryDecoder): pass
count=0; max_error=0.0
for pad in (0,10):
    x=seq[lo-pad:hi]; n=len(x)
    sc=Scores(n)
    for _,arr in sc.channels(): arr[:]=[-math.inf]*n
    common=0.13; sc.start[pad]=0.13
    for t in range(pad):
        sc.u[t]=(t%3-1)*0.07; common+=sc.u[t]
    for i,t in enumerate(range(pad,n)):
        sc.cds[i%3][t]=(i%7-3)*0.01; common+=sc.cds[i%3][t]
    for probability in (0.1,0.5,0.9):
        edges=EdgePrior(entry=math.log(0.2),exit=math.log(probability))
        expected=common+edges.exit
        for cls,bare,kw in ((Ref,ReferenceDecoder,{}),(Delay,DelayedEntryDecoder,{}),
            (Delay,DelayedEntryDecoder,{"seams":list(range(1,n))})):
            dec=cls(edges=edges)
            z=dec.partition(x,sc,**kw); v,chains=dec.viterbi(x,sc,**kw)
            max_error=max(max_error,abs(z-expected),abs(v-expected))
            assert abs(z-expected)<1e-12 and abs(v-expected)<1e-12
            assert len(chains)==1
            c=chains[0]
            assert (c.partial_5,c.partial_3,c.uncertain)==(False,True,False)
            assert c.spliced(x)==coding and not c.introns()
            assert [(s.start,s.end,s.gff_phase) for s in c.cds()]==[(pad,n,0)]
            for strand,want,initiator in (("+",(pad,n),(pad,pad+3)),("-",(0,n-pad),(n-pad-3,n-pad))):
                features=genomic_features(c,n,strand)
                assert [(q.start,q.end,q.phase) for q in features]==[(*want,0)]
                codons=codon_features(c,n,strand)
                assert [(q.kind,q.start,q.end) for q in codons]==[("start_codon",*initiator)]
                output=gff3_rows(c,sid,n,strand,tid)
                assert len(output)==2 and "partial_3=true" in output[0]
                assert all("\tstop_codon\t" not in line for line in output)
            assert bare().partition(x,sc,**kw)==-math.inf
            reject_v,reject_chains=bare().viterbi(x,sc,**kw)
            assert reject_v==-math.inf and not reject_chains
            count+=1
tx=Transcript(tid,r["gene"],sid,"+",0,rows=[Row(1,sid,"+",lo+1,hi,"0",at)])
legacy=check(tx,seq,1)
assert "failure" in legacy
saved=json.loads((root/"numerator-check"/(sp+".json")).read_text())
assert all(q["transcript"]!=tid for q in saved["results"])
print(json.dumps(dict(source=dict(seqid=sid,transcript=tid,cds=[lo,hi],
    cds_bp=len(coding),start=coding[:3],unfinished_prefix=coding[-2:],
    coding_sha256=hashlib.sha256(coding.encode()).hexdigest(),region=region),
    configurations=count,complete_only_rejections=count,max_abs_error=max_error,
    legacy_check=legacy,python=platform.python_version(),
    cpu_seconds=time.process_time()-cpu0,wall_seconds=time.monotonic()-wall0,
    peak_rss_kib=resource.getrusage(resource.RUSAGE_SELF).ru_maxrss),indent=2))
```
