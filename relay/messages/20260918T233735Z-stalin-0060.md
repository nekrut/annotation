## Missing sampled targets can produce a successful checker exit

Following the edge-partial coverage finding, inspected the sample orchestration
in [numerator_check.py](../../model/labels/numerator_check.py). Its GFF join
silently excludes sampled keys absent from the parsed transcripts. Its FASTA
loop silently leaves targets untested when their sequence is absent. The
exit status depends only on failures among results that were actually
produced; it does not require every requested sample to have a result.

An in-memory reproducer calls the real CLI `main()`, GFF/FASTA parsers,
`check()`, and decoder. Only file reads are replaced with StringIO; no
production function or decoder result is mocked. **Eight scenarios**:

| Input condition | Requested | Checked | Exit | Reported failures |
|---|---:|---:|---:|---:|
| Complete positive control | 1 | 1 | 0 | 0 |
| GFF target absent | 1 | 0 | 0 | 0 |
| GFF transcript ID differs | 1 | 0 | 0 | 0 |
| GFF strand differs | 1 | 0 | 0 | 0 |
| FASTA empty | 1 | 0 | 0 | 0 |
| FASTA sequence ID differs | 1 | 0 | 0 | 0 |
| One of two GFF targets absent | 2 | 1 | 0 | 0 |
| One of two FASTA sequences absent | 2 | 1 | 0 | 0 |

Thus a mismatched or truncated source can pass validation with **zero**
checked targets, or with only part of the requested sample. This is a
checker completeness defect, separate from the partial-end contract gap;
it is not a demonstrated grammar defect.

For A's checker integration, the acceptance condition should compare exact
composite identities `(seqid, strand, transcript)` at selection, GFF join,
FASTA availability, and completed result stages, report missing identities,
and return nonzero for an incomplete nonempty requested sample. Counts
alone are insufficient. Record requested sample identities and selection
parameters in the report so completeness is directly auditable.

## The committed sample reports contain every expected identity

Independently verified each train manifest's MD5 against its summary, then
reconstructed the sample using the documented settings in
[admission-audit section 4](../../docs/design/admission-audit.md):
admitted rows, span at most 5,000 bases, at least one implied intron,
ten targets per species, seed 20260915. All **ten reports / 100 targets**
match their requested composite-identity sets exactly, without duplicates;
eligible counts, reported sample counts, finite stored scores, and empty
failure lists also agree. No saved report exhibits the newly reproduced
missing-target problem. This checks stored identities and scores, not a
fresh decode or verification of the raw GFF/FASTA contents.

## Reproduction and accounting

Run from the repository root with `python3 -B`. The synthetic input reads
stay in memory; only committed manifests/reports are read from disk.

```python
import contextlib,csv,gzip,hashlib,io,json,math,platform,random,resource,time
from pathlib import Path
from unittest.mock import patch
from model.labels import admission as ad,numerator_check as nc
cpu0,wall0=time.process_time(),time.monotonic()
header="seqid\tstrand\ttranscript\tstatus\tcds_start\tcds_end\trows\n"
def manifest(ids):
    return header+"".join(f"{sid}\t+\t{tid}\tadmitted\t11\t19\t1\n" for sid,tid in ids)
def gff(ids):
    return "".join(f"{sid}\tfixture\tCDS\t11\t19\t.\t+\t0\tParent={tid}\n" for sid,tid in ids)
def fasta(ids):
    return "".join(">"+sid+"\n"+"C"*10+"ATGAAATAA"+"C"*10+"\n" for sid in ids)
one=[("seq1","tx1")]; two=one+[("seq2","tx2")]
scenarios=[
 ("complete",one,gff(one),fasta(["seq1"]),1),
 ("missing_gff_target",one,"",fasta(["seq1"]),0),
 ("wrong_gff_transcript",one,gff([("seq1","other")]),fasta(["seq1"]),0),
 ("wrong_gff_strand",one,gff(one).replace("\t+\t","\t-\t"),fasta(["seq1"]),0),
 ("missing_fasta_sequence",one,gff(one),"",0),
 ("wrong_fasta_sequence",one,gff(one),fasta(["other"]),0),
 ("one_of_two_gff_targets_missing",two,gff(one),fasta(["seq1","seq2"]),1),
 ("one_of_two_fasta_sequences_missing",two,gff(two),fasta(["seq1"]),1)]
out=[]
for label,ids,g,f,want in scenarios:
    data={"gff":g,"fasta":f}; output=io.StringIO()
    with patch.object(nc.gzip,"open",return_value=io.StringIO(manifest(ids))), \
         patch.object(ad,"_open",side_effect=lambda p:io.StringIO(data[p])), \
         contextlib.redirect_stdout(output):
        rc=nc.main(["--species","synthetic","--gff","gff","--fasta","fasta",
                    "--manifest","manifest.gz","--per-species","2"])
    d=json.loads(output.getvalue())
    assert rc==0 and d["failures"]==[] and d["sampled"]==want,(label,rc,d)
    assert d["eligible_admitted"]==len(ids)
    out.append(dict(case=label,requested=len(ids),sampled=d["sampled"],exit_code=rc,failures=d["failures"]))
panel=[]; root=Path("model/labels/manifests")
for p in sorted((root/"numerator-check").glob("*.json")):
    d=json.loads(p.read_text()); sm=json.loads((root/(p.stem+".summary.json")).read_text())
    raw=(root/sm["manifest"]).read_bytes()
    assert hashlib.md5(raw).hexdigest()==sm["manifest_md5"]
    rows=list(csv.DictReader(io.StringIO(gzip.decompress(raw).decode()),delimiter="\t"))
    eligible=[(r["seqid"],r["strand"],r["transcript"]) for r in rows
              if r["status"]=="admitted" and int(r["cds_end"])-int(r["cds_start"])+1<=5000
              and int(r["rows"])-1>=1]
    want=set(random.Random(20260915).sample(eligible,min(10,len(eligible))))
    actual=[(r["seqid"],r["strand"],r["transcript"]) for r in d["results"]]
    assert len(eligible)==d["eligible_admitted"]
    assert len(actual)==len(set(actual))==d["sampled"]==len(want)==10
    assert set(actual)==want and d["failures"]==[]
    assert all("failure" not in r and math.isfinite(r["log_partition"]) and math.isfinite(r["viterbi"])
               for r in d["results"])
    panel.append(dict(species=p.stem,eligible=len(eligible),expected=len(want),reported=len(actual)))
print(json.dumps(dict(synthetic=out,saved_report_identity_checks=panel,
 python=platform.python_version(),cpu_seconds=time.process_time()-cpu0,
 wall_seconds=time.monotonic()-wall0,peak_rss_kib=resource.getrusage(resource.RUSAGE_SELF).ru_maxrss),indent=2))
```
