## From-spec closed-form oracle for the censored `I(c,k)` tail exit

lenin-0060 left the censored-pending-donor tail exit (reference `I(c,k)` at
boundary `n`, delayed `tail_exits`) as the untested boundary case. The
committed suite checks reference==delayed==all-seams *agreement* on this
exit (`test_partial_3_exit_inside_an_intron_and_inside_a_codon`,
`DelayedEntryAgreement`), but agreement alone would not catch a shared
arithmetic error: both decoders could charge the same wrong total. This tick
certifies the **absolute** score against the proposal's formulas,
independently of either decoder, in the lenin-0060 style: mask every score
cell to `-inf` except the exact cells the one intended parse charges, so a
single path survives, and check both decoders and the delayed decoder
checkpointed at **every** interior boundary against a hand-computed total.

**Intended parse.** Enter at boundary 0 in `E0("")` (CDS from the edge),
emit `c` coding bases, open a donor at boundary `c`, consume `L` intronic
bases with `1 <= L < m` so the intron is censored before reaching `m` bases,
and exit at boundary `n = c+L` via the edge prior. The proposal charges, and
nothing else,

    entry + prefix_prior("") + sum_{j<c} cds[j%3][j] + donor[c]
          + sum_{j=c}^{n-1} intron[p][j] + exit,     p = c % 3

with **no** duration-mixture term (`log_pi`/`log_q`/`log_1mq`): a censored
intron never enters a tail, so `R` is irrelevant. The paired `L == m` case is
the contrast -- the donor materializes into `T(c,r)`, so `tail_exits` is
empty and the mixture reappears: partition adds `log(sum_r pi[p]) = 0`,
Viterbi adds `max_r log_pi(p,r)`.

**Results (seed 20260918, deterministic).** **81** cases pass over `m` in
{4,5}, `R` in {1,2,3}, donor phase `p = c%3` for `c` in {1,2,3}, and `L` in
`1..m`: **63** censored `I(c,k)` exits and **18** materialized-tail
contrasts. For every case both decoders and the delayed decoder with
`seams=range(1,n)` reproduce the closed-form partition and Viterbi, and all
three trace the identical single chain -- `partial_5` and `partial_3` set,
one CDS segment `[0,c)` phase 0, one intron `[c,n)` phase `p`, component
`None` when censored and assigned when materialized. The delayed decoder's
`tail_exits` is exactly `{("I", ("E","A"*(c%3)), L)}` when censored and
empty when materialized. Max absolute error over all 81 cases and both
score types **1.776e-15**. That `R` and the mixture never move the censored
total is the substantive property: the seam run also confirms a donor parked
at boundary `c` survives checkpointing across every interior seam and exits
from its true boundary, never a fabricated seam state.

Three controls confirm the oracle is not vacuous. With `edges=None` both
decoders give partition `-inf` and no chains and `tail_exits` is empty (the
`E0` entry and the edge exit both vanish). Bumping one live intron emission
by 1.7 shifts the delayed partition by exactly 1.7. Masking the sole donor
gives partition `-inf`.

**Scope.** A score/normalization oracle for the censored-pending-donor exit
(`I(c,k)` at boundary `n`) with `E0` edge entry, and its invariance under
checkpointing at every interior seam. Genetic code table 1, all-`A`
sequences (so `permitted_bases` is a singleton and no base prior enters).
It does not test the residual-donor `J` tail exit at `n` (lenin-0060), the
acceptor-mediated intron exit into CDS, interior-seam edge *suppression* of
ordinary donors/exits, learned emissions, autograd/loss, the crop hazard
(engels-0046), source-data joins (stalin/engels), held-out accuracy, or
throughput. Committed grammar suite still green: **36** tests, 3.944 s.
No implementation files changed; run from repo root with
`PYTHONPATH=. python3 -B` on the scratch below.

```python
"""From-spec closed-form oracle for the censored-pending-donor tail exit
(reference I(c,k) at boundary n) and its checkpointed equivalent, plus the
interior-seam invariance of that exit. lenin tick, seed 20260918.

Method (as in lenin-0060): mask every score cell to -inf except the exact
cells the one intended parse charges, so a single path survives, and check
that both decoders -- and the delayed decoder checkpointed at every interior
boundary -- reproduce a total computed independently from the proposal's
formulas. Certifies the ABSOLUTE score, not just cross-decoder agreement.

Intended parse (censored): enter at boundary 0 in E0("") (CDS from the edge),
emit c coding bases, open a donor at boundary c, consume L intronic bases
with 1 <= L < m so the intron is censored before reaching m bases, and exit
at boundary n via the edge prior. The proposal charges, and nothing else:

  entry + prefix_prior("") + sum_{j<c} cds[j%3][j] + donor[c]
        + sum_{j=c}^{n-1} intron[p][j] + exit,     p = c % 3

with NO duration-mixture term (log_pi/log_q/log_1mq): a censored intron never
enters a tail, so R is irrelevant -- asserted below. The paired L == m case is
the contrast: the donor materializes into a tail T(c,r), tail_exits is empty,
and the mixture DOES appear (partition adds log(sum_r pi)=0; Viterbi adds
max_r log_pi)."""
import math, platform, resource, time
from math import log, isinf

from model.grammar.reference import (ReferenceDecoder, DurationMixture,
    EdgePrior, prefix_prior)
from model.grammar.delayed import DelayedEntryDecoder
from model.grammar.scores import Scores
from model.grammar.codes import TABLES

NEG = float("-inf")
cpu0, wall0 = time.process_time(), time.monotonic()


def masked_scores(n, rng):
    """All channels -inf; caller lights up the intended finite cells."""
    sc = Scores(n,
                u=[NEG] * n,
                cds=[[NEG] * n for _ in range(3)],
                intron=[[NEG] * n for _ in range(3)],
                start=[NEG] * n, stop=[NEG] * n,
                donor=[NEG] * n, acceptor=[NEG] * n)
    return sc


def rand(rng):
    return rng.uniform(-3.0, 3.0)


def make_dur(m, R, rng):
    pi = tuple(tuple(v / s for v in row)
               for row, s in ((r, sum(r)) for r in
                              ([rng.uniform(0.2, 1.0) for _ in range(R)] for _ in range(3))))
    q = tuple(tuple(rng.uniform(0.15, 0.85) for _ in range(R)) for _ in range(3))
    return DurationMixture(m=m, pi=pi, q=q)


def build(c, L, m, R, entry, exit, rng):
    """Return (x, sc, dur, edges, closed_form_partition, closed_form_viterbi,
    censored, p, cstate). c coding bases, then an intron of length L; n=c+L."""
    n = c + L
    x = "A" * n                              # 'AAA' (Lys) is not a stop under table 1
    sc = masked_scores(n, rng)
    p = c % 3
    cds_cells = {}
    for j in range(c):                       # CDS emissions: phase j%3 at boundary j
        v = rand(rng); sc.cds[j % 3][j] = v; cds_cells[j] = v
    dv = rand(rng); sc.donor[c] = dv         # the one live donor
    intron_cells = []
    for j in range(c, n):                    # intron emissions, all in phase p
        v = rand(rng); sc.intron[p][j] = v; intron_cells.append(v)
    dur = make_dur(m, R, rng)
    edges = EdgePrior(entry, exit)
    cstate = ("E", "A" * (c % 3))            # E-state that opens the donor
    common = (entry + prefix_prior("") + sum(cds_cells.values()) + dv
              + sum(intron_cells))
    censored = L < m
    if censored:
        z = v_ = common + exit               # no mixture term
    else:                                    # L == m: materializes into tail T(c,r)
        p_ = p
        z = common + math.log(sum(dur.pi[p_])) + exit           # = common + 0 + exit
        v_ = common + max(dur.log_pi(p_, r) for r in range(dur.R)) + exit
    return x, sc, dur, edges, z, v_, censored, p, cstate


def close(a, b, tol=1e-9):
    if isinf(a) or isinf(b):
        return a == b
    return abs(a - b) < tol


def chain_shape(chains):
    assert len(chains) == 1
    ch = chains[0]
    cds = [(s.start, s.end, s.prefix_len) for s in ch.cds()]
    intr = [(s.start, s.end, s.prefix_len, s.component) for s in ch.introns()]
    return (ch.partial_5, ch.partial_3, ch.uncertain, cds, intr)


def main():
    import random
    rng = random.Random(20260918)
    cases = passed = censored_seen = materialized_seen = 0
    max_err = 0.0
    for m in (4, 5):
        for R in (1, 2, 3):
            for c in (1, 2, 3):              # donor phase p = c % 3 in {1,2,0}
                for L in list(range(1, m)) + [m]:   # censored L<m, plus the L==m contrast
                    entry, exit = log(0.3), log(0.4)
                    x, sc, dur, edges, z, v_, censored, p, cstate = build(
                        c, L, m, R, entry, exit, rng)
                    ref = ReferenceDecoder(TABLES[1], dur, edges)
                    dl = DelayedEntryDecoder(TABLES[1], dur, edges)
                    n = len(x)
                    seams = list(range(1, n))

                    zr, zd = ref.partition(x, sc), dl.partition(x, sc)
                    zds = dl.partition(x, sc, seams=seams)
                    vr, cr = ref.viterbi(x, sc)
                    vd, cd = dl.viterbi(x, sc)
                    vds, cds_ = dl.viterbi(x, sc, seams=seams)

                    for got in (zr, zd, zds):
                        assert close(got, z), (m, R, c, L, "partition", got, z)
                        max_err = max(max_err, abs(got - z))
                    for got in (vr, vd, vds):
                        assert close(got, v_), (m, R, c, L, "viterbi", got, v_)
                        max_err = max(max_err, abs(got - v_))

                    # traced chains agree across all three, and match the parse
                    sh = chain_shape(cr)
                    assert chain_shape(cd) == sh and chain_shape(cds_) == sh, (m, R, c, L)
                    partial5, partial3, unc, cdssegs, intrsegs = sh
                    assert partial5 and partial3 and not unc, (m, R, c, L, sh)
                    assert cdssegs == [(0, c, 0)], (m, R, c, L, cdssegs)
                    # intron [c,n) in phase p; censored -> no component, tail -> a component
                    (ia, ib, iph, icomp), = intrsegs
                    assert (ia, ib, iph) == (c, n, p), (m, R, c, L, intrsegs)
                    if censored:
                        assert icomp is None, (m, R, c, L, icomp)
                    else:
                        assert icomp is not None, (m, R, c, L, icomp)

                    # inspect the delayed decoder's tail_exits directly
                    _, _, _, te = dl._run(x, sc, viterbi=False)
                    if censored:
                        assert list(te.keys()) == [("I", cstate, L)], (m, R, c, L, te)
                        censored_seen += 1
                    else:
                        assert te == {}, (m, R, c, L, te)        # materialized into a tail
                        materialized_seen += 1
                    cases += 1
                    passed += 1

    # --- controls ---
    rng2 = random.Random(4242)
    # 1. no edges: the E0 entry and the tail exit both vanish -> NEG, empty te
    x, sc, dur, edges, z, v_, *_ = build(2, 2, 5, 2, log(0.3), log(0.4), rng2)
    for cls in (ReferenceDecoder, DelayedEntryDecoder):
        d0 = cls(TABLES[1], dur, edges=None)
        assert d0.partition(x, sc) == NEG and d0.viterbi(x, sc) == (NEG, []), cls
    dn = DelayedEntryDecoder(TABLES[1], dur, edges=None)
    assert dn._run(x, sc, viterbi=False)[3] == {}, "tail_exits must be empty without edges"

    # 2. sensitivity: bumping one live intron emission shifts the total by delta
    x, sc, dur, edges, z, v_, censored, p, cstate = build(2, 2, 5, 2, log(0.3), log(0.4), rng2)
    delta = 1.7
    sc.intron[p][2] += delta
    zd2 = DelayedEntryDecoder(TABLES[1], dur, edges).partition(x, sc)
    assert close(zd2, z + delta), (zd2, z, delta)

    # 3. killing the sole donor removes the only path -> NEG
    x, sc, dur, edges, *_ = build(2, 2, 5, 2, log(0.3), log(0.4), rng2)
    sc.donor[2] = NEG
    assert DelayedEntryDecoder(TABLES[1], dur, edges).partition(x, sc) == NEG

    print("PASS")
    print(f"cases={cases} passed={passed} censored={censored_seen} "
          f"materialized={materialized_seen} max_abs_err={max_err:.3e}")
    print(f"python={platform.python_version()} "
          f"cpu_s={time.process_time()-cpu0:.4f} wall_s={time.monotonic()-wall0:.4f} "
          f"peak_rss_kib={resource.getrusage(resource.RUSAGE_SELF).ru_maxrss}")


if __name__ == "__main__":
    main()
```
