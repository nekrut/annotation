**P3 — `PackedBackPointers.nbytes()` measures payload, not allocated storage.**
The [counter](https://github.com/nekrut/annotation/blob/31a5bdee1184cf24d7d0578f9933f03f179a5a5a/model/a/fast_viterbi.py#L533)
sums `numel() * element_size()`, but
[append](https://github.com/nekrut/annotation/blob/31a5bdee1184cf24d7d0578f9933f03f179a5a5a/model/a/fast_viterbi.py#L493)
drops the preceding exit column with a view, retaining the allocation.
For B=1, sliced `prev2.contiguous()` also returns a view of its already
contiguous storage, retaining the seam context; the R=8 int8 exit fallback
has the same issue. Thus the current equality test establishes logical
payload size, not the docstring's "Bytes held by the packed store."

Small real scans with code 1, m=20, L=47 and tile=1 produce:

| B | R | reported payload bytes | unique pointer-storage bytes |
|---|---|---:|---:|
| 1 | 3 | 1,104 | 3,154 |
| 2 | 3 | 2,208 | 3,312 |
| 1 | 8 | 2,400 | 21,874 |

The last column deduplicates `untyped_storage()` by data pointer across
the three pointer lists only; it excludes grammar tables, the bit mask,
Python objects and allocator overhead, and is not RSS. For B=1/R=3, the
breakdown is prev2 96 logical / 1,594 storage, exit_r 576 / 1,128, and
entered 432 / 432 bytes. At tile=64, all these examples have just one tile
and storage equals payload. The production tile is much wider, so these
tiny-tile factors must not be extrapolated to the pilot.

Please either label this helper explicitly as logical payload and report
deduplicated storage separately, or ensure discarded views release their
backing allocations before claiming exact allocated bytes. The
[23-byte claim](https://github.com/nekrut/annotation/blob/31a5bdee1184cf24d7d0578f9933f03f179a5a5a/docs/design/a-pilot.md#L972)
is a useful payload rate; packing still works and this finding is not a
decode correctness failure.

Minimal reproduction after importing the pinned `fast_viterbi as fv`,
`Grammar`, `DurationMixture`, `TABLES` and torch:

```python
R, B, L = 3, 1, 47  # also (3, 2, 47) and (8, 1, 47)
d = DurationMixture(m=20, pi=((1/R,)*R,)*3, q=((.7,)*R,)*3)
g = Grammar.get(TABLES[1], d, dtype=torch.float64, device=torch.device('cpu'))
_, p, _ = fv.scan_segments(
    torch.zeros(B, 11, L, dtype=torch.float64),
    torch.zeros(B, L, dtype=torch.long), torch.full((B,), L), g, tile=1)
stores = {}
for tensors in (p.prev2, p.exit_r, p.entered):
    for t in tensors:
        s = t.untyped_storage()
        stores[s.data_ptr()] = s.nbytes()
print(p.nbytes(), sum(stores.values()))
```
