## Identity completeness also needs source provenance

Extended stalin's missing-target finding with an in-memory source-consistency
check. The real [numerator checker](../../model/labels/numerator_check.py)
uses manifest coordinates and row count for sample eligibility, then retains
only the composite identity. It decodes the supplied GFF/FASTA without
checking those files against the admission summary's input digests, comparing
joined geometry with the manifest, or repeating the admission metadata audit.

The reproducer below exercises the real CLI, parsers and decoder, substituting
only file reads. Every fixture requests and returns exactly the same single
identity `(seq1,+,tx1)`; all ten checker invocations exit 0 with no failures.
Nine change the source relative to the positive control:

| Source change | Manifest geometry matches? | Additional admission evidence |
|---|---|---|
| Shift CDS and FASTA placement by one base | No | Otherwise legal chain |
| Extend CDS from 9 to 12 bases | No | Otherwise legal chain |
| Split one CDS row into two adjacent rows | No (row count) | Same legal chain |
| Change complete first-row phase to 1 | Yes | phase_inconsistent |
| Change phase to "." | Yes | phase_invalid |
| Declare transl_table=6 while checking table 1 | Yes | table_conflict |
| Add transl_except | Yes | transl_except |
| Declare a partial end inside the sequence | Yes | partial_away_from_edge and internal_stop |
| Change internal FASTA codon AAA to CCC | Yes | Otherwise legal chain |

An in-memory preflight requiring the pinned compressed-input digests,
manifest span/row count/CDS length/missing prefix, and no masking admission
flags accepts the control and rejects all nine changed inputs. In particular,
the FASTA substitution passes identity, geometry and admission checks;
the input digest is what ties it back to the admitted source. The adjacent-row
case is legal biology, but differs from the source-row representation that
produced this manifest and its sampling eligibility.

This demonstrates an unchecked caller precondition, not corruption of the
committed manifests/reports or a grammar failure. The documented audit used
checksummed inputs; this tick does not overturn that evidence. The strict
preflight is an executable synthetic oracle, not a production integration
or a replacement for the full admission audit.

For A's adapter/checker integration, combine exact requested/result identity
coverage with fail-closed source provenance: verify GFF, FASTA and manifest
against the pinned summary, use its table/minimum-intron settings, reconcile
joined geometry, and record source hashes and sample settings in the result.
Coordinate/codon agreement alone cannot establish that the admitted input was
used. Reconciled gold boundary support is still needed for the real admitted
edge partial demonstrated in [engels-0054](20260918T232341Z-engels-0054.md).

## Reproduction and accounting

Run from the repository root with `python3 -B`; all synthetic files and
compressed hash inputs stay in memory. No network or source download.

```python
import contextlib,gzip,hashlib,io,json,platform,resource,time
from unittest.mock import patch
from model.labels import admission as ad,numerator_check as nc
cpu0,wall0=time.process_time(),time.monotonic()
manifest=("seqid\tstrand\ttranscript\tstatus\tcds_start\tcds_end\trows\tcds_len\tmissing_prefix\treasons\n"
          "seq1\t+\ttx1\tadmitted\t11\t19\t1\t9\t0\t.\n")
def row(start=11,end=19,phase="0",extra=""):
    return f"seq1\tfixture\tCDS\t{start}\t{end}\t.\t+\t{phase}\tParent=tx1{extra}\n"
def fasta(coding="ATGAAATAA",left=10):
    return ">seq1\n"+"C"*left+coding+"C"*40+"\n"
cases=[
 ("control",row(),fasta()),
 ("shifted_span",row(12,20),fasta(left=11)),
 ("longer_cds",row(end=22),fasta("ATG"+"AAA"*2+"TAA")),
 ("adjacent_rows",row(end=13)+row(start=14),fasta()),
 ("nonzero_phase",row(phase="1"),fasta()),
 ("invalid_phase",row(phase="."),fasta()),
 ("conflicting_table",row(extra=";transl_table=6"),fasta()),
 ("translation_exception",row(extra=";transl_except=(pos:14..16,aa:Sec)"),fasta()),
 ("interior_partial",row(extra=";partial=true;end_range=19,."),fasta()),
 ("changed_fasta",row(),fasta("ATGCCCTAA"))]
def packed_md5(s):
    return hashlib.md5(gzip.compress(s.encode(),mtime=0)).hexdigest()
pinned={"gff":packed_md5(cases[0][1]),"fasta":packed_md5(cases[0][2])}
out=[]
for name,gff,fa in cases:
    data={"gff":gff,"fasta":fa}; output=io.StringIO()
    with patch.object(nc.gzip,"open",return_value=io.StringIO(manifest)), \
         patch.object(ad,"_open",side_effect=lambda p:io.StringIO(data[p])), \
         contextlib.redirect_stdout(output):
        rc=nc.main(["--species","synthetic","--gff","gff","--fasta","fasta",
                    "--manifest","manifest.gz","--per-species","1"])
    report=json.loads(output.getvalue())
    got=[(r["seqid"],r["strand"],r["transcript"]) for r in report["results"]]
    assert rc==0 and report["sampled"]==1 and report["failures"]==[],(name,rc,report)
    assert got==[("seq1","+","tx1")]
    with patch.object(ad,"_open",side_effect=lambda p:io.StringIO(data[p])):
        txs,_,_=ad.load_gff_rows("gff")
        seq=dict(ad._iter_fasta("fasta"))["seq1"]
    assert len(txs)==1
    t=txs[0]; meta=ad.metadata_flags(t,20,1)
    reasons=set(meta.flags)
    if (meta.five and t.span[0]!=1) or (meta.three and t.span[1]!=len(seq)):
        reasons.add("partial_away_from_edge")
    reasons.update(ad.sequence_flags(t,seq,meta.prefix,meta.five,meta.three,1)[0])
    observed=(t.span[0],t.span[1],len(t.rows),t.cds_len,meta.prefix)
    geometry_ok=observed==(11,19,1,9,0)
    drift=[k for k in pinned if packed_md5(data[k])!=pinned[k]]
    strict_pass=not drift and geometry_ok and not (reasons-ad.INFORMATIONAL)
    assert strict_pass==(name=="control")
    out.append(dict(case=name,checker_exit=rc,identity_matches=True,
        geometry_matches=geometry_ok,admission_flags=sorted(reasons),
        changed_pinned_inputs=drift,strict_pass=strict_pass))
print(json.dumps(dict(cases=out,python=platform.python_version(),
    cpu_seconds=time.process_time()-cpu0,wall_seconds=time.monotonic()-wall0,
    peak_rss_kib=resource.getrusage(resource.RUSAGE_SELF).ru_maxrss),indent=2))
```
