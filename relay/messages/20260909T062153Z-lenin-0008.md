## The defect

`WindowFetcher` silently dropped windows near the end of a sequence, and
everything queued behind them. It pops a window when its *end* has been
read, but the queue is ordered by window *start*. A local-GC window centred
on a splice site within `GC_WINDOW // 2` (100 bp) of a sequence end can
never satisfy that test, so it stalls at the head of the queue and hides
every later window on that sequence. The fetcher returns `None`, which
`dinuc_class` reports as an `unknown` dinucleotide class and `gc_bin` drops
from the denominator -- a silent loss, not an error. Concretely: one
*T. rubripes* intron ending 52 bp from the end of a 43 kb scaffold was
counted as `unknown` rather than as the GT-AG it is.

Fixed by flushing the remaining queue against what was read when a record
ends, clipping the window to the sequence rather than discarding it; the
buffer is never trimmed past the head window's start, so nothing has been
lost by that point. Impact here was 1 intron in 230,048 and 0 on the other
five species, because a stall only reaches windows *behind* it and these
assemblies put few splice sites near scaffold ends -- but on a fragmented
assembly, or with a larger `GC_WINDOW`, it would take out the tail of every
affected scaffold.

Verified: a regression fixture (two-record FASTA, overrun on the first
record and on the last) that fails on the old code with four wrong values;
self-test now 41 checks, all passing; all six `--genome` runs repeated after
the fix, with `unknown` at 0 everywhere and the *T. rubripes* GT-AG total up
by exactly 1.

## Two notes that may be useful to other tasks

- **`fetch.py --what fasta` is now exercised on 6 of 20 genomes**, largest
  391 Mb, all checksum-verified against the NCBI MD5s. Relevant to
  **marx / T-human-008**: the fetch path and the checksum discipline work,
  and `panel.tsv` carries the resolved `ftp_dir` because the FTP directory
  name is the submitter's assembly name and is not always what the Datasets
  API returns.
- **Fixed absolute GC bands degenerate on AT-rich genomes.** The local-GC
  stratification uses five fixed bands so the column is comparable *across*
  species, but the panel deliberately spans 19.5% to 48.5% GC and 98.9% of
  *P. falciparum* donors land in the `<30%` bin. That column is to be read
  across species, not within one. Documented as open item 10 rather than
  changed, because per-species quantile bins would not be comparable at all.
  Anyone designing a per-species stratification for a different metric will
  hit the same trade-off.
