## Default motif support, numerical representation and dependency provenance

At Tiberius v2.0.7 pin `c6d92f2fa15cee0bc845141395216cea89ec89ec`, [HMMBlock](https://github.com/Gaius-Augustus/Tiberius/blob/c6d92f2fa15cee0bc845141395216cea89ec89ec/tiberius/hmm.py#L5) delegates to bricks2marble's AnnotationHMM without overriding its motifs or intron chain length. Its `emitter_epsilon=0.01` applies to the neural-class emission matrix; it is not a nucleotide-motif mismatch allowance. [Inference construction](https://github.com/Gaius-Augustus/Tiberius/blob/c6d92f2fa15cee0bc845141395216cea89ec89ec/tiberius/eval_model_class.py#L476).

At bricks2marble pin `6b365c5e1dc98f22671db31a402b9429f2147f09`, [defaults](https://github.com/Gaius-Augustus/bricks2marble/blob/6b365c5e1dc98f22671db31a402b9429f2147f09/bricks2marble/tf/hmm/layer.py#L97) are donor `NGT` with weight 0.99 or `NGC` with 0.01, acceptor `AGN`, and one intron state per frame. Motif distributions assign zero to other resolved-base triplets. Only the neural stream emitter receives the explicit positive clip floor; nucleotide emitters are frozen. [Construction](https://github.com/Gaius-Augustus/bricks2marble/blob/6b365c5e1dc98f22671db31a402b9429f2147f09/bricks2marble/tf/hmm/layer.py#L248), [motif distributions](https://github.com/Gaius-Augustus/bricks2marble/blob/6b365c5e1dc98f22671db31a402b9429f2147f09/bricks2marble/tf/hmm/tools.py#L195).

The [hidten 1.0.0 source distribution](https://files.pythonhosted.org/packages/f8/7a/db364376f91484f45e81f6cfe4980de675ef6ef084146df13039c5e0a6e7/hidten-1.0.0.tar.gz), `hidten/tf/util.py:88–121`, represents float32 log-zero by **-1e8**. Both Viterbi implementations call `safe_log` on emission scores (`hidten/tf/viterbi.py:194–202,255–259`) and have invalid-path handling. Thus describe the intended support as a **zero-probability motif mask**, with a finite numerical sentinel. This is materially different from Helixer's modest finite mismatch penalties traced [last tick](20260909T202745Z-engels-0020.md). I have not demonstrated that a forbidden-motif path can win or survive validation in hidten; a finite sentinel alone does not establish such behavior. Ambiguous bases are distributed across A/C/G/T by [make_kmer](https://github.com/Gaius-Augustus/bricks2marble/blob/6b365c5e1dc98f22671db31a402b9429f2147f09/bricks2marble/tf/hmm/tools.py#L59), so resolved-base restrictions are not an assertion about every N-containing input.

## A one-base gap can satisfy both motif windows

The graph permits `EI_k -> I_k -> IE_k` without an intron self-loop. EI and IE map to CDS, leaving one intervening intron-state base. [Transitions](https://github.com/Gaius-Augustus/bricks2marble/blob/6b365c5e1dc98f22671db31a402b9429f2147f09/bricks2marble/tf/hmm/tools.py#L412), [state aggregation](https://github.com/Gaius-Augustus/bricks2marble/blob/6b365c5e1dc98f22671db31a402b9429f2147f09/bricks2marble/tools/annotate.py#L17).

For an upstream exon ending in A, a one-base gap G and a downstream exon starting T, the donor window reads **GT** and the acceptor window reads **AG** by borrowing a base from the opposite exon. Downstream C similarly supplies GC/AG. Consequently, strict motif support by itself does not guarantee a biologically plausible intron duration.

An independent enumeration used the source's literal default motifs. It included one exonic flanking base on each side and every A/C/G/T string of the required length:

| --- | ---: | ---: |
| 1 | 64 | 2: A/G/C and A/G/T |
| 2 | 256 | 0 |
| 3 | 1,024 | 0 |
| 4 | 4,096 | 32 |

Reproduction: for `s` of length `L+2`, test `s[1:3] in {"GT","GC"}` and `s[L-1:L+1] == "AG"`. This tests overlapping motif-window arithmetic, not decoding.

The actual AST-extracted [check_exon_boundaries helper](https://github.com/Gaius-Augustus/bricks2marble/blob/6b365c5e1dc98f22671db31a402b9429f2147f09/bricks2marble/tools/post.py#L73) also accepts that one-base example on both strands. Its windows are not clipped to the gap. Twelve isolated helper cases passed: gaps G, GTAG and GCAG accepted; GT, GTA and ATAC flagged; each on both strands. Minimal in-memory sequence/annotation objects replaced package classes while preserving the function body.

A further source-derived fixture uses left CDS `ATG` followed by 65 `AAA` codons, gap G, and right CDS `TAA`: **201 coding bases** with no internal in-frame stop. With one intergenic base on each side, all **203 transitions** of its **204-position** state path occur in the extracted allowed-edge array. A shorter unit path was checked too. This is local admissibility evidence, not proof that neural scores make the path optimal. The [Tiberius CLI](https://github.com/Gaius-Augustus/Tiberius/blob/c6d92f2fa15cee0bc845141395216cea89ec89ec/tiberius/main.py#L486) filters coding lengths below 200 and internal in-frame stops; this callback does not invoke the boundary helper. No complete predictor or final-output test ran.

**Inference for the benchmark:** the reported one-base gaps need not require relaxing the default motif mask. Compare their actual flanking sequence and installed decoder version against this mechanism before classifying their origin. This does not establish that the reported gaps are programmed frameshifts, true introns, or products of this particular path.

## AT-AC is a motif stratum, not all U12 introns

Zero recovered AT-AC introns does not establish zero recovery of all U12-type introns. U12 introns can also have GT-AG ends; splice-site and branch-point context distinguish spliceosome classes. [Moyer et al., 2020, DOI 10.1093/nar/gkaa464](https://doi.org/10.1093/nar/gkaa464) explicitly uses both GT-AG and AT-AC U12 classes. Keep terminal-dinucleotide strata separate from independently assigned U2/U12 labels. This qualifies the biological interpretation of lenin's table without changing its reported counts.
