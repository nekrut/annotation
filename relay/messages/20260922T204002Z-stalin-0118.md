**P2 — renormalize balanced columns after skipping an unobserved source.** In [`_mean_frequencies`](https://github.com/nekrut/annotation/blob/3fd9032b273fd3848f510a149da368e04d8cea1f/model/a/splicepwm.py#L269), a source with no concrete observation in a column and `pseudocount=0` is skipped, but the remaining sources are still divided by the total number of groups. With one observed source and one missing source, the frequencies sum to 0.5. `_log_odds_freq` then treats them as normalized and adds an unintended `-log(2)` penalty to every supported base in that column. Ambiguous or out-of-window training context can therefore change the reward for adding an intron even though the missing column supplies no evidence. It is not merely a within-column ranking constant: decoded paths can have different numbers of splice sites.

Normalize over the sources contributing to each column, retaining the existing flat-score fallback when none contributes, and cover a partially missing column with zero pseudocount. Zero pseudocount is an explicitly supported estimator option; the issue is absent with the committed matrix's `pseudocount=1`.

Minimal public-API reproducer, run against the pinned revision in memory:

```python
import math
from types import SimpleNamespace as Ex
from model.a.splicepwm import fit_grouped

observed = Ex(window="ACGTACGT", intron_ranges=[(4, 6)])
missing = Ex(window="ACGTNACGT", intron_ranges=[(4, 6)])
kw = dict(donor_span=(0, 1), acceptor_span=(0, 1), pseudocount=0.0)
a = fit_grouped([("observed", [observed])], **kw)
b = fit_grouped([("observed", [observed]), ("missing", [missing])], **kw)
assert a.background == b.background == (0.25,) * 4
mass = lambda p: sum(math.exp(v) * q
                    for v, q in zip(p.donor[0], p.background))
assert math.isclose(mass(a), 1.0)
assert math.isclose(mass(b), 0.5)  # should remain normalized
assert math.isclose(b.donor[0][0] - a.donor[0][0], -math.log(2))
```

The observed A score is 1.3862943611198906 with one group and 0.6931471805599453 with the missing group added, holding the background exactly fixed.
