relay/artifacts/T-human-012/non_hmm_geometric_spec.md

Summary of the Architectural Blueprint:
1. Core Paradigm Shift:
   - Completely replaces HMM and Generalized HMM dynamic programming (GENSCAN, AUGUSTUS, Tiberius), eliminating single-isoform collapse, geometric intron length bias, and closed binary dependencies (hidten, bricks2marble).
   - Solves the problem via a decoupled neural-graph paradigm: high-resolution single-base neural prediction + grammar-constrained biological DAG pathfinding.

2. Parameter-Budgeted PyTorch Neural Backbone (Verified: 1,596,812 parameters):
   - Local Convolutional Stem: Preserves single-base resolution feature map (H_local, 128-d) for skip connections.
   - Codon-Preserving Downsampling: Groups by pool_size = 9 bp (3 full codons) to compress the sequence axis by 9x before global context processing.
   - Global Context Stack: 2-layer Bidirectional LSTM / Axial Transformer over codon steps.
   - Total weights: ~1.60M, strictly under the 2.0M parameter budget, runnable in seconds on a standard laptop CPU/GPU.

3. Multi-Task Heads & Compound Loss:
   - Single-Nucleotide Junction Head (B, L, 5): Focal Loss (gamma=2, alpha=0.25) to handle the extreme sparsity (<0.01%) of donor, acceptor, start, and stop positions.
   - Codon-Aligned Span Head (B, L, 4): Multiclass Soft F1 Loss for intergenic, intron, CDS, and UTR segmentation.
   - Reading Frame Head (B, L, 3): Masked cross-entropy across coding frames (0, 1, 2).
   - Bilinear Intron Compatibility Head: Low-rank bilinear scoring S(donor_i, acceptor_j) = phi(d_i)^T W psi(a_j).

4. Biological Splice-Graph Decoder (Pure Python / NumPy / Numba):
   - Consensus Dinucleotide Peak Extraction: Strict filtering of GT/GC donors, AG acceptors, ATG starts, and TAA/TAG/TGA stops.
   - Arbitrary Intron Spans: Scores introns (40 bp to 200 kb) via the integral of intronic span potential, overcoming HMM exponential penalties.
   - Grammar-Constrained Traversal: Translates spliced coding sequences on the fly, immediately pruning any branch containing a premature in-frame stop codon and enforcing terminal length mod 3 == 0.
   - Multi-Isoform Extraction: Uses Yen's top-K shortest paths or beam search to emit multiple distinct alternative splicing isoforms per locus in standard GTF/GFF3 format.

5. Evolutionary Geometric Integration:
   - Ingests 4D MDS tree metric coordinates and Tree-RoPE from the HyphAeon design pattern, along with windowed KA/KS selection statistics and base-wise phyloP scores.

Ready for review and integration into the Phase 3 design proposal (T-human-011).
