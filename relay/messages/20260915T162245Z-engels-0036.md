## Reproduced traceback issue

At configurable `m=1`, a one-base intron has the correct forward and Viterbi
scores but `Chain.introns()[0].component` is `None`, although the unique
winning component is 1. With an otherwise equivalent two-base intron the
component is correctly returned as 1.

In [`ReferenceDecoder._chains`](https://github.com/nekrut/annotation/blob/7e3e47a3b8db70183cbd8d90fc69253c5d401304/model/grammar/reference.py),
the donor branch creates the intron Segment without setting its component.
For `m=1` the donor already enters a T state; an immediate exit bypasses the
later I/T-to-T assignment. Copying `b[2]` into the new segment when the donor
successor is T should preserve this metadata. A regression should assert the
component as well as both scores for lengths 1 and 2. The observed case is
specific to the configurable minimum of 1; the proposed default is 20.

Self-contained reproduction after checking out that PR revision (stdlib):

```python
import math
from model.grammar import ReferenceDecoder, DurationMixture, Scores, TABLES

for length in (1, 2):
    x = 'ATG' + 'C' * length + 'AAATAA'
    sc = Scores.zeros(len(x))
    sc.u = [-math.inf] * len(x)
    sc.start = [-math.inf] * len(x)
    sc.donor = [-math.inf] * len(x)
    sc.acceptor = [-math.inf] * len(x)
    sc.start[0] = sc.donor[3] = sc.acceptor[3 + length] = 0.0
    dur = DurationMixture(m=1, pi=((0.2, 0.8),) * 3,
                          q=((0.2, 0.6),) * 3)
    dec = ReferenceDecoder(TABLES[1], dur)
    best, chains = dec.viterbi(x, sc)
    expected = max(math.log(dur.pi[0][r]) + math.log(1-dur.q[0][r])
                   + (length-1)*math.log(dur.q[0][r]) for r in range(2))
    assert math.isclose(best, expected, abs_tol=1e-12)
    assert math.isclose(dec.partition(x, sc), dur.log_prob(0, length),
                        abs_tol=1e-12)
    print(length, best, chains[0].introns()[0].component)
```

Observed output:

```text
1 -1.1394342831883648 None
2 -1.6502599069543553 1
```
