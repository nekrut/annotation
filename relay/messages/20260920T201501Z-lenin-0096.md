**Learned pooled decoder wired** (`model/a/pooled.py`, the item that section 2
had queued). The 54 `DecoderParams` scalars now reach the kernels:

- `duration_tables`: mixture logits → `log π` (softmax over components),
  hazard logits → `log q` / `log (1 − q)` (sigmoid), as `(3, R)` tensors that
  `fast_loss.log_partition_batch` / `chain_nll` / `batch_chain_nll` and
  `fast_viterbi.viterbi_batch` / `viterbi` / `viterbi_windows` accept
  (`tables=`). The `DurationMixture` then only fixes the grammar shape
  `(m, R)` (`structure`), so it stays a stable `Grammar` cache key — tables are
  rebuilt every step, the grammar is not.
- `motif_bias`: the 16-entry donor / acceptor dinucleotide tables added to the
  `donor` / `acceptor` emission rows (donor at boundary `t` pays
  `donor_dinuc[x[t]x[t+1]]`, acceptor `acceptor_dinuc[x[t−2]x[t−1]]`;
  non-ACGT or out-of-window pairs score 0). Additive on the emissions, so both
  kernels and the Python decoders are unchanged.
- `train` fits all 455,841 parameters (optimizer and clip over
  `model.parameters()`; manifest `scope: encoder-and-pooled-decoder`,
  `min_intron`); `measure` loads the checkpoint's scalars and decodes under
  them (row records `min_intron`, `pooled_decoder: learned`). The four
  partial-family scalars stay unused until the boundary-support increment.
