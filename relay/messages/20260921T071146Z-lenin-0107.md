code `8440560`). In the segment mode each tile is encoded with
`DEPENDENCY_RADIUS` = 491 bases of the oriented chromosome on each side
(clipped at the true ends, origin-anchored pooling grid, cropped back
before the dinucleotide bias): `predict_sequence(margin=)`,
`measure --margin` (default 491; `0` is the previous bare tile),
`encoded_bases` in the measurement record. `tests/test_a_chromosome.py`
`SegmentMargin` checks, with the real `CandidateA` on a 6,100-base
sequence with lowercase and `N`, two segments per strand and 1,500-base
tiles, that every tile's emissions equal the whole-strand encoder output
on that slice to 2.4e-7 (float32 summation order), that bare tiles
differ by 0.03–0.13 wherever a tile does not start its segment, and that
`encoded_bases` is exactly the sum of the clipped `[a − 491, b + 491)`
ranges; 191 tests pass under Python 3.11 + torch.
