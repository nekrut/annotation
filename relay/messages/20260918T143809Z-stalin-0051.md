## Independent duration and edge-weight derivative oracle

[Proposal sections 3.2 and 3.6](../../docs/design/proposal.md) also require
marginalizing duration components in the numerator and preserving shared
edge weights. The new in-memory check below passes **66 synthetic targets /
132 decoder configurations / 1,056 central finite-difference comparisons**,
maximum absolute derivative error **3.2437519337236154e-10**. It covers
three components, phases 0/1/2, tables 1/6, complete introns of lengths
20/21/25, right-censored introns of lengths 1/19/20/21/25, and left-edge
residual introns of lengths 1/20/21. Every delayed run has a seam at every
interior boundary. Gold initial/terminal support is explicit, and hidden
prefixes are marginalized with their original prior.

For a component with survival probability q, mixture pi, continuation
count e and observed-exit indicator h, define
`w_r = pi_r * q_r**e * (1-q_r)**h`, and
`rho_r = w_r / sum(w)`. Derivatives of the log numerator with respect to
mixture logits a and survival logits b are
`d/da_r = rho_r - pi_r` and
`d/db_r = rho_r * (e*(1-q_r) - h*q_r)`.
Here:

- Complete intron: e = length - m, h = 1.
- Right-censored tail: e = length - m, h = 0; no acceptor/hazard-exit factor.
- Left residual: e = observed length, h = 1; no invented donor/minimum prefix.
- Right censoring before m: no duration component has been selected, so
  this target's log numerator has zero duration derivatives.
- At a right-censored length exactly m, the component sum is sum(pi) = 1;
  its duration derivatives also vanish. A component maximum would fail
  this normalization check.

These are **numerator derivatives**; the loss additionally contains the
denominator derivatives. Zero numerator duration derivatives do not imply
zero loss derivatives. The existing scalar EdgePrior is checked (one
entry, one exit), not the four coding/intron families required of the
future learned decoder. No PyTorch/autograd implementation, real-data
adapter, training crop, or throughput claim is validated here.

Reproduce from the repository root using `python3 -B`:

```python
import itertools, json, math, platform, time
from model.grammar import ReferenceDecoder, DelayedEntryDecoder, DurationMixture, EdgePrior, Scores, TABLES

class GoldSupport:
    def __init__(self, *args, kind, phase, **kw):
        self.kind, self.phase = kind, phase
        super().__init__(*args, **kw)
    def initial(self):
        if self.kind != 'left': return {('U',):0.}
        return {s:w for s,w in super().initial().items()
                if s[0]=='J' and len(s[1][1])==self.phase}
    def terminal(self, s):
        allowed = s[0] in ('I','T') if self.kind=='right' else s==('U',)
        return super().terminal(s) if allowed else -math.inf

class GoldRef(GoldSupport, ReferenceDecoder): pass
class GoldDelay(GoldSupport, DelayedEntryDecoder): pass

def parameters(theta):
    a, b = theta[:3], theta[3:6]
    ea = [math.exp(v-max(a)) for v in a]
    pi = [v/sum(ea) for v in ea]
    q = [1/(1+math.exp(-v)) for v in b]
    return pi, q

def target(kind, p, length):
    coding='ATGAAAAAATGA'; cut=3+p
    parts = ([('cds',coding[:cut])] if kind!='left' else [])
    parts += [('intron','C'*length)]
    if kind!='right': parts += [('cds',coding[cut:])]
    x=''.join(s for _,s in parts); sc=Scores.zeros(len(x))
    for _,arr in sc.channels(): arr[:]=[-math.inf]*len(x)
    phase = p if kind=='left' else 0
    t=0
    for label,seq in parts:
        for _ in seq:
            getattr(sc,label)[phase][t]=0.
            if label=='cds': phase=(phase+1)%3
            t+=1
    if kind!='left': sc.start[0]=0.; sc.donor[cut]=0.
    if kind!='right':
        sc.stop[-1]=0.
        sc.acceptor[(0 if kind=='left' else cut)+length]=0.
    return x,sc,coding[cut:]

def expected(kind,p,length,table,suffix,theta):
    pi,q=parameters(theta)
    if kind=='right' and length<20:
        return theta[7], [0.]*7+[1.]
    e = length if kind=='left' else length-20
    h = int(kind!='right')
    w = [pi[r]*(1-q[r])**h*q[r]**e for r in range(3)]
    rho=[v/sum(w) for v in w]
    grad=[rho[r]-pi[r] for r in range(3)]
    grad += [rho[r]*(e*(1-q[r])-h*q[r]) for r in range(3)]
    grad += [float(kind=='left'),float(kind=='right')]
    z=math.log(sum(w))
    if kind=='left':
        compatible=0
        for prefix in itertools.product('ACGT',repeat=p):
            seq=''.join(prefix)+suffix
            codons=[seq[i:i+3] for i in range(0,len(seq),3)]
            if all(not TABLES[table].is_stop(c) for c in codons[:-1]) and TABLES[table].is_stop(codons[-1]):
                compatible+=1
        assert compatible
        z+=theta[6]-math.log(3)+math.log(compatible/4**p)
    if kind=='right': z+=theta[7]
    return z,grad

t0,c0=time.monotonic(),time.process_time()
theta=[-1.,.2,.9,-1.3,.1,1.4,-.6,-.8]
cases=configs=checks=0; maxerr=0.
for table,p in itertools.product((1,6),range(3)):
    for kind,lengths in (('complete',(20,21,25)),('right',(1,19,20,21,25)),('left',(1,20,21))):
        for length in lengths:
            x,sc,suffix=target(kind,p,length)
            z,grad=expected(kind,p,length,table,suffix,theta)
            for cls in (GoldRef,GoldDelay):
                def measured(v):
                    pi,q=parameters(v)
                    dec=cls(TABLES[table],DurationMixture(m=20,pi=(tuple(pi),)*3,q=(tuple(q),)*3),
                            EdgePrior(v[6],v[7]),kind=kind,phase=p)
                    kw={'seams':range(1,len(x))} if cls is GoldDelay else {}
                    return dec.partition(x,sc,**kw)
                assert math.isclose(measured(theta),z,abs_tol=1e-11),(table,p,kind,length,cls.__name__,measured(theta),z)
                for j in range(8):
                    lo,hi=theta.copy(),theta.copy(); eps=1e-5
                    lo[j]-=eps; hi[j]+=eps
                    fd=(measured(hi)-measured(lo))/(2*eps)
                    err=abs(fd-grad[j]); maxerr=max(maxerr,err)
                    assert err<2e-8,(table,p,kind,length,cls.__name__,j,fd,grad[j])
                    checks+=1
                configs+=1
            cases+=1
print(json.dumps(dict(cases=cases,decoder_configurations=configs,finite_difference_checks=checks,
                      max_gradient_error=maxerr,python=platform.python_version(),
                      cpu_seconds=time.process_time()-c0,wall_seconds=time.monotonic()-t0)))
```
