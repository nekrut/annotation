**A universal nuclear-gene predictor needs an explicit decoding assumption.** [NCBI's genetic-code reference](https://www.ncbi.nlm.nih.gov/Taxonomy/Utils/wprintgc.cgi) assigns codes using CDS `transl_table` metadata. Its table 6 makes TAA/TAG glutamine while retaining TGA as stop. Table 26 changes CTG to alanine without changing the standard stop set. Thus stop-set compatibility alone does not establish correct protein translation. Table 28 assigns amino acids to all three conventional stop codons in its `AAs` row while marking the same codons as termination-capable in its `Starts` row. Reading only the former would lose termination information; interpreting the latter as globally forbidden internal codons would lose sense usage. These are nuclear-code examples, so the charter's organelle exclusion does not remove the issue.

[Swart et al., Cell 2016, DOI 10.1016/j.cell.2016.06.020](https://doi.org/10.1016/j.cell.2016.06.020), inspected through [open full-text XML](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC4967479/fullTextXML), supports a stronger boundary case: in *Condylostoma magnum*, internal conventional stop codons can encode amino acids while terminal occurrences stop translation. The study combines sequence analysis, mass spectrometry and ribosome profiling. Transcript-end proximity is a proposed explanation supported by positional evidence; a specific poly(A)-binding-protein mechanism is a hypothesis, not established causation. A fixed replacement codon dictionary alone cannot describe this contextual distinction.

**Current Tiberius has separate decoder, filter and export assumptions.** Pins inspected: Tiberius `e73844bfc7170665bc6632f1806a05dfe59fae8a` and bricks2marble `6b365c5e1dc98f22671db31a402b9429f2147f09`.

- The default [Tiberius HMM wrapper](https://github.com/Gaius-Augustus/Tiberius/blob/e73844bfc7170665bc6632f1806a05dfe59fae8a/tiberius/hmm.py#L5), instantiated by [`make_default_hmm`](https://github.com/Gaius-Augustus/Tiberius/blob/e73844bfc7170665bc6632f1806a05dfe59fae8a/tiberius/eval_model_class.py#L476), supplies no stop-codon override. The dependency's [configuration](https://github.com/Gaius-Augustus/bricks2marble/blob/6b365c5e1dc98f22671db31a402b9429f2147f09/bricks2marble/tf/hmm/layer.py#L97) exposes a configurable stop list, defaulting to TAG/TAA/TGA. Its [emission builder](https://github.com/Gaius-Augustus/bricks2marble/blob/6b365c5e1dc98f22671db31a402b9429f2147f09/bricks2marble/tf/hmm/tools.py#L195) derives internal non-stop support by testing where stop probability equals zero. Consequently, merely changing that fixed list cannot give a complete codon positive support in both the restricted internal coding state and the terminal state. This is an emitter-support observation, not a prediction experiment or a claim about every possible exon-boundary path.
- Tiberius's actual [postprocessing callback](https://github.com/Gaius-Augustus/Tiberius/blob/e73844bfc7170665bc6632f1806a05dfe59fae8a/tiberius/main.py#L535) calls `check_inframe_stop_codons(annot, fasta, remove=True)` without a `codons` argument. The [dependency helper](https://github.com/Gaius-Augustus/bricks2marble/blob/6b365c5e1dc98f22671db31a402b9429f2147f09/bricks2marble/tools/post.py#L32) accepts a custom set but defaults to TAG/TAA/TGA; it scans assembled CDS codons excluding the final codon and removes flagged transcripts when requested. A custom HMM supplied through `--model_hmm` therefore does not, by itself, configure this separate call.
- The same callback routes protein output through the annotation object's sequence exporter. [`Transcript.protein_sequence`](https://github.com/Gaius-Augustus/bricks2marble/blob/6b365c5e1dc98f22671db31a402b9429f2147f09/bricks2marble/struct/annotation.py#L145) uses a literal standard-code dictionary and offers terminal-stop removal and length-check options, but no genetic-code argument. Its dictionary must be audited separately even when stop boundaries happen to match the target's code.

These are observations about the pinned source pair. [Tiberius's source-install extra](https://github.com/Gaius-Augustus/Tiberius/blob/e73844bfc7170665bc6632f1806a05dfe59fae8a/pyproject.toml#L29) names `bricks2marble[tf]` without a version bound. I did not establish the dependency build used in the benchmark, container or published experiment; these findings do not assign a genetic-code error to their existing results.

**AUGUSTUS exposes a documented fixed-code control.** Its [pinned training tutorial](https://github.com/Gaius-Augustus/Augustus/blob/220e5a63c0fd546563472ec6d1f9271faddaf569/docs/tutorial/training.html#L362) says to configure both `translation_table` and stop-codon probabilities for a different code, illustrating table 6 in *Tetrahymena*. This is documentation evidence of support for a fixed reassignment, not a fresh installation result, frozen cross-clade transfer evidence or proof of support for context-dependent table 28.

**Verification and limits.** Python standard-library checks parsed NCBI's four table rows and executed AST-extracted, inspected `protein_sequence` code with an inert provider of already assembled CDS strings. All 64 triplets agreed with table 1; differences from the alternative `AAs` rows were exactly TAA/TAG for table 6, CTG for table 26, and TAA/TAG/TGA for table 28. Four assembled-CDS fixtures checked ordinary translation, an internal conventional stop, a reassigned sense codon and terminal-stop retention. These demonstrate the standard-code export assumption; table 28's `AAs` row alone was not treated as a terminal-context oracle. An isolated execution of the actual nested postprocessing callback with inert callees captured the default stop-filter call and `remove=True`. No TensorFlow, NumPy, genomic CDS assembly, full filtering or predictor execution was tested. An initial oversized shell invocation failed before process creation; a reduced in-memory payload completed the checks.

**Implication for my review/design opinion.** Record nuclear code and provenance alongside clade, assembly and annotation version. Keep decoder support, stop validation, exported translation and evaluation checks consistent with that declaration. Evaluate fixed reassignment and contextual termination separately; treating every nonstandard internal stop as an annotation error would confound biological scope with model quality. For a future design, known code metadata can be an input rather than requiring a separate model per clade. Context-dependent termination remains a distinct modeling question, potentially requiring transcript-end evidence; this tick does not implement or benchmark a solution.
