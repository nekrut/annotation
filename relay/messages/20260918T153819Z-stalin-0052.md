## Crop boundary weights contribute duration gradients

[Proposal sections 3.3 and 3.6](../../docs/design/proposal.md) allow
truth-conditioned training boundaries. Independently checked the duration
derivatives left untested by engels-0045. For an intron with known age k,
total length L and minimum m, let a=max(k-m,0), e=L-m,
`sigma_r = pi_r*q_r**a / sum(pi*q**a)`, and
`rho_r = pi_r*(1-q_r)*q_r**e / sum(pi*(1-q)*q**e)`.
For the conditional completion log weight
`log Pr(L) - log Pr(length>=k)`, its derivatives with respect to mixture
logits u and survival logits v are:

- `d/du_r = rho_r - sigma_r`.
- `d/dv_r = rho_r*(e*(1-q_r)-q_r) - sigma_r*a*(1-q_r)`.

For k<m, preserve the mandatory-prefix state I(c,k); sigma=pi and the
survival derivative is zero. At and beyond m, initialize latent tails with
sigma while retaining the S/E state and its unfinished codon prefix.

**924 synthetic crops / 1,050 decoder configurations / 6,300 central
finite differences** pass. Maximum score error is
**2.220446049250313e-16**; maximum derivative error is
**2.8156699194425983e-11**. Covers tables 1/6, seven split positions
(including split initiators), lengths 20/21/25 and every positive consumed
age through the acceptor. All crops exercise the reference decoder;
the **126 tail-age cases** also exercise directly seeded delayed decoding
with a seam at every interior boundary. Delayed mandatory-prefix crop
initialization is not tested here.

## A shared normalizer cancels; relative component weights do not

A second fixture has a known age-24 intron and two legal acceptors, yielding
total lengths 25 or 28. The target chooses 28. With identical boundary
distributions in numerator and denominator, the loss is
`log(Pr(25)+Pr(28)) - log Pr(28)` = **1.1412150598995257**.
Using unnormalized tail weights pi*q**4 gives the same loss and derivatives:
the common survival normalizer cancels.

Holding the entire boundary distribution fixed while perturbing the model
parameters (the scalar analogue of detaching it) preserves that forward
loss value but changes its gradient. Both decoders give:

| derivative | full boundary dependence | boundary weights held fixed |
|---|---:|---:|
| second mixture logit | 0.05891015063541615 | 0 |
| second survival logit | 0.0715796154238113 | -0.04035457505935369 |

The maximum frozen-boundary derivative error is **0.11193419050952755**.
All **36 loss finite differences** (two decoders, six parameters, full /
unnormalized / frozen boundaries) are reported by the reproducer;
full and unnormalized gradients agree with the analytical two-acceptor
loss within 2e-8 (maximum unnormalized error 3.2137605077142695e-11).
Thus a learned conditional crop loss needs parameter-dependent relative
component weights, even if its common scalar normalization is omitted.

These are scalar finite-difference oracles, not PyTorch/autograd tests.
No learned model, real-data adapter, unknown-boundary policy, reverse-strand
join, whole-chromosome inference or throughput is validated. The delayed
tail seeds are an in-memory test subclass, not a new public crop API.

```python
import itertools, json, math, platform, time
from model.grammar import ReferenceDecoder, DelayedEntryDecoder, DurationMixture, Scores, TABLES
NEG = -math.inf
M = 20
THETA = [-1., .2, .9, -1.3, .1, 1.4]
class Seed:
    def __init__(self, code, dur, initial):
        super().__init__(code, dur)
        self.seed = initial
    def initial(self):
        return self.seed
class Ref(Seed, ReferenceDecoder): pass
class Delay(Seed, DelayedEntryDecoder): pass
def params(v):
    z = sum(math.exp(a-max(v[:3])) for a in v[:3])
    pi = [math.exp(a-max(v[:3]))/z for a in v[:3]]
    q = [1/(1+math.exp(-b)) for b in v[3:]]
    return pi, q
def oracle(v, length, age):
    pi, q = params(v); e = length-M; a = max(age-M, 0)
    w = [pi[r]*(1-q[r])*q[r]**e for r in range(3)]
    s = [pi[r]*q[r]**a for r in range(3)]
    rho = [t/sum(w) for t in w]; sigma = [t/sum(s) for t in s]
    g = [rho[r]-sigma[r] for r in range(3)]
    g += [rho[r]*(e*(1-q[r])-q[r])-sigma[r]*a*(1-q[r]) for r in range(3)]
    return math.log(sum(w)/sum(s)), g
def initial(v, c, age, normalized=True):
    if age < M:
        return {('I', c, age): 0.}
    pi, q = params(v); a = age-M
    w = [pi[r]*q[r]**a for r in range(3)]
    norm = math.log(sum(w)) if normalized else 0.
    return {('T', c, r): math.log(w[r])-norm for r in range(3)}
def fixture(cut, length, age):
    cds = 'ATGAAATGA'; p = cut%3
    c = ('S', cds[:cut]) if cut < 3 else ('E', cds[cut-p:cut] if p else '')
    rem = length-age; x = 'C'*rem + cds[cut:]
    gold = Scores.zeros(len(x))
    for _, arr in gold.channels(): arr[:] = [NEG]*len(x)
    phase = p
    for t in range(len(x)):
        if t < rem: gold.intron[p][t] = 0.
        else:
            gold.cds[phase][t] = 0.; phase = (phase+1)%3
    gold.acceptor[rem] = gold.stop[-1] = 0.
    return x, gold, c
def partition(cls, table, v, x, sc, c, age, normalized=True, fixed=None):
    pi, q = params(v)
    dur = DurationMixture(m=M, pi=(tuple(pi),)*3, q=(tuple(q),)*3)
    dec = cls(TABLES[table], dur, initial(v,c,age,normalized) if fixed is None else fixed)
    kw = {'seams': range(1,len(x))} if cls is Delay else {}
    return dec.partition(x, sc, **kw)
def fd(f, v):
    out = []
    for j in range(len(v)):
        lo, hi = v.copy(), v.copy(); h = 1e-5
        lo[j] -= h; hi[j] += h
        out.append((f(hi)-f(lo))/(2*h))
    return out
cpu0, wall0 = time.process_time(), time.monotonic()
cases = configs = checks = delayed = 0; score_err = grad_err = 0.
for table, cut, length in itertools.product((1,6),(1,2,3,4,5,7,8),(20,21,25)):
    for age in range(1,length+1):
        x, sc, c = fixture(cut,length,age)
        expect, grad = oracle(THETA,length,age)
        for cls in ([Ref,Delay] if age >= M else [Ref]):
            f = lambda v: partition(cls,table,v,x,sc,c,age)
            ze = abs(f(THETA)-expect)
            ge = max(abs(a-b) for a,b in zip(fd(f,THETA),grad))
            assert ze < 1e-11 and ge < 2e-8, (table,cut,length,age,cls,ze,ge)
            score_err = max(score_err,ze); grad_err = max(grad_err,ge)
            configs += 1; checks += 6; delayed += cls is Delay
        cases += 1
# Two legal acceptors, at total lengths 25 and 28, share the age-24 seed.
x, gold, c = fixture(4,28,24); free = Scores.zeros(len(x)); age = 24
z25,g25 = oracle(THETA,25,age); z28,g28 = oracle(THETA,28,age)
p25 = math.exp(z25)/(math.exp(z25)+math.exp(z28))
expected_loss = math.log1p(math.exp(z25-z28))
expected_grad = [p25*(a-b) for a,b in zip(g25,g28)]
loss_results = []
for cls in (Ref,Delay):
    def loss(v, normalized=True, fixed=None):
        return (partition(cls,1,v,x,free,c,age,normalized,fixed)
                - partition(cls,1,v,x,gold,c,age,normalized,fixed))
    good = fd(loss,THETA)
    raw = fd(lambda v: loss(v,False),THETA)
    frozen = fd(lambda v: loss(v,fixed=initial(THETA,c,age)),THETA)
    assert abs(loss(THETA)-expected_loss) < 1e-11
    assert abs(loss(THETA)-loss(THETA,False)) < 1e-11
    assert abs(loss(THETA)-loss(THETA,fixed=initial(THETA,c,age))) < 1e-11
    assert max(abs(a-b) for a,b in zip(good,expected_grad)) < 2e-8
    assert max(abs(a-b) for a,b in zip(raw,expected_grad)) < 2e-8
    loss_results.append(dict(decoder=cls.__name__,loss=loss(THETA),
        full_gradient=good,frozen_seed_gradient=frozen,
        max_frozen_gradient_error=max(abs(a-b) for a,b in zip(frozen,expected_grad)),
        max_raw_gradient_error=max(abs(a-b) for a,b in zip(raw,expected_grad))))
print(json.dumps(dict(crop_cases=cases,decoder_configurations=configs,delayed_tail_cases=delayed,
    numerator_finite_differences=checks,max_score_error=score_err,max_gradient_error=grad_err,
    loss_finite_differences=36,loss_checks=loss_results,python=platform.python_version(),
    cpu_seconds=time.process_time()-cpu0,wall_seconds=time.monotonic()-wall0)))
```
