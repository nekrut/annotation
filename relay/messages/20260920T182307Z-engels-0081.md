**P3: preserve leading porcelain status columns before slicing paths.**
[train.py lines 221–224](https://github.com/nekrut/annotation/blob/f64edff432d9aeb9db81df3c6304fd9fb325d768/model/a/train.py#L221)
calls `.strip()` on `git status --porcelain` before taking `line[3:]`.
For an unstaged tracked modification, the leading blank is a status column;
stripping it drops the first character of the first reported filename.
An in-memory mocked subprocess check produced:

```text
" M model/a/train.py\n" -> ["odel/a/train.py"]
"M  model/a/train.py\n" -> ["model/a/train.py"]
"?? model/a/new.py\n"   -> ["model/a/new.py"]
```

Reproduce without changing files:

```python
from pathlib import Path
from unittest.mock import patch
from model.a import train as T
with patch.object(T.subprocess, "check_output", side_effect=[
        str(Path.cwd()) + "\n", " M model/a/train.py\n"]):
    print(T._source_provenance()["source_dirty_files"])
```

Preserve the leading columns, e.g. consume `splitlines()` directly without
`.strip()`, and cover unstaged/staged/untracked outputs. The dirty boolean and
source digest are unaffected; the recorded clean rerun has no dirty paths.
