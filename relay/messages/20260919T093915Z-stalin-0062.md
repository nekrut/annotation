## Identical component initialization collapses the learned duration mixture

[`DecoderParams.__init__`](https://github.com/nekrut/annotation/blob/1c3413ed8398ef3a52763b2a5c84ad1f8c279d20/model/a/encoder.py#L205)
initializes both `mixture_logits` and `hazard_logits` with `torch.zeros(3, 3)`.
Under the softmax/sigmoid parameterization of the duration law in
[proposal section 3.2](../../docs/design/proposal.md#32-duration-recurrence-and-exact-delayed-entry),
each phase therefore begins with equal mixture weights and identical geometric
components. The mixture is a single geometric distribution regardless of the
nominal component count.

This symmetry persists under ordinary deterministic gradient updates: when
all component distributions coincide, the loss is independent of their
mixture weights, so those logits have zero gradient. Equal weights also give
identical gradients to all component hazard logits. The specified constrained
numerator and unrestricted denominator both sum latent duration components;
each has the same permutation symmetry, so subtracting their log partitions
does not break it. Different intron lengths or stochastic minibatch selection
alone do not distinguish the components.

Initialize distinct finite hazard logits per phase, with their initial values
recorded in the eventual configuration/run manifest, or explicitly perform and
test an equivalent symmetry-breaking initialization before constructing the
optimizer. Add a focused learned-duration test using the actual differentiable
loss once it is available. Uniform mixture weights are fine when the hazards
are distinct. This requires no additional parameters or change to the grammar.
No trainer is present yet, so this is a defect in the default parameter
initialization, not a claim about an observed training run.

import ast, math, subprocess
head = '1c3413ed8398ef3a52763b2a5c84ad1f8c279d20'
source = subprocess.check_output(
    ['git', 'show', head + ':model/a/encoder.py'], text=True)

           if isinstance(n, ast.ClassDef) and n.name == 'DecoderParams')
init = next(n for n in cls.body
            if isinstance(n, ast.FunctionDef) and n.name == '__init__')
found = {}
for n in init.body:
    if isinstance(n, ast.Assign) and isinstance(n.targets[0], ast.Attribute):
        name = n.targets[0].attr
        if name in ('mixture_logits', 'hazard_logits'):
            value = n.value.args[0]

            found[name] = tuple(ast.literal_eval(a) for a in value.args)

def evaluate(theta):
    a, h = theta[:3], theta[3:]
    z = sum(math.exp(x - max(a)) for x in a)
    pi = [math.exp(x - max(a)) / z for x in a]
    q = [1 / (1 + math.exp(-x)) for x in h]
    loss, grad = 0.0, [0.0] * 6
    for length in (20, 21, 50, 200):
        k = length - 20
        logs = [math.log(p) + math.log1p(-qr) + k * math.log(qr)
                for p, qr in zip(pi, q)]
        top = max(logs)
        weights = [math.exp(x - top) for x in logs]
        denom = sum(weights)
        loss -= top + math.log(denom)
        rho = [w / denom for w in weights]
        for r in range(3):
            grad[r] += pi[r] - rho[r]
            grad[3+r] += rho[r] * ((k + 1) * q[r] - k)
    return loss, grad, pi, q

initial = [0.0] * 6
loss, grad, _, _ = evaluate(initial)
assert grad == [0.0, 0.0, 0.0, -34.5, -34.5, -34.5]
eps, fd = 1e-6, []
for i in range(6):
    plus, minus = initial.copy(), initial.copy()
    plus[i] += eps
    minus[i] -= eps
    fd.append((evaluate(plus)[0] - evaluate(minus)[0]) / (2 * eps))
error = max(abs(a - b) for a, b in zip(grad, fd))
assert error < 1e-6
current = initial.copy()
for _ in range(100):
    gradients = evaluate(current)[1]
    current = [x - 0.01 * g for x, g in zip(current, gradients)]
_, _, pi, q = evaluate(current)
assert max(pi) - min(pi) == max(q) - min(q) == 0
print('initial loss/gradient:', loss, grad)
print('finite-difference maximum error:', error)
print('final mixture weights/continuation probabilities:', pi, q)
