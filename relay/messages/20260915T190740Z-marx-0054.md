**3.3 bounded-memory traceback replay (engels-0038, stalin-0045).** The
forward pass now retains only the block checkpoints (`_run(..., retain=False)`
is the default for `partition` and `viterbi`; checkpoints carry no back
pointers). `viterbi` walks boundaries from n to 0 and, whenever it needs a
block it does not hold, drops the block it held and recomputes the needed
one from its own checkpoint with the same emissions. The boundary index only
decreases, so each block is replayed at most once and one block of back
pointers is alive at a time; a tail entry whose donor lies several blocks
back resumes from the donor's true boundary through blocks that were never
retained. `chunk_calls` and `max_held_back` on the decoder expose the
accounting: regressions assert at most `2 K` chunk calls for `K` blocks and
a held set no larger than the block, on a two-intron layout with blocks of
3, 7 and 64 bases (m = 20) and on 60 random lattices with random seams, with
chains equal to the reference. engels' retention probe should now show
`layers == back == []` from `_run` and the held back-pointer count bounded
by the block size.

**3.6 admission audit on the ten train species.** `model/labels/admission.py`
implements the loader contract: the scorer's sequence and biotype filters,
longest-CDS representatives, topology masks, the metadata audit on raw rows
(exception and transl_except tags, partial declarations with the minus-strand
swap, interior and unlocated partials, overlaps, gaps under m, phase
consistency with the 5'-partial prefix rule, table conflicts), then the
streaming FASTA audit (ambiguity, initiator, stop, in-frame stops, length,
prefix marginalized rather than trimmed). Manifests, summaries and the
numerator-check outputs are under `model/labels/manifests/`; every count,
reason, checksum and runtime is in `docs/design/admission-audit.md`. The
proposal's 4.4 table reproduces exactly for its four species (IDs, loci,
components, masked representatives, donor/acceptor catalogs).

Finding for the coordinator: in the RefSeq vertebrates the exception tag
`annotated by transcript or proteomic data` dominates the mask. Zebrafish
loses 7,959 of 28,402 representatives (28%) to it, frog 3,692 (17%), maize
1,851 (5%), while only 156 / 90 / 72 of those also fail an ORF check. The
audit keeps the proposal's conservative policy and exposes the loss; taking
the ORF-passing subset back is a manifest filter plus a `decision`, not a
code change.

Finite legal numerator: constructive for every admitted chain, and checked
with the delayed decoder itself on ten spliced admitted genes per species
(`model/labels/numerator_check.py`; 100 windows, 0 failures, chains
recovered exactly, about 0.7 ms per base in pure Python).
