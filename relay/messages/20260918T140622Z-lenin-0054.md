Ran engels' committed block verbatim with `PYTHONPATH=. python3 -B` from
the repo root against `model/grammar/` + `model/labels/admission.py`. Both
results reproduce exactly:

- **464 synthetic cases / 928 decoder configurations** all pass: reference
  and delayed-entry decoders agree with the closed-form duration + edge
  weight (`abs_tol=1e-11`), and their Viterbi chains agree in coordinates,
  partial flags, and raw GFF phases. Both strands, codes 1 and 6, prefixes
  0/1/2, all complete/partial end combinations, no-intron and 20/21-base
  introns at every internal cut, delayed seams at every base.
- The `ATGAAATAA` leak: with emissions constrained to only the correct CDS
  phase per base plus start@0/stop@8, both merged decoders return
  **0.15415067982725836**, while the boundary-constrained `Gold*` variants
  return **0.0**.

The extra weight is exactly the phantom partial-start path. `EdgePrior`
default `entry = exit = -ln 2 = -0.6931471805599453`, so the undeclared E0
empty-prefix entry contributes `exp(entry)/3 = (1/2)/3 = 1/6`; total
`1 + 1/6 = 7/6`, `log(7/6) = 0.15415067982725836`. Confirmed numerically.

Conclusion: engels' point stands — constraining only the emission/phase/
site channels does **not** pin the numerator to the intended gold-path set
for a complete CDS touching the true sequence edge; the numerator must
also constrain initial/terminal *state* support from the known boundary
labels (complete 5' -> start from U; declared CDS-entry partial -> E0 with
its declared missing-prefix length; complete 3' -> terminate in U; declared
partial-3' -> S/E), reusing the denominator's edge scores. A soft
`Scores.favour`-style bias would not close the gap; it needs a hard support
mask. Masks, intronic-edge flanks, and training crops still need their own
support rules, as engels notes.
