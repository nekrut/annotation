## From-spec manifest/summary consistency oracle, whole train panel

Earlier ticks certified the decoder scores; this one certifies the *labels*
they will be fit against. I recomputed the summary invariants of admission
audit (proposal 3.6) purely from the committed
`model/labels/manifests/*.manifest.tsv.gz` and `*.summary.json`, with no
network, no GFF/FASTA re-parse, and no call into `model/labels/admission.py`.
All **10 train species** pass every check:

- **Representative count.** manifest data rows == `representatives` == `loci`
  for each species (e.g. Dictyostelium 13,155; Zea mays 34,039).
- **Partition of representatives.** `admitted + masked_union ==
  representatives`, and the manifest's own `status` column splits into
  exactly `admitted` admitted rows and `masked_union` masked rows
  (Danio 19,574 + 8,828 = 28,402; Neurospora 9,722 + 7 = 9,729).
- **Frame of admitted chains.** Every admitted row with `reasons == '-'`
  has `(cds_len + missing_prefix) % 3 == 0`. Exactly **one** admitted row in
  the whole panel is flagged rather than clean: Dictyostelium
  `rna-XM_628800.1` (gene DDB_G0294204, NW_003102056.1:+, cds 11651–12018,
  `cds_len 368`, so length ≡ 2 mod 3), reason `partial_3`, `missing_prefix
  0`. That is the spec's admitted at-edge 3'-partial (admission.py: a
  declared 3'-partial is admissible where the chain's own 3' end touches the
  sequence edge); its stop is censored, so a non-multiple-of-3 spliced length
  is correct, not a defect. It sits on the scaffold behind engels's
  circular-boundary note ([engels-0053](20260918T222357Z-engels-0053.md)).
- **Transcript bookkeeping.** `accepted_transcripts == cds_transcripts_all −
  Σ benchmark_filtered` and `nonrepresentative_omitted == accepted_transcripts
  − representatives`, for all 10 (Dictyostelium 13,315 − 136 = 13,179 accepted;
  13,179 − 13,155 = 24 omitted alternates).
- **Reason histogram.** Aggregating the `reasons` column over **all**
  representatives reproduces `summary.reasons` token-for-token in every
  species. So the summary's reason counts are per-representative, and the
  masked-only histogram differs from it by exactly the admitted edge-partials
  — for Dictyostelium only `partial_3`: 74 over all reps, 73 masked, +1 the
  admitted row above. No orphan or unknown reason token anywhere.

No discrepancy found. The manifests are internally consistent and consistent
with their summaries across the panel; the single non-clean admitted chain is
spec-legal. This is a static consistency proof of the committed artifacts, not
a rerun of representative selection, topology masking, or the FASTA audit
(those need the pinned GFF/FASTA and are engels's to own), and it does not
touch the benchmark denominator.

## Reproduction and accounting

Run from the repo root with `python3 -B`; all in memory, no network.

```python
import gzip,json,glob,os,collections,re
def load(mf):
    with gzip.open(mf,'rt') as fh:
        h=fh.readline().rstrip('\n').split('\t')
        return [dict(zip(h,l.rstrip('\n').split('\t'))) for l in fh]
for sm in sorted(glob.glob('model/labels/manifests/*.summary.json')):
    d=json.load(open(sm)); rows=load(sm.replace('.summary.json','.manifest.tsv.gz'))
    adm=[r for r in rows if r['status']=='admitted']
    msk=[r for r in rows if r['status']=='masked']
    assert len(rows)==d['representatives']==d['loci']
    assert d['admitted']+d['masked_union']==d['representatives']
    assert len(adm)==d['admitted'] and len(msk)==d['masked_union']
    for r in adm:
        if r['reasons']=='-':
            assert (int(r['cds_len'])+int(r['missing_prefix']))%3==0
        else:
            assert 'partial_3' in r['reasons'] or 'partial_5' in r['reasons']
    bf=sum(d['benchmark_filtered'].values())
    assert d['cds_transcripts_all']-bf==d['accepted_transcripts']
    assert d['accepted_transcripts']-d['representatives']==d['nonrepresentative_omitted']
    tok=collections.Counter()
    for r in rows:
        for t in re.split(r'[;,]',r['reasons']):
            t=t.strip()
            if t and t!='-': tok[t]+=1
    assert dict(tok)=={k:v for k,v in d['reasons'].items()}
```
