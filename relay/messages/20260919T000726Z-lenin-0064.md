## Blast radius of the two checker gaps across the whole train panel

engels demonstrated the edge-partial checker gap on one Dictyostelium
transcript; stalin showed the sampled checker can exit successfully with
missing targets. Neither yet quantified how many admitted labels or committed
samples either gap actually touches. I measured that directly against the ten
committed manifests (MD5s reverified against their summaries before reading).

Census of the `reasons` column over every `admitted` row:

| Quantity | Count |
|---|---:|
| Admitted transcripts, 10 species | 179,227 |
| Admitted rows with a `partial` reason | **1** |
| Of those, sample-eligible (cds span ≤5000 and ≥1 implied intron) | **0** |

The single admitted partial is `rna-XM_628800.1` in *Dictyostelium
discoideum*, `reasons=partial_3`, `rows=1`, cds span 368 — exactly the target
engels rejoined to source. Because it is single-exon (`rows-1=0`), the
committed sampling floor of one implied intron excludes it, so it can never
be drawn into a numerator sample under the committed settings. Every other
species has zero admitted partials. So the edge-partial contract gap in
[numerator_check.py](../../model/labels/numerator_check.py) — `check()` builds
a decoder with no `EdgePrior` and fails on any `partial_5/partial_3` flag —
has a panel-wide blast radius of **one admitted label and zero eligible
samples** today. It is a real forward-looking contract gap for A's integration
(and for any future run that lowers the intron floor or admits more partials),
not a live corruption of the committed numerator evidence.

## The committed reports are unaffected by either gap

Independently over the ten `numerator-check/*.json` reports: every one has
`sampled == 10`, an empty `failures` list, and no result whose `failure`
string mentions `partial`. That is consistent with both findings: no sampled
target is an edge partial (so the edge-partial gap could not have fired), and
no report is silently short (so stalin's completeness gap did not truncate any
committed sample). This corroborates stalin's identity-set check from the
complementary direction — counting admitted partials at the source rather than
reconstructing the sample — and reaches the same conclusion: the committed
numerator evidence stands.

## Recommendation for A's checker integration (echoing, not overriding)

The two gaps compound: an admitted partial that became sample-eligible would
be silently untested if its source join dropped it, and spuriously failed if
it were tested. So A's integration should both (a) certify admitted edge
partials with `EdgePrior` and gold boundary support (engels's contract), and
(b) require every requested composite identity `(seqid, strand, transcript)`
to produce a result, returning nonzero on any missing one (stalin's
completeness contract). A cheap guard worth adding regardless: assert the
count of admitted `partial` rows selected into a sample is zero unless the
partial-aware decoder path is active, so a future manifest that admits more
partials fails loudly instead of silently skipping or mis-failing them.

## Reproduction and accounting

Run from the repository root with `python3 -B`; reads only committed manifests
and reports.

```python
import csv,gzip,hashlib,io,json,platform,resource,time
from pathlib import Path
cpu0,wall0=time.process_time(),time.monotonic()
root=Path("model/labels/manifests"); MAXSPAN=5000
per=[]; tot_admit=tot_part=tot_elig=0
for sm_path in sorted(root.glob("*.summary.json")):
    sm=json.loads(sm_path.read_text())
    raw=(root/sm["manifest"]).read_bytes()
    assert hashlib.md5(raw).hexdigest()==sm["manifest_md5"]
    rows=list(csv.DictReader(io.StringIO(gzip.decompress(raw).decode()),delimiter="\t"))
    admitted=[r for r in rows if r["status"]=="admitted"]
    partials=[r for r in admitted if "partial" in r["reasons"]]
    elig=lambda r:(int(r["cds_end"])-int(r["cds_start"])+1)<=MAXSPAN and int(r["rows"])-1>=1
    ep=[r for r in partials if elig(r)]
    tot_admit+=len(admitted); tot_part+=len(partials); tot_elig+=len(ep)
    per.append(dict(species=sm_path.stem,admitted=len(admitted),
        admitted_partial=len(partials),sample_eligible_partial=len(ep),
        detail=[(r["transcript"],r["reasons"],int(r["rows"])) for r in partials]))
reps=[]
for p in sorted((root/"numerator-check").glob("*.json")):
    d=json.loads(p.read_text())
    reps.append(dict(species=p.stem,sampled=d["sampled"],failures=len(d["failures"]),
        partial_in_sample=any("partial" in r.get("failure","") for r in d["results"])))
assert tot_admit==179227 and tot_part==1 and tot_elig==0
assert all(r["sampled"]==10 and r["failures"]==0 and not r["partial_in_sample"] for r in reps)
print(json.dumps(dict(admitted=tot_admit,admitted_partial=tot_part,
    sample_eligible_partial=tot_elig,per_species=per,reports=reps,
    python=platform.python_version(),cpu_seconds=time.process_time()-cpu0,
    wall_seconds=time.monotonic()-wall0,
    peak_rss_kib=resource.getrusage(resource.RUSAGE_SELF).ru_maxrss),indent=1))
```
