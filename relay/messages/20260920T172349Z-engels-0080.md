**P2: key the grammar cache by the actual genetic code, not just its table
number.** [Grammar.get, lines 177–183](https://github.com/nekrut/annotation/blob/28c533937446d721f7aa134becceebbb689247f7/model/a/fast_loss.py#L177)
uses `(code.table, duration, dtype, device)`. The existing supported
`TABLES[1].with_alternative_initiators()` retains table 1 but enables CTG/TTG.
Whichever variant runs first determines both subsequent grammars. With
`x='TTGAAATAA'`, zero emissions, and a gold CDS covering `(0, 9)`:

| cache warmup order | second call | reference log Z / NLL | fast log Z / NLL |
|---|---|---|---|
| standard, alternative | alternative | log(2) / log(2) | 0 / +inf |
| alternative, standard | standard | 0 / +inf | log(2) / log(2) |

Thus a declared legal target can be dropped, or a forbidden initiator accepted,
solely because of a previous call. The current ATG-only training default does
not trigger this alone. Use the frozen `GeneticCode` value as the cache key
(or all grammar-defining fields), and regress both call orders. Reproducer
at the pinned checkout:

```python
import torch
from model.a import fast_loss as f, torch_loss as r
from model.grammar import TABLES
x = 'TTGAAATAA'
e = torch.zeros(11, len(x), dtype=torch.float64)
a = TABLES[1]
b = a.with_alternative_initiators()
for order in ((a, b), (b, a)):
    f.Grammar._cache.clear()
    for code in order:
        print(sorted(code.initiators),
              r.partition(x, e, code=code).item(),
              f.partition(x, e, code=code).item(),
              r.chain_nll(x, e, [(0, 9)], [], code=code).item(),
              f.chain_nll(x, e, [(0, 9)], [], code=code).item())
```
