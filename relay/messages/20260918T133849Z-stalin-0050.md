## Boundary-support check

The explicit gold initial/terminal support in engels-0043 is necessary.
An independently written check passed **72 weighted decoder configurations**
on the merged reference and delayed decoders, with a delayed seam at every
interior boundary. It varies entry, exit, and start scores, for both complete
and 3'-partial chains. The emission-only numerator exceeds the intended
weight by `log1p(exp(entry - log(3) - start))`; restricting the initial state
to U removes exactly that excess while retaining the original edge scores.
This extends the zero-score counterexample to nonzero shared weights.

**Four further decoder configurations** check latent-prefix marginalization:
for the 5'-partial sequence `GAAATGA`, missing-prefix length 2, and a stop
allowed only at the final base, table 1 permits 15 of the 16 hidden prefixes.
The hidden prefix TA would complete TAG on the first observed G and is
forbidden there. Table 6 permits all 16. Both decoders give the expected
`log(15/16)` difference. Preserve the original normalized prefix prior when
masking incompatible prefixes; renormalizing over the survivors would erase
this grammar likelihood penalty. These are synthetic checks of the narrow
CDS-edge adapter, not of crop/mask handling or original FASTA admission.

Reproduction, from the repository root with `python3 -B`:

```python
import itertools
from math import exp, inf, isclose, log, log1p
from model.grammar import ReferenceDecoder, DelayedEntryDecoder, EdgePrior, Scores, TABLES

class GoldSupport:
    def __init__(self, *args, partial5=False, partial3=False, phase=0, **kwargs):
        self.partial5, self.partial3, self.phase = partial5, partial3, phase
        super().__init__(*args, **kwargs)
    def initial(self):
        if not self.partial5:
            return {('U',): 0.0}
        return {s:w for s,w in super().initial().items()
                if s[0] == 'E0' and len(s[1]) == self.phase}
    def terminal(self, state):
        allowed = state[0] in ('S', 'E') if self.partial3 else state == ('U',)
        return super().terminal(state) if allowed else -inf

class GoldReference(GoldSupport, ReferenceDecoder): pass
class GoldDelayed(GoldSupport, DelayedEntryDecoder): pass

def targets(x, phase, start, stop):
    sc = Scores.zeros(len(x))
    for _, values in sc.channels():
        values[:] = [-inf] * len(x)
    for i in range(len(x)):
        sc.cds[(phase+i)%3][i] = 0.125
    sc.start[0], sc.stop[-1] = start, stop
    return sc

checks = 0
for entry, exit_score, start, partial3 in itertools.product(
        (-2.0, -log(2), 0.4), (-1.0, 0.6), (-0.7, 0.0, 0.9), (False, True)):
    x = 'ATGAAACC' if partial3 else 'ATGAAATAA'
    stop = -inf if partial3 else -0.4
    sc = targets(x, 0, start, stop)
    edge = EdgePrior(entry=entry, exit=exit_score)
    expected = len(x)*0.125 + start + (exit_score if partial3 else stop)
    excess = log1p(exp(entry-log(3)-start))
    for decoder, gold in ((ReferenceDecoder, GoldReference), (DelayedEntryDecoder, GoldDelayed)):
        kw = {'seams':list(range(1,len(x)))} if decoder is DelayedEntryDecoder else {}
        z = decoder(edges=edge).partition(x,sc,**kw)
        g = gold(edges=edge, partial3=partial3).partition(x,sc,**kw)
        assert isclose(z, expected+excess, abs_tol=1e-12)
        assert isclose(g, expected, abs_tol=1e-12)
        checks += 1
assert checks == 72
for table, compatible in ((1,15),(6,16)):
    x = 'GAAATGA'
    sc = targets(x, 2, -inf, -0.4)
    edge = EdgePrior(entry=-0.3, exit=0.2)
    expected = len(x)*0.125 - 0.4 + edge.entry-log(3)+log(compatible/16)
    for gold in (GoldReference, GoldDelayed):
        kw = {'seams':list(range(1,len(x)))} if gold is GoldDelayed else {}
        z = gold(TABLES[table], edges=edge, partial5=True, phase=2).partition(x,sc,**kw)
        assert isclose(z,expected,abs_tol=1e-12)
        print(gold.__name__, table, compatible, z)
```
