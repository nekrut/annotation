## Decoder/graph consistency (verified this tick)

- **Decoder arithmetic reproduces from the grammar's own settings**
  (P=41, R=3, m=20). Delayed entry: active scores `1+P*(1+R)=165`,
  transition candidates `2+P*(1+3R)=412`, checkpoint slots
  `S+m*P+4*(m+1)=165+820+84=1069`. Expanded oracle: `1+P*(m+R)=944` and
  `2+P*(m+3R)=1191`. Candidates/Mb both strands, forward plus replay:
  `412*2*2=1.648` billion and `1191*4=4.764` billion. All match section 3.3.
- **P=41 is consistent with the state inventory**, not a free parameter:
  the intron I(c,r) holds any complete coding state c, and E(q)+S(q) give
  `21+20=41` such states (section 3.1). The 11 emission channels decompose
  exactly: U(1)+CDS-by-p(3)+intron-by-p(3)+start/stop/donor/acceptor(4).
- **Delayed-entry recurrence matches the stated duration law.** At l=m the
  entry pays `log(pi[p,r])` and the exit `log(1-q[p,r])` with no
  continuation factor -> `pi*(1-q)`; at l=m+1 one `log(q)` is paid ->
  `pi*q*(1-q)`. This reproduces `Pr(length=l|p)=sum_r pi*(1-q)*q**(l-m)`
  term by term, so the optimized form and the section 3.2 expanded oracle
  score the same durations.
- **CRF <-> splice-graph agreement is correct and load-bearing.** Section
  3.1 states that a graph decoder must carry the full spliced prefix q
  (nucleotide identities), not only its phase; section 5.1/5.2 honor this
  ("intron edge preserves the full coding prefix"; exon edges "propagate
  section 3.1's S/E prefix states through actual oriented bases"). The
  joint chain/component Viterbi choice in 3.2 is reused verbatim in 5.2
  ("same joint-component choice as A's Viterbi"). So C cannot admit a
  codon-incompatible chain that A's CRF would forbid.
- **Phase formula agrees with the independent check.** Section 3.1's
  `(3-p)%3` equals marx's `(-p)%3` for p in {0,1,2} (0,2,1 respectively),
  so the two independent derivations of GFF3 phase coincide.

## Frozen-encoder comparison

The comparison is set up as a proper nested ablation: for K=1 the
comparative residual is identically disabled, so B reduces exactly to A,
and any B-over-A gap is attributable to the added comparative/tree
evidence rather than to a different decoder or inference rule (3.2 pins
the inference choice identical across arms; section 7 exp 1 fixes decoder,
support, split). Milestone ordering respects this: A is frozen before the
gate threshold tau is fit (milestone 3), and both are frozen before
held-out evaluation. The complete-genome denominator is retained for the
A/B report (exp 4), so the gate's tile selection does not bias the
comparison.

**Finding 2 (recommended clarification, non-blocking).** One degree of
freedom in the frozen-encoder comparison is not pinned: whether A's 455,841
DNA-encoder weights are *frozen* (only B's 39,180 comparative scalars
train) or *co-trained* inside each comparative arm. Section 4 and
milestone 3 read as frozen-A-plus-residual; section 7 exp 1's phrase
"effective capacity controlled" and its arm list (DNA-only; MSA/no-tree;
MSA/tree; patristic; MDS) read as separately trained encoders. These give
different interpretations of a B>A result: a co-trained A can adapt its own
features to feed the residual, inflating the apparent geometry gain, while
a frozen A understates it. Recommend the decision/charter state one regime
explicitly and report it, since it also determines whether the parameter
budget is 455,841+39,180 or a second full encoder. The nested property
(K=1 => B==A) already holds either way; only the attribution needs the
declared A-weight regime.
